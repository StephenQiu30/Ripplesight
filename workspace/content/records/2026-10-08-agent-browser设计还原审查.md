# agent-browser 全站设计还原审查

## 做了什么

审查前核对main与origin/main均为e7e886a4，执行推送返回Everything up-to-date。使用agent-browser 0.33.0，以本聊天从Figma桌面端导出的10张稿为快照基线，对52个代表路由进行1440px走查，另检查8类核心页面的390px布局。

本人允许临时测试会话。本轮使用隔离合成会话，保留登录页，未创建真实用户或修改认证。8666发生OOM后，用同一生产构建接真实8667后端补查公开入口；个人页面另用只读固定/空样本核对版式。运营页只检查令牌入口，没有写真实业务数据。

## 结果

**未完整还原，验收未通过。** 302px侧栏、350px正文起点、主要标题和登录面板已接近原稿；核心窄屏未发生文档横向溢出。收藏备注可用键盘保存，刷新后仍显示。

| 问题 | 结果 |
|---|---|
| 探索辅栏 | 展开38专题，相关搜索在5481px、主栏空态在3175px；偏离6个紧凑专题的原稿 |
| 探索结果 | 数量另占一行，首条徽标比原稿约靠下68px |
| 事件详情 | 曲线与时间线之间仍保留旧“事实与进展”整段 |
| 开发预览 | 2GB前端容器11:34:02触发OOM重启，多页断连 |
| 真实模型榜 | database_unavailable、503；样本排名不算真实服务通过 |
| 可访问性 | 首页提醒对比度4.34低于4.5；登录页页脚地标嵌套 |

原稿要求的全站统计、情感/历史曲线、X趋势、关注、多类型收藏、小时命中和告警已读仍缺完整正常数据。辅助页没有单页原稿，不能认定保留的旧表单已完成还原。

完整[逐页表、问题及证据边界](../product/reference/15-全站设计还原审查明细.md)已持久化。首页空/503/403状态已另复核；全站每页五状态、所有实体ID/筛选分支、真实身份和运营写入尚未验收。
