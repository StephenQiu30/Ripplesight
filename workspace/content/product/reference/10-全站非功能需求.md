# 全站非功能需求

支持[页面需求总纲](../prd/03-PRD-全站页面需求.md)，与每页的功能验收同时生效。**硬约束**来自用户及仓库工程规范；下列耗时、容量、留存和服务目标均为 **AI 初始提案，尚未建立实测基线**，不能写成已达到的 SLA。与原 PRD 既有指标冲突时先核对原范围，不静默覆盖。

## 测量协议

前端分别使用 1440px 桌面、390px 窄屏；浅/深色、键盘和缩放分别检查。固定浏览器/版本、网络条件和构建 SHA；首次无缓存与热缓存分开，每场景至少 20 次，记录原始分布，不能只报最快一次。浏览器性能提案网络条件为下行 10Mbps、往返 100ms、CPU 4 倍限速；工具和版本须记入验收记录。

后端在独立测试库，记录机器 CPU/内存、PostgreSQL/应用版本、并发、样本规模和查询计划。目标容量样本先设 10 万内容、100 万观察、1000 主题、1 万事件；这是基准输入提案，并非当前业务规模。受控本机接口测量至少 200 请求、分别并发 1/10/20，剔除首次预热但保留错误；真实来源时间不能混入本机 API 耗时统计。

生产或本人真实来源只能在已授权范围验收，不做压力测试，不借登录态扩大采集。没有实际跑过的格子写“未测”，不写“满足”。

## 目标与验收矩阵

| 质量项／页面范围 | 必须满足的行为或初始目标 | 测量与失败条件 |
|---|---|---|
| 首屏阅读／全部主要入口 | 提案：关键正文可读时间 p75≤2.5s，布局位移≤0.1，常用交互响应 p75≤200ms；含请求失败时可见降级 | 按固定浏览器协议采集导航与交互轨迹；超标调查后优化，不隐藏慢样本 |
| 读取 API／公开列表、本人列表 | 提案：上述容量、并发 20 下 p95≤800ms，p99≤1500ms，本机服务错误率<1%；聚合接口单列 | 独立库计时+SQL 计划；超时、权限或空结果不能从样本中删除 |
| 写入受理／主题、告警、文档 | 提案：本地验证和写事务 p95≤1s；长采集/模型/构建异步回执，页面 100ms 内可见操作反馈 | 网络断开和重放仍可查原结果；错误呈现不丢草稿 |
| 列表与包体／首页、探索、监控 | 有界分页，不全量拉取；首页热度最多一次批量读取，单项不得 N+1；提案列表 JSON 压缩后≤250KB（20 项，不含正文） | 网络瀑布、序列化体积、React 生产构建检查；正文/导出另设容量，不删关键权限字段换体积 |
| 阅读并行与取消 | 独立区块并行；筛选变更取消或忽略旧响应；可选模块失败不阻塞核心内容；长任务状态从服务器恢复 | 注入反序响应和一个永久失败区块，旧筛选结果覆盖新结果即失败 |
| 缓存与新鲜度 | 私有内容、令牌与许可敏感结果遵守服务端缓存头；撤回后的下一次服务器读取必须重新校验；公开缓存绑定发布修订 | 提案页面恢复焦点或最长 60s 重查许可；离线明确“未核实”，不得继续授权新下载；已合法下载的文件无法远程撤回 |
| 身份与隔离 | owner 从会话获得；每种资源做匿名/本人/其他账号/运营四类测试；越权正文、标题、计数、ID存在性泄漏为 0 | 故意换 ID、游标、批次/文档路径；前端隐藏按钮不算授权控制 |
| 凭据与输入 | Cookie、密码、运营/来源 Token 不进入 URL、日志、导出、模型上下文和快照；不可信 Markdown/链接/文件名安全渲染 | 恶意 URL、脚本片段、超长 Unicode、路径穿越样本；任何执行/外泄阻断发布 |
| 可靠写入 | 新异步写有 owner 隔离的 operation_id、请求指纹和回执；同键同参不重复副作用，异参 409 | 注入提交前、提交后丢响应与进程重启；只测双击不充分 |
| 并发与一致性 | 更新比较版本，旧 Job 继续冻结版本；列表游标绑定快照，许可变更不拼接旧数据 | 两标签页编辑、分析进行中翻页、删除/撤回期间刷新；静默覆盖/漏项/混页失败 |
| 调度与停止 | 已暂停、无准入、预算耗尽、验证码/风控时不再发新请求；取消不能宣称已撤销发出的请求 | 假时钟/隔离任务验证边界；自然到期与持续运行另做真实验收 |
| 外部依赖降级 | 来源/模型/邮件失败独立呈现；不得静默换身份、收费接口或备用付费模型 | 故障注入认证过期、429、503、结果结构变化；覆盖状态不得 complete |
| 统计可信度 | 显示范围/窗口/单位/来源/分母/分析版本；未知为 null、零有观测，跨平台不同量纲不直接相加 | 固定金标样本、时间缺失与全部跳过；零与未知无法区分即失败 |
| 分析质量 | 情感只对定义的有效样本统计，四档相关性与旧 bool 结果不混算；没有证据不输出“准确率” | 盲标评估集、样本来源/标注者/分歧流程先建立；达到何门槛由原 POC 与评审定，不自报百分比 |
| 时间与增量 | UTC 存储、带时区接口、界面北京时间；来源发布时间/首次发现/观测分开，窗口左闭右开 | 边界整点、跨日、夏令时输入、未来/缺失时间、晚到评论与重抓；不得漏掉第二轮新增 |
| 键盘与读屏 | 全部主路径可用 Tab/Enter/Escape；语义标题/名称/错误关联；弹层焦点闭环，异步反馈可感知 | 真浏览器键盘和读屏抽测关键表单/弹层；只有鼠标可操作即失败 |
| 视觉可访问性 | 提案：普通文本对比度≥4.5:1、大字和控件边界≥3:1；200% 缩放仍可读；颜色之外提供文字/形状 | 此处是测试阈值提案，不宣称取得标准认证；测浅/深主题、禁用与错误态、图表非颜色信息 |
| 响应式与运动 | 1440px/390px 没有整页横向溢出或被固定导航遮挡；表格区域内滚动；遵从减少动态效果偏好 | 中文长标题、无空格长链接、空列表、200 项与浮层；不能通过隐藏关键动作通过 |
| 费用与资源 | 取数无必需收费 API；严格服从来源每日预算和并发；模型成本来源与计量可解释 | 0、余1、并发竞争和重试边界；超预算外发或未知价格被计0阻断 |
| 可观测性 | request_id/operation_id/job_id、阶段、耗时、结果和停止原因可关联；日志不含密钥、私人正文或全文搜索词 | 一条失败链路可从页面定位到阶段；敏感字段扫描和采样审查；日志有界留存 |
| 导出与可移植性 | 只导出所选/当前可读数据，注明时间、范围与许可；CSV 单元格公式安全，Markdown/JSON 转义 | 撤回、混合选择、恶意标题、失败重试；不输出未选内容和隐藏凭据 |
| 备份与恢复 | 架构要求先实际恢复再升级；提案单机 RPO≤24h、RTO≤4h，实际须测量且注明数据量 | 独立环境备份→恢复→行数/约束/业务抽检；备份成功不等于恢复成功，不承诺当前已达标 |
| 运维可用性 | 当前无已验证生产 SLA；提案 7 天受控运行记录失败/停机/漏触发窗口，计划停机单列 | 外部平台不可用与自身故障分别统计，不只用 /health 成功推断服务可用 |
| 可维护与契约 | 生成 API 无手改、只有一份 schema、shadcn 语义组件与统一令牌、按领域服务处理 | 按工程检查；新业务流程具备有意义回归，不写仅镜像实现的测试 |
| 文档与追踪 | 52 页路由覆盖、中文搜索可命中、链接与原文导出有效；改字段/端点同提交更新文档 | workspace index/check/build/verify；源码盘点与需求页路由集合一致 |

## 留存与用户控制

| 信息 | 现状或候选策略 | 用户操作与验证 |
|---|---|---|
| 本机收藏/已读 | 当前分别上限 500/5000；受浏览器存储影响，无跨设备保证 | 存储异常可见，不悄悄丢失；清除、退出和共享电脑情形有说明 |
| 云收藏/备注提案 | 主动开启；取消使用墓碑避免离线旧写复活，完整回执建议30天，精简防重键与墓碑保留至云数据清除；超过回执窗的旧写必须拒绝/重新同步 | 清除账号数据时处理业务行、操作回执及备份保留；账户删除能力尚需合同，不能凭页面文案承诺即时彻底删除 |
| 原始证据/评论 | 按来源与许可现有留存配置；没有一刀切永久保存 | 暂时不可见、明确删除与采集失败分别处理，保留必要状态而非全文 |
| 日志/统计 | 最少必要字段，期限按用途设定；全局概览只用当前可公开输入 | 公开指标不能反推私有来源或个体；清理结果与备份延迟说明 |
| 项目需求 | Git 保留变更历史，公开允许清单不含秘密 | 敏感材料误入时撤回发布/旋转凭据，不能认为删最新文件就清除了历史 |

## 失败分级与交付

权限/凭据泄漏、非法外发、数据损坏、重复外发、许可绕过、错误统计伪装真实属于阻断问题。性能或可访问性目标未达需明确受影响页面和测量数据，不能把“能运行”当符合需求。外部不可用允许受控降级，但必须真实呈现覆盖和恢复条件。

每个实施切片留下构建 SHA、测试数据范围、命令/退出码、浏览器尺寸、实际结果和未测项；只有真实来源验收才更新能力状态。统一[跨页场景](11-全站验收场景.md)与每页的验收共同使用；工程全量测试、文档检查和业务验收分别记录。
