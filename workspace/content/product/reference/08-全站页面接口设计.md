# 全站页面接口设计

本设计属于[页面需求总纲](../prd/03-PRD-全站页面需求.md)。基线为 `4489b400`：52 个页面入口、247 个生成函数，逐项方法、路径、请求、响应与后端授权见[现有接口清单](12-现有接口清单.md)。**现有接口与拟新增接口分开列出；本文没有修改 API、数据库或生成客户端。**

## 统一合同

| 事项 | 现状与目标约束 |
|---|---|
| 入口 | 沿用 `/api/*`，不引入另一套版本前缀。每个 operation_id 唯一；前端只使用生成函数与 `request.ts`。 |
| 权限 | 公开读取使用固定发布范围；个人读取使用当前会话 owner；运营读取/写入使用独立运营授权。路径中的 owner 不可信，新增接口不得接受客户端指定 owner。 |
| 文档权限 | 登录之外再校验项目文档读、编辑、发布允许清单；读取允许不意味着可发布。 |
| 写入 | 保留现有同源/CSRF 校验。新异步写必须 `operation_id: UUID`；同 owner + 操作类型 + ID 同输入复用结果，不同输入返回 409。 |
| 版本 | 现有 `expected_version`、`expected_revision`、source_hash 各有适用对象，不能混用；新增更新先比较服务端当前版本再事务提交。 |
| 成功 | 同步返回 DTO；创建依路由为 201，异步受理为 202 + 回执，读取为 200。**现有 runMonitorTopic 的真实返回以路由为准，不因本文建议改码。**受理不是执行成功。 |
| 错误 | 继承 `ErrorView(code,message,request_id,details)`；客户端按 code/状态分支，不解析自然语言。401 身份、403 权限、404 不存在或不可访问、409 版本/游标/幂等冲突、422 输入、429 限流、503 不可用。每个接口只声明实际分支。 |
| 分页 | 现有个人记录有 UUID 游标，公开检索有不透明游标；新聚合查询游标绑定筛选、排序、snapshot、权限修订。不要把它们统一解释成 offset。 |
| 时间 | RFC3339 带时区；存 UTC，界面北京时间；`[start,end)`。发布时间、采集、首次发现、处理完成分开，可空时间不得用当前时间填充。 |
| 数值 | 未知为 null，并给原因；0 必须有观测依据。比例给分子、分母、覆盖与窗口，未知不进“负面=0”。 |
| 缓存 | 私有/运营和许可敏感接口 `private, no-store` 或当前更严格策略；新聚合缓存包含权限/许可修订，不缓存令牌。 |
| 超时 | GET 可显式重试；写超时先按原 operation_id 查询，不自动产生新操作键。不要笼统给所有 POST 加自动重试。 |
| 输入限制 | 字符串长度、枚举、日期范围、数组项数、文件大小由 Pydantic 声明，再生成前端类型；前端校验只能帮助用户。 |

## 核心现有流程

| 页面流程 | 现有调用与事务边界 | 结果未知／冲突处理 |
|---|---|---|
| 创建主题 | `previewMonitorTopic` 仅本地规则预览；`createMonitorTopic` 保存主题、版本与停用调度；创建后 paused | 创建未必具备本节新增统一操作账本；保持现有合同，不假定网络重发安全；先查列表和原输入核对 |
| 编辑主题 | `updateMonitorTopic(expected_version)`；规则/来源/周期变化创建不可变版本 | 409 保留草稿并重新读当前版本；旧 Job 继续引用已冻结版本 |
| 运行主题 | `runMonitorTopic(operation_id, source_keys)` 返回每来源 job_ids 或 skip_reason | 展示 source_unavailable/quiet/budget/rate_limited，跳过不是空结果；查已受理任务 |
| 评论采集 | 先 `getContentCommentRunReadiness`，再 `runContentComments`；读取评论与发请求分开 | 验证码/登录/预算停止；取消只阻止后续阶段，不能撤回已发请求 |
| 公开阅读 | public DTO 由当前许可投影读取，公开页不能调用 `/api/contents` 取本人正文 | 收紧许可立即限制 HTML、API、导出、媒体及聚合；缓存不绕过 |
| 刊物阅读 | 目录 → 固定 kind/key 正文；相邻期可独立失败 | 最新入口不是固定版本，引用用固定刊期；撤回引用不复活 |
| 告警保存 | `AlertRuleInput` 包含 operation_id、expected_revision、topic_rule_version 和 target_revision | 任一过期拒绝保存；triggered 只是评估事实，不是邮件已送达 |
| 文档发布 | 保存草稿携 hash/版本；发布完整快照；按操作记录查询结果 | 冲突保留草稿；失败仍读上一快照，不逐文件半发布 |

## 设计稿增量接口（全部为待实现提案）

本节只对已识别缺口给出可评审合同。实现前更新 FastAPI schemas/路由与唯一 schema，再生成客户端；没有授权时不得直接把以下方法加进前端。

### 公开阅读概览

`GET /api/publication/overview?window=24h&as_of=<RFC3339>`；匿名固定公开范围，最大窗口先允许 24h/7d。首次未传 as_of 由服务端冻结窗口；用户传未来或不支持窗口返回 422。

| 输出字段 | 类型与定义 |
|---|---|
| `window_start,window_end,computed_at` | 带时区时间；结束时刻冻结本次查询，不承诺持续变化的精确实时计数 |
| `scope` | 固定 `public_currently_readable`，不是全网 |
| `published_item_count,event_count,independent_source_count` | integer 或 null；范围为当前仍允许公开且在窗口内的去重数据 |
| `coverage` | complete/partial/unknown；来源失败或缺观测必须 partial/unknown |
| `unavailable_metrics` | `{metric,reason}` 数组，便于局部降级 |
| `projection_revision` | 可复核发布快照指纹；不是私人 owner ID |

不增加所谓“全球 AI 信息数”，不把当前页四条热点的来源数标成所有平台。超出容量 503 `publication_aggregation_busy`，失败不返回 0。

### 公开事件分析

`GET /api/publication/stories/{event_id}/analytics?window=24h&bucket=1h`；仅允许 24h/1h、7d/6h 两种初值组合（提案），限制最多 48 个点。事件不存在、不可公开或无可公开成员按公开路径既有 404 语义处理。

| 输出字段 | 规则 |
|---|---|
| `event_id,event_revision,window_start,window_end` | 同一固定事件修订和窗口 |
| `heat` | `{formula_version,points:[{at,value,coverage}],input_revision}`；value 可空，缺口不插值 |
| `sentiment` | 可空；非空含 positive/neutral/negative/unknown/eligible_count、analyzed_count、coverage、contract_version、sample_method |
| `representative_comments` | 最多 5 个合法公开引用，包含 content_id、版本、来源、时间、截断状态、采样理由；不返回私有作者资料 |
| `related_events` | 最多 10 个公开事件引用，关系种类与证据；不得输出私有事件标题 |
| `unavailable_sections` | 热度未生成、样本不足、未授权等产品可读原因；不暴露私有行数 |

私有热度历史已存在，**不能仅改 URL 就当公开接口**。必须重新验证全部输入的公开资格；现有 `content_annotations.relevant` 与 sentiment 不能无条件跨主题聚合。未授权的输入既不进入代表观点，也不进入公开分母。公开聚合身份不借用登录用户 owner。

样本达到何种规模才显示比例由验收基准决定，初值建议至少 20 条独立可读评论、覆盖至少 2 个独立来源；这是待验证提案，不能展示为统计学代表性。规模不足仍可展示原始样本数和局限。

### 首页事件曲线批量读取

`GET /api/publication/stories/analytics?ids=<UUID,...>&window=24h`；静态 analytics 路由必须优先于 `{event_id}` 参数路由注册，避免被当 UUID 解析；最多 20 个去重 ID，只返回当前公开事件的轻量曲线。单项失败返回 `unavailable`，不泄露“不公开但存在”的状态；单页最多一次批量调用。结果与上述 analytics 共享口径，禁止每张卡单独请求历史造成 N+1。

### 平台趋势

`GET /api/publication/trends?platform=x&window=24h&limit=10`；仅开放明确准入且已有授权快照的平台。返回 `{snapshot_at,platform,scope,coverage,entries:[{rank,label,source_url,observed_at,metric,metric_unit}]}`。metric 可空，不同平台量纲不相加。不支持/未配置返回明确能力状态，不能自动借用私人账号或付费 API。先复用 hotlist 快照，只有真实缺数据时才另设计来源。

### 云收藏与个人备注（用户主动启用后的提案）

当前本机模式保持有效。新增云模式必须显式启用；不把浏览器收藏、历史或备注自动上传。

| 方法与路径 | 输入 | 输出与约束 |
|---|---|---|
| `GET /api/reading/bookmarks` | q≤100 字、category、cursor、limit 1–50，默认 20 | `{items,next_cursor,snapshot_at}`；只读本人，内容标题通过当前公开许可重取；不可读仅留 ID 与本人备注 |
| `PUT /api/reading/bookmarks/{content_id}` | operation_id、expected_revision≥0、note≤2000 字、saved=true/false | 当前记录 revision、saved_at、updated_at、deleted_at；新建 expected_revision=0；同键异参 409 |
| `POST /api/reading/bookmarks/import` | operation_id、最多 500 个去重 ID 与可选原收藏时间/备注；仅 ID/笔记，不接受全文 | 202 回执，逐项 accepted/unavailable/conflict；重复读取不重复导入；不可信未来时间降级为服务端时间并标明 |
| `GET /api/reading/operations/{operation_id}` | 当前用户和原操作键 | 原回执或未找到；写结果未知时先查询 |
| `PUT /api/reading/follows/{event_id}` | operation_id、expected_revision、resource_kind:public_story/private_event、following:boolean（scope只由服务端解析） | 当前关注记录；只允许公开事件或本人合法私有事件，但必须区分资源种类和发布范围 |

导出仍按许可，仅导出本人选择的可读链接和本人备注；生成下载前重新校验，不能从缓存重建撤回正文。账户退出清除内存云数据，本机数据是否保留由用户明示选择，不能混到另一个账号。云阅读历史并非此次必需，暂不新增全量历史同步接口。

### 主题运行历史与结果

| 提案接口 | 请求 | 响应 |
|---|---|---|
| `GET /api/topics/{topic_id}/runs` | cursor、limit≤50 | 操作批次列表：operation_id、主题版本、起止、聚合状态、每来源 job_ids/skip_reason、ready_at |
| `GET /api/topics/{topic_id}/runs/{operation_id}` | 受保护路径 | 固定来源版本、窗口、阶段、明确零值与未知值、来源覆盖、错误及恢复入口 |
| `GET /api/topics/{topic_id}/results` | run_operation_id、relevance=direct/weak/irrelevant/insufficient/all、time_state、sort=latest/recommended、cursor、limit≤50 | 固定候选快照、source_time、first_seen、observed、relevance label/理由/证据、分析状态、父链、许可及 next_cursor |
| `GET /api/topics/{topic_id}/series` | start/end（最多 31 天）、bucket=1h/1d、metric=observed/matched/analyzed | 每桶 value、coverage、scope、source 状态；缺口 null，不从当前页 5 条推总量 |

运行列表复用 jobs，但需要完整批次回执，包括“全部来源跳过”的操作；否则无法解释用户点击后的结果。结果推荐排序沿用原 POC 的相关性/时间提案，不添加未经验证的混合分。游标失效 409 `result_snapshot_changed`，返回可重新开始的入口，不静默混页。

### 告警已读

`PUT /api/alerts/evaluations/{evaluation_id}/read-state`：`{operation_id,expected_revision,read:boolean}`；返回 read_at、revision。`GET /api/alerts/read-operations/{operation_id}` 查询原写回执，仅本人；`GET /api/alerts/summary` 返回当前用户可见 triggered 评估的 unread_count、as_of；规则 disabled、发送失败与未读是不同维度。新增状态不会改变阈值、冷却或重新触发消息。事件/规则撤权后计数立即剔除。

## 版本与错误详表（新增接口提案）

| 情况 | HTTP / code | 前端行为 |
|---|---|---|
| 同操作键、同规范输入 | 原状态码/原回执 | 展示原结果，不重复执行 |
| 同操作键、不同输入 | 409 `operation_conflict` | 阻止重复，展示重新核对入口；不能自动换新键 |
| 防重键已过完整回执保留期 | 410 `operation_expired` | 保留精简防重键，拒绝重放；全量核对后由用户发新操作 |
| 乐观锁过期 | 409 `revision_conflict` | 保留本地草稿并读取服务端版本供比较 |
| 固定结果或许可修订变化 | 409 `result_snapshot_changed` | 清空旧游标，明确重新读取 |
| 未登录 | 401 `authentication_required` | 清除旧私有内存结果，安全 returnTo |
| 非本人资源 | 404（沿用服务隐藏资源策略） | 不揭示其他用户存在或数据量 |
| 合法请求但能力未配置 | 503 `capability_unavailable` | 独立模块不可用，展示原因；不能填样本 |
| 输入非法 | 422 `validation_error`（以最终核心错误转换为准） | 关联字段与焦点，保留其他输入 |
| 受理结果未知 | 网络中断，不伪造 HTTP | 查原操作状态，再允许用户决定恢复 |

以上新增 code 是设计候选，开工时须与 [core.errors](../../../../backend/app/core/errors.py) 的既有命名逐项合并，不把文档直接当生成契约。

## 安全与合同验收

对每个新增读取验证匿名/本人/他人/运营身份；对每个新增写入验证 CSRF、同键重放、异参冲突、过期版本、长输入、非法 UUID 和失败后恢复。公开聚合准备混合公开/摘要/撤回/私有样本，确认任何分母、标题、趋势、来源数和海报均不泄漏不可公开材料。由同一后端提交导出 OpenAPI，生成客户端无漂移，再接页面；数据库和接口设计通过不代表允许真实采集或自动推送。
