# 07 趋势与告警

依据：[07 趋势与告警](../requirement/07-趋势与告警.md)；设计：[07 趋势与告警](../design/07-趋势与告警.md)。采用pm-execution的Card / Conversation / Confirmation拆解。本文定义交付工作，不登记进度，不授权提交推送、真实请求或数据库改造。

## 用户故事与工作拆解

### US-07-01 可比趋势

**Card**：作为个人监测用户，当不想盯屏但要知道重要变化时，我希望能够查看可比较的真实趋势，以便及时知道值得关注的进展且少受重复打扰。

**Conversation**：使用FR-07-01及BR-07-01确定范围。需要讨论的边界为“覆盖改变或断采窗口不得解释为事件降温或异常增长”；需对齐的业务输入合同为05事实、06自然窗口、10许可、35目标，不以当前实现是否方便决定取舍。

**Confirmation**：AC-07-01使用固定输入“E首次达标，随后转载三条和一项重要延期更正；规则换版、换目标；覆盖中断”，执行“计算真实24h趋势并对照断采窗口”，核对“帖子/可识别作者/事实/互动独立；断采不可比”，并验证对应反例。界面样本通过与真实业务验收分别记录。

**Conversation**：使用FR-07-02及BR-07-01确定范围。需要讨论的边界为“现有负面或热度增量规则不能冒充首次热点条件”；需对齐的业务输入合同为05事实、06自然窗口、10许可、35目标，不以当前实现是否方便决定取舍。

**Confirmation**：AC-07-02使用固定输入“E首次达标，随后转载三条和一项重要延期更正；规则换版、换目标；覆盖中断”，执行“首次达标后跨规则版本、目标与合并事件重放”，核对“同规范事件及前身只产生一次首次业务提醒”，并验证对应反例。界面样本通过与真实业务验收分别记录。

### US-07-03 交付语义

**Card**：作为个人监测用户，当不想盯屏但要知道重要变化时，我希望能够核对提醒是否被实际收到，以便及时知道值得关注的进展且少受重复打扰。

**Conversation**：使用FR-07-03及BR-07-01确定范围。需要讨论的边界为“提供方接受、模拟发送及站内只读记录不能证明外部实际送达”；需对齐的业务输入合同为05事实、06自然窗口、10许可、35目标，不以当前实现是否方便决定取舍。

**Confirmation**：AC-07-03使用固定输入“E首次达标，随后转载三条和一项重要延期更正；规则换版、换目标；覆盖中断”，执行“发送超时后核对提供方回执及本人接收证据”，核对“unknown先核对；accepted与delivered分开，无回执不伪造送达”，并验证对应反例。界面样本通过与真实业务验收分别记录。

## 工程任务与完成判据

数据合同先行，数据提供方与消费入口可按同一合同独立开发；关联编号不是相互完成前置。任务按下表顺序推进；共享实现步骤只维护一次，各故事通过同序号FR/AC关联。任何发现的设计缺口先补同编号规格，再实施。

| 任务 | 具体交付物 | 输入合同与任务依赖 | 完成判据 |
|---|---|---|---|
| T-07-01 | 可比窗口测量 | 05事实、06自然窗口、10许可、35目标 | 形成可比窗口测量的输入字段、身份/版本、输出与拒绝条件；覆盖FR-07各相关条款，独立审查无冲突 |
| T-07-02 | 三类评估及语义去重 | 前一任务产物与同编号设计 | 三类评估及语义去重能处理固定场景“E首次达标，随后转载三条和一项重要延期更正；规则换版、换目标；覆盖中断”，正常及BR-07-01反例均有可核对结果 |
| T-07-03 | 目标版本验证、消息有效期与送达核对 | 前一任务产物与同编号设计 | 目标版本验证、消息有效期与送达核对接入目标业务流程，能从操作返回稳定资源/回执；没有隐式扩权或外部动作 |
| T-07-04 | AC-07场景、质量检查及独立复核 | 本编号全部故事及适用NFR | 执行“评估首次/事实/增长条件并重放、离开通知静默后发送”；核对“首次按owner+规范事件继承+类型去重，换版本/渠道不再首次；更正按事实版本和更正关系去重；中断覆盖不触发增长”；反例不产生错误业务效果，证据写BACKLOG |

## 验收与发布门槛

本编号交付先满足FR-07和全部AC，质量方法见[11 质量评测与验收](../requirement/11-质量评测与验收.md)。核心需取得相应真实来源/模型/自然窗口/送达证据；辅助功能还须先确认用户价值与批次。读界面、工程样本、数据迁移和真实业务验收互不替代。

每项任务将实际结果、证据范围、未冻结参数、阻塞及下一步写入根目录BACKLOG；没有证据则保持待验收。实施需要的提交/推送与真实外部请求按AGENTS及已有授权单独处理。
