# PLAN001-01 账户与登录真实验收计划

需求：[PRD001 §3](../prd/001-热点舆情监控平台需求.md#3-账户与登录)；设计：[Design001 §9.2](../design/001-热点舆情监控平台总体设计.md#92-公开欢迎页登录与个人数据访问)；BACKLOG 代号 BL-01。计划规则与检查节奏见 [docs/README §5](../README.md#5-plan-规则)。

**状态：延后。** 本人决定（2026-10-05）登录真实验收延后，现有受控实现保持，不新增工作。

## 1. 目标

**让用户用任意一种方式真实登录，并确信自己的数据不会被别人看到。**

三种登录、会话/CSRF、API/SSR 门禁与个人隔离已有实现和受控证据（EV-001-020/021/023），但真实第三方授权和真实收件从未完成，双账户隔离只覆盖了部分资源。

## 3. 范围与非目标

- 范围：真实 GitHub OAuth App、真实认证 SMTP、双账户全资源隔离、会话失效浏览器验证。
- 非目标：组织/租户/角色矩阵、邀请、第三方身份平台；报告推送渠道（见 PLAN006-01）。
