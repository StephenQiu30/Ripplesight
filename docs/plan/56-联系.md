# 56 联系

依据：[56 联系](../requirement/56-联系.md)；设计：[56 联系](../design/56-联系.md)。采用pm-execution的Card / Conversation / Confirmation拆解。本文定义交付工作，不登记进度，不授权提交推送、真实请求或数据库改造。

## 用户故事与工作拆解

### US-56-01 获取已公开联系入口

**Card**：作为公开读者，当获取站点主动公开的联系方式时，我希望能够读取主动公布的联系渠道，以便选择合适渠道主动联系。

**Conversation**：使用FR-56-01及BR-56-01确定范围。需要讨论的边界为“不得从账号、反馈邮箱或日志推断联系方式”；需对齐的业务输入合同为51配置、10许可，不以当前实现是否方便决定取舍。

**Confirmation**：AC-56-01使用固定输入“一个公开渠道、一个隐藏渠道”，执行“打开联系页并使用公开链接”，核对“未配置、隐藏及读取失败分别说明。”，并验证对应反例。界面样本通过与真实业务验收分别记录。
