# 23 模型综合榜

依据：[23 模型综合榜](../requirement/23-模型综合榜.md)；设计：[23 模型综合榜](../design/23-模型综合榜.md)。采用pm-execution的Card / Conversation / Confirmation拆解。本文定义交付工作，不登记进度，不授权提交推送、真实请求或数据库改造。

## 用户故事与工作拆解

### US-23-01 比较模型能力

**Card**：作为模型比较读者，当选择适合任务的模型时，我希望能够在可比轮次下比较模型，以便在共同证据下比较模型。

**Conversation**：使用FR-23-01及BR-23-01确定范围。需要讨论的边界为“不混合不同协议/轮次制造可比排名或首次入榜结论”；需对齐的业务输入合同为26来源、28规则，不以当前实现是否方便决定取舍。

**Confirmation**：AC-23-01使用固定输入“两个同协议轮次和一个改权重轮次，某模型缺分”，执行“切轮次并比较模型”，核对“排名、分项与类型证据同轮可追溯；缺失维度保留未知。”，并验证对应反例。界面样本通过与真实业务验收分别记录。

## 工程任务与完成判据

数据合同先行，数据提供方与消费入口可按同一合同独立开发；关联编号不是相互完成前置。任务按下表顺序推进；共享实现步骤只维护一次，各故事通过同序号FR/AC关联。任何发现的设计缺口先补同编号规格，再实施。

| 任务 | 具体交付物 | 输入合同与任务依赖 | 完成判据 |
|---|---|---|---|
| T-23-01 | 模型别名目录 | 26来源、28规则 | 形成模型别名目录的输入字段、身份/版本、输出与拒绝条件；覆盖FR-23各相关条款，独立审查无冲突 |
| T-23-02 | 排名轮次和共同证据 | 前一任务产物与同编号设计 | 排名轮次和共同证据能处理固定场景“两个同协议轮次和一个改权重轮次，某模型缺分”，正常及BR-23-01反例均有可核对结果 |
| T-23-03 | 可比升降投影 | 前一任务产物与同编号设计 | 可比升降投影接入目标业务流程，能从操作返回稳定资源/回执；没有隐式扩权或外部动作 |
| T-23-04 | AC-23场景、质量检查及独立复核 | 本编号全部故事及适用NFR | 执行“切轮次并比较模型”；核对“可比轮次才显示升降；缺分不补零；共同证据比较并展示缺口”；反例不产生错误业务效果，证据写BACKLOG |

## 验收与发布门槛

本编号交付先满足FR-23和全部AC，质量方法见[11 质量评测与验收](../requirement/11-质量评测与验收.md)。核心需取得相应真实来源/模型/自然窗口/送达证据；辅助功能还须先确认用户价值与批次。读界面、工程样本、数据迁移和真实业务验收互不替代。

每项任务将实际结果、证据范围、未冻结参数、阻塞及下一步写入根目录BACKLOG；没有证据则保持待验收。实施需要的提交/推送与真实外部请求按AGENTS及已有授权单独处理。
