# 51 站点联系配置

依据：[51 站点联系配置](../requirement/51-站点联系配置.md)；设计：[51 站点联系配置](../design/51-站点联系配置.md)。采用pm-execution的Card / Conversation / Confirmation拆解。本文定义交付工作，不登记进度，不授权提交推送、真实请求或数据库改造。

## 用户故事与工作拆解

### US-51-01 管理主动公开的联系方式

**Card**：作为站点管理员，当主动公布可联系渠道时，我希望能够选择联系方式的公开显隐，以便只公布愿意公开的联系方式。

**Conversation**：使用FR-51-01及BR-51-01确定范围。需要讨论的边界为“私有账号信息不自动成为公共联系方式，恶意链接不发布”；需对齐的业务输入合同为56公开联系、10隐私，不以当前实现是否方便决定取舍。

**Confirmation**：AC-51-01使用固定输入“一公开邮箱、一隐藏账号、二维码被取消展示”，执行“保存并预览公开联系页”，核对“保存后公开页面只读已启用且安全的白名单字段。”，并验证对应反例。界面样本通过与真实业务验收分别记录。
