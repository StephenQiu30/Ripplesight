# Plan014：事件候选与稳定身份验证

## 范围与前置

本卡承接 [PRD004](../prd/004-事件与热度需求.md) 的 FR-004-001，贡献 AC-004-001 中的候选、模型确认、稳定身份与幂等证据。技术前置是 [Design002](../design/002-信息获取主链路设计.md) 的内容版本、有效相关标注及阅读产物，以及 [Design004](../design/004-事件与热度设计.md) 的事件领域与跨领域 DTO 合同；不依赖提前编写的分析、阅读、人工修订、热度或页面细卡。

`depends_on: 009` 是真实产品样本的前置条件：009通过后才使用 M1 已验收的真实三平台同事件与近似反例进行产品核对。受控验证与输入准备可以先行，不需要等待 M1 整个观察期；本人账号 B 站仅在 M2 正式验收通过后纳入，公开热榜不能代替本人账号来源验收。

候选与稳定身份已有受控实现，历史技术证据见 [Acceptance004 EV-004-001/002](../acceptance/004-事件与热度验收.md)。当前真实三平台样本、真实模型确认和产品人工复核均未验收。`HOTKEY_EVENTS_CLUSTER_ENABLED=false` 保持默认关闭，真实 Codex 请求继续暂停；本次文档整理不启动扫描、Worker、来源或模型。

## 现行合同引用

既有关键 ID 保持含义，具体参数、字段和事务只维护在 Design004，不重写实施历史：

- `SPEC-014-DATA-001—004`：按 Design004 §4核对输入身份、来源与时间依据、候选指纹、稳定事件和成员版本、唯一当前归属以及确认时的并发与人工修订保护。标题相似度只产生候选，不能自动等同事件成立。
- `SPEC-014-JOB-001/002`：按 Design004 §6核对槽扫描、新建与追加候选、模型确认、预算、输入上限、硬截止与重放；模型调用在数据库事务外，结果与输入版本可审计。
- 已完成的 `CHK-014-101`、`CHK-014-102`、历史 G0—G4及 R1—R5/RG只作为 Acceptance 的受控证据引用，不复制失败日志、测试数、提交和通用阶段清单，不据此关闭真实产品条件。

## 下一步

1. 只读核对实际代码、Schema、运行库与模型开关，以及可用内容版本、相关标注、来源和时间依据；列明尚无真实证据的输入条件，不拼接不同库或窗口的样本。
2. 复用现有受控证据；若发现代码漂移或具体缺口，按 Design004 合同明确本轮变更和失败场景，再做必要回归。重点核对新建与追加候选、重复确认、人工修订冲突、输入变化失败、槽内补扫和预算拒绝，不调用真实模型。
3. 准备正式取证所需的三平台同事件及近似反例清单、输入版本与人工判定方法。009通过、真实样本条件齐备并获准恢复真实模型后，再在同一冻结环境核对候选、确认结果、成员与重放，证据写入 Acceptance004。

当前核对入口为 `backend/app/events/{models,schemas,services,clustering}.py`、`backend/app/analysis/services.py`、`backend/app/worker/scheduler.py`，以及 `backend/tests/unit/test_event_clustering.py`、`backend/tests/unit/test_scheduler.py`、`backend/tests/integration/test_event_clustering.py`。这些是已有产物；只有发现实际问题才限定变更文件，不为验证重新创建模块或执行 DDL。

## 未通过条件与结论边界

- [ ] `CHK-014-103`：009通过后，以真实三平台同事件和不相关近似反例进行人工复核，保存输入版本、候选、ai_call、事件 ID、成员与拒绝原因，并核对重复确认和重放。高相似度、合成样本或单次模型输出不能单独满足该条件。

历史 `CHK-014-G5-001` 是上述真实样本核对，不另建重复清单；`CHK-014-G6-001` 和 `AC-004-001` 的完整产品结论仍未通过。人工合并/拆分、可复算热度与可操作事件页面继续由 PRD004/Design004 定义，按实际缺口后续排期，不作为本卡已经实现或通过的能力。事件数据进入报告前仍须在 M3 Acceptance 汇合完整产品证据。

故障时暂停事件候选任务，保留原内容与候选证据，不把热榜快照直接转为事件；涉及 Schema 或保留库时继续按 PROJECT 的新库初始化与同版本恢复门槛执行。本卡保持未完成，受控技术通过不改变真实三平台未验结论。
