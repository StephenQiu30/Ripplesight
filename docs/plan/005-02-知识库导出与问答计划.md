# PLAN005-02 知识库导出与问答计划

需求：[PRD005](../prd/005-报告与知识库需求.md) FR-005-006—007；设计：Design005。计划规则见 [docs/README §5](../README.md#5-plan-规则)。

## 1. 目标

**让用户在自己的 Obsidian 里找到所有关注成果，并能提问、拿到有出处的回答。**

现状：`knowledge.export` 只导出日报；周报、事件、精选帖子、主题对象导出和检索/问答未形成完整结果。

## 2. 可度量结果

| # | 结果 | 基线 | 目标值 | 验收依据 | 反作弊/反向指标 |
|---|---|---|---|---|---|
| R1 | 可安全导出到 `HotKey/` 的对象类型 | 1/5（日报） | 4/5：日报、周报、主题、精选帖子（事件待 M3） | AC-005-006、008 | 用户“我的笔记”区块被覆盖的次数为 0 |
| R2 | 重导出与 vault 只读场景 | 未验 | 每类对象各 1 次，失败可见且不回滚报告 | AC-005-006 | 悬空双链数为 0 |
| R3 | 资料检索可用（只读当前 owner 获准内容） | 0 | Web 与 CLI 各可检索，跨账户结果 0 | FR-005-007 | 以扩展存在代替可查询不计 |
| R4 | 10 个问题至少 8 个回答正确且出处可打开 | 0 | ≥8/10 | AC-005-004 | 资料外问题须明说不足 |
