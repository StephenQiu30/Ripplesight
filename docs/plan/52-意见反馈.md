# 52 意见反馈

依据：[52 意见反馈](../requirement/52-意见反馈.md)；设计：[52 意见反馈](../design/52-意见反馈.md)。采用pm-execution的Card / Conversation / Confirmation拆解。本文定义交付工作，不登记进度，不授权提交推送、真实请求或数据库改造。

## 用户故事与工作拆解

### US-52-01 主动提交问题反馈

**Card**：作为反馈提交者，当主动报告问题而不泄露多余信息时，我希望能够主动提交反馈并核对受理，以便清楚报告问题且不泄露多余信息。

**Conversation**：使用FR-52-01及BR-52-01确定范围。需要讨论的边界为“重复提交不制造多份反馈，越权附件和秘密不得泄漏”；需对齐的业务输入合同为10隐私、49处理，不以当前实现是否方便决定取舍。

**Confirmation**：AC-52-01使用固定输入“同operation重复提交，附件超限，正文草稿已填写”，执行“提交、修正附件并核对受理”，核对“不自动截屏，限制和隐私用途事先说明，失败保留草稿。”，并验证对应反例。界面样本通过与真实业务验收分别记录。
