# 34 监控主题详情

依据：[34 监控主题详情](../requirement/34-监控主题详情.md)；设计：[34 监控主题详情](../design/34-监控主题详情.md)。采用pm-execution的Card / Conversation / Confirmation拆解。本文定义交付工作，不登记进度，不授权提交推送、真实请求或数据库改造。

## 用户故事与工作拆解

### US-34-01 通过链接继续指定主题

**Card**：作为个人监测用户，当用链接接续指定主题时，我希望能够通过稳定链接回到指定主题，以便从链接接续同一个主题任务。

**Conversation**：使用FR-34-01及BR-34-01确定范围。需要讨论的边界为“失效或他人链接不得回落并显示另一个主题的结果”；需对齐的业务输入合同为32唯一工作区、10权限，不以当前实现是否方便决定取舍。

**Confirmation**：AC-34-01使用固定输入“本人主题深链接、他人ID和已归档主题”，执行“直接打开、刷新和回退”，核对“深链接选中资源与正文、编辑及运行回执一致。”，并验证对应反例。界面样本通过与真实业务验收分别记录。

本编号交付先满足FR-34和全部AC，质量方法见[11 质量评测与验收](../requirement/11-质量评测与验收.md)。核心需取得相应真实来源/模型/自然窗口/送达证据；辅助功能还须先确认用户价值与批次。读界面、工程样本、数据迁移和真实业务验收互不替代。
