# PLAN005-01 个人日周报真实周期计划

需求：[PRD005](../prd/005-报告与知识库需求.md) FR-005-001、003—005、012；设计：Design005 §3.2。计划规则见 [docs/README §5](../README.md#5-plan-规则)。

## 1. 目标

**登录用户每天早上和每周一都能收到一份自己关注的、每个数字和引用都能核对的报告。**

现状（EV-001-025、026）：两个账户已有真实 HN 材料、模板日报与周报存档及跨账户隔离证据；周报只是缺稿存档（上周无历史日报）；Scheduler 08:00/周一 08:00 已接入。

- 宿主 Worker 依赖 Kafka localhost 监听，开机恢复未验；中断会使 R1 重新计数。
