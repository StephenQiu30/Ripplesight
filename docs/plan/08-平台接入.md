# 08 平台接入

依据：[08 平台接入](../requirement/08-平台接入.md)；设计：[08 平台接入](../design/08-平台接入.md)。采用pm-execution的Card / Conversation / Confirmation拆解。本文定义交付工作，不登记进度，不授权提交推送、真实请求或数据库改造。

## 用户故事与工作拆解

### US-08-01 来源能力契约

**Card**：作为个人监测用户，当要知道平台是否真的支持所需查询时，我希望能够查明来源具体能力，以便按真实能力选择合法免费来源。

**Conversation**：使用FR-08-01及BR-08-01确定范围。需要讨论的边界为“来源名称或适配器存在不能证明全部能力可用”；需对齐的业务输入合同为00执行边界、10秘密管理，不以当前实现是否方便决定取舍。

**Confirmation**：AC-08-01使用固定输入“来源只有热榜与详情，搜索/评论未知；另一候选费用不明”，执行“预览来源能力并请求启用”，核对“未知和不支持明确；能力附依据及核对时间。”，并验证对应反例。界面样本通过与真实业务验收分别记录。

### US-08-02 准入门槛

**Card**：作为个人监测用户，当要知道平台是否真的支持所需查询时，我希望能够核对费用、许可和账号准入，以便按真实能力选择合法免费来源。

**Conversation**：使用FR-08-02及BR-08-01确定范围。需要讨论的边界为“本轮文档工作不解冻平台或授权真实请求”；需对齐的业务输入合同为00执行边界、10秘密管理，不以当前实现是否方便决定取舍。

**Confirmation**：AC-08-02使用固定输入“来源只有热榜与详情，搜索/评论未知；另一候选费用不明”，执行“预览来源能力并请求启用”，核对“未获准、计费不明、验证码、失效账号或撤权均拒绝新请求。”，并验证对应反例。界面样本通过与真实业务验收分别记录。

### US-08-03 目标与替代

**Card**：作为个人监测用户，当要知道平台是否真的支持所需查询时，我希望能够逐平台核对国内POC与最终覆盖目标，以便按真实能力选择合法免费来源。

**Conversation**：使用FR-08-03及BR-08-01确定范围。需要讨论的边界为“B站/HN或热榜通过不能勾销海外目标的能力缺口”；需对齐的业务输入合同为00执行边界、10秘密管理，不以当前实现是否方便决定取舍。

**Confirmation**：AC-08-03使用固定输入“来源只有热榜与详情，搜索/评论未知；另一候选费用不明”，执行“预览来源能力并请求启用”，核对“来源受限时说明能够回答的问题与缺口，用户可选已准入路径。”，并验证对应反例。界面样本通过与真实业务验收分别记录。

## 工程任务与完成判据

数据合同先行，数据提供方与消费入口可按同一合同独立开发；关联编号不是相互完成前置。任务按下表顺序推进；共享实现步骤只维护一次，各故事通过同序号FR/AC关联。任何发现的设计缺口先补同编号规格，再实施。

| 任务 | 具体交付物 | 输入合同与任务依赖 | 完成判据 |
|---|---|---|---|
| T-08-01 | 能力证据版本 | 00执行边界、10秘密管理 | 形成能力证据版本的输入字段、身份/版本、输出与拒绝条件；覆盖FR-08各相关条款，独立审查无冲突 |
| T-08-02 | 准入矩阵 | 前一任务产物与同编号设计 | 准入矩阵能处理固定场景“来源只有热榜与详情，搜索/评论未知；另一候选费用不明”，正常及BR-08-01反例均有可核对结果 |
| T-08-03 | 稳定身份命名空间及国内平台覆盖清单 | 前一任务产物与同编号设计 | 稳定身份命名空间及国内平台覆盖清单接入目标业务流程，能从操作返回稳定资源/回执；没有隐式扩权或外部动作 |
| T-08-04 | AC-08场景、质量检查及独立复核 | 本编号全部故事及适用NFR | 执行“预览来源能力并请求启用”；核对“搜索不能标ready；费用不明或未获准拒绝启用；保存能力说明不隐式探测”；反例不产生错误业务效果，证据写BACKLOG |

## 验收与发布门槛

本编号交付先满足FR-08和全部AC，质量方法见[11 质量评测与验收](../requirement/11-质量评测与验收.md)。核心需取得相应真实来源/模型/自然窗口/送达证据；辅助功能还须先确认用户价值与批次。读界面、工程样本、数据迁移和真实业务验收互不替代。

每项任务将实际结果、证据范围、未冻结参数、阻塞及下一步写入根目录BACKLOG；没有证据则保持待验收。实施需要的提交/推送与真实外部请求按AGENTS及已有授权单独处理。
