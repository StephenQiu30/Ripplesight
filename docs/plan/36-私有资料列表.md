# 36 私有资料列表

依据：[36 私有资料列表](../requirement/36-私有资料列表.md)；设计：[36 私有资料列表](../design/36-私有资料列表.md)。采用pm-execution的Card / Conversation / Confirmation拆解。本文定义交付工作，不登记进度，不授权提交推送、真实请求或数据库改造。

## 用户故事与工作拆解

### US-36-01 查找本人采集资料

**Card**：作为个人监测用户，当寻找采集到的相关材料时，我希望能够检索并排序本人材料，以便找到本人需要的相关资料。

**Conversation**：使用FR-36-01及BR-36-01确定范围。需要讨论的边界为“未分析不得等同无关，分页与资源替换不得泄漏他人计数”；需对齐的业务输入合同为03身份、09排序、10许可，不以当前实现是否方便决定取舍。

**Confirmation**：AC-36-01使用固定输入“第二页有最相关新材料，另有缺时刻和旧高互动材料”，执行“检索按相关性/时效排序并主动补充合法材料”，核对“筛选覆盖本人可读集合，原始身份/版本和发现路径可追溯。”，并验证对应反例。界面样本通过与真实业务验收分别记录。

### US-36-02 主动补充合法材料

**Card**：作为个人监测用户，当寻找采集到的相关材料时，我希望能够主动补充合法证据，以便找到本人需要的相关资料。

**Conversation**：使用FR-36-02及BR-36-01确定范围。需要讨论的边界为“URL可访问不代表通用浏览器采集解冻，读取列表不能自动采集”；需对齐的业务输入合同为03身份、09排序、10许可，不以当前实现是否方便决定取舍。

**Confirmation**：AC-36-02使用固定输入“第二页有最相关新材料，另有缺时刻和旧高互动材料”，执行“检索按相关性/时效排序并主动补充合法材料”，核对“准入、预算、重定向与范围校验后受理并回到原文。”，并验证对应反例。界面样本通过与真实业务验收分别记录。

## 验收与发布门槛

本编号交付先满足FR-36和全部AC，质量方法见[11 质量评测与验收](../requirement/11-质量评测与验收.md)。核心需取得相应真实来源/模型/自然窗口/送达证据；辅助功能还须先确认用户价值与批次。读界面、工程样本、数据迁移和真实业务验收互不替代。

每项任务将实际结果、证据范围、未冻结参数、阻塞及下一步写入根目录BACKLOG；没有证据则保持待验收。实施需要的提交/推送与真实外部请求按AGENTS及已有授权单独处理。
