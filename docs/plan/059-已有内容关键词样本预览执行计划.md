# Plan059：已有内容关键词样本预览

## 1. 范围与依赖

实现 FR-002-009/AC-002-010 的已有持久样本预览部分，沿用 FR-002-008 的三组词和 ASCII 整词判断。当前 Plan058 的同日外采预算已经耗尽；本卡只读取现有内容，不改变预算或其 A/B 范围。逐来源原生/本地条件转换及能力矩阵由 FR-002-010/011 的后续合同承接，本卡不关闭全部 FR-002-009/AC-002-010。

主责 content：仅本领域 ORM 查询，通过 monitors 的规范化/判断函数处理草稿规则；API 不执行 SQL。无 DDL、模型、Job、调度或预算变更。既有人工标题 `/api/topics/preview` 保持兼容。

## 2. 文件与契约

修改 `backend/app/content/schemas.py` 定义严格输入/输出；`content/services.py` 负责只读事务与已有生命周期权限；`api/routers/monitor_topics.py` 注入既有 ContentService。修改 `frontend/src/components/monitors/topic-rule-preview.tsx`，它已经被新建与编辑两个页面复用；两个调用处传入当前选择的 sourceKeys。仅由运行 OpenAPI 生成 `frontend/src/api/`。测试新增 `backend/tests/unit/test_sample_preview_contract.py`、扩展 `backend/tests/integration/test_content_records.py` 并新增 `frontend/src/components/monitors/topic-rule-preview.test.tsx`。

| SPEC | 固定合同 |
|---|---|
| SPEC-059-API-001 | `POST /api/topics/sample-preview`，operation_id=`previewMonitorTopicSamples`，当前 owner 会话+CSRF，200 类型化输出、401/403/422/500 ErrorView，Cache-Control=no-store。输入继承现有三词组、source_keys≤32（空表示 owner 全部已有来源）；不接受 owner、topic、版本、外部 URL 或路径。 |
| SPEC-059-DATA-001 | 固定服务端 UTC `[now-7天,now)` 观察窗；按 owner/来源选择、非评论的 post/webpage、生命周期仍可读的含文本观察过滤，每身份取最新含文本可读观察，再按 observed_at/received_at/id 倒序取最多20项+1判断截断。不先筛命中，保留未命中/排除样本，避免伪造相关率。未来/过旧/不可读观察不返回，空窗只表示预览证据不足。 |
| SPEC-059-RULE-001 | 复用 normalize/evaluate_monitor_rules，对保存的标题+正文做本地判断，返回规范化草稿规则与 matched_any/matched_all/excluded_by。区分草稿规则与持久内容版本；标题/正文仅返回短摘录并标其截断，判断使用完整已保存文字，不表示源站完整正文。每项有内容/观察/内容版本 ID、来源、发布时间（可空）与观察时间，可进入内部作品页。 |
| SPEC-059-UI-001 | 预览 Dialog 中添加“预览已采集内容”，仅读当前表单词组/来源；保留人工标题检查。展示最近7天、实际样本数/最多20/截断、草稿判断、匹配/未匹配/排除原因及内容入口。空/加载/失败/会话失效可辨；输入变更和新请求时清除旧结果，防止草稿变更后误用旧解释。Dialog 用 shadcn/Radix，布局命名尺度，桌面/390px可操作。 |
| SPEC-059-SEC-001 | 不保存主题/规则、创建 Job/Outbox/AI call/请求预算；复用 readable_resource_ids_query 的 owner/保留期/删除控制。只读隔离真实库测试证明越权/过期不返回；真实旧样本核对零外采、零模型、零Job副作用，不当作当日真实采集证据。 |
