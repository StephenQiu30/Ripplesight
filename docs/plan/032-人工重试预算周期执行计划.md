# Plan 032：人工重试预算周期

## 交付与现状

修复首次失败两分钟后人工重试立即耗尽采集时间的问题；FR-002-002、NFR-001-112 对应 AC-002-007。周期与账本已有受控实现，剩余真实重试和恢复在本卡取证，短窗汇入058、正式窗口归009。技术前置是 Design001/002 的版本化来源策略、Job/attempt、预算与备份恢复合同，不依赖已删除的配置计划。候选 stash 只作差异参考，不能整体恢复。

## 实施规格

| SPEC | 数据、行为和文件 |
|---|---|
| SPEC-032-DATA-001 | `backend/app/jobs/models.py`、`jobs/schemas.py`、`backend/database/schema.sql` 为 Job 保存 `collection_cycle_no`、`collection_cycle_started_at`、`collection_cycle_requests_sent`，为 JobAttempt 保存该周期号及 `queued_at`。初始周期 0/空时间/0 请求，首次领取周期 1；人工重试受理只用 `defer_reason=manual_retry` 标记待开新周期，下一次成功领取时原子递增、取当前时间并把周期请求数清零。Job 累计 `requests_sent` 永不清零，作为请求尝试与预算预留唯一 ID 的序号；单周期次数仅用于本轮请求上限。`jobs.started_at` 永远保留首次启动；`queued_at` 保存本次到期可领取的时刻，排队等待不消耗尚未开始的新周期。 |
| SPEC-032-JOB-001 | `jobs/services.py` 的人工 retry 事务校验失败状态、owner、执行版本、来源开关和每日预算；重复 retry 请求只能有一个待重试状态/Outbox。`jobs/execution.py` 领取与 `content/discovery_execution.py`、`content/comments_execution.py`、`content/hotlist_execution.py` 的截止计算消费周期时钟。自动重试、429 重排、租约失效重放不新开周期。 |
| SPEC-032-OBS-001 | 现有 `POST /api/jobs/{job_id}/retry` 与 `GET /api/jobs/{job_id}` 增加只读周期/attempt 时间信息，保留 operation_id；页面 `frontend/src/app/jobs/[jobId]/components/job-detail.tsx` 区分排队等待、当前尝试、整单历时、周期剩余额度，未开始用空值。每日/全局请求实耗不回退、不返还。 |

## Checklist 与验收用例

- [x] CHK-032-001 → DATA-001：周期起点需真实行锁与 JobAttempt 事务，故失败时钟落在 `backend/tests/integration/test_job_reliability.py`；首次失败后 +120 秒受理、再排队 +60 秒领取，新周期从领取开始，首次时间不变。旧 Schema 上先复现缺列失败，现行隔离库已通过。
- [x] CHK-032-002 → JOB-001：`backend/tests/integration/test_job_reliability.py` 验证并发点击、受理事务回滚、租约过期恢复、自动/限流重排、旧租约回写；周期最多递增一次，旧写被拒绝。
- [x] CHK-032-003 → OBS-001：`backend/tests/integration/test_hotlist_persistence.py` 在同一 Job/operation 下核对来源/全局实耗累计和两类零额度拒绝排队，`job-detail.test.tsx` 核对三个时长、未开始和待领取；隔离浏览器核对桌面/390px。原计划指向 `test_resource_budgets.py` 的跨事务用例由热榜持久化集成测试承载。
- [ ] CHK-032-004 → AC-002-007：既有获准来源记录一次首次失败后的人工重试真实请求、attempt、内容与账本；不人为向外部平台制造限流。自动重试受控证明与人工重试真实证据分别保留。

按实际变更运行 B/C/F 及针对测试；DDL 只在隔离新库验证，保留库按 Design001/PROJECT 的同版本备份恢复合同执行。已有受控证据见 Acceptance002 EV-002-013，不复制旧 G0—G6 阶段表。历史并发、预算零和旧租约用例缺各自实施前失败记录；热榜本身 Kafka 重放与保留库适配仍待核对，这些未通过边界不因表格合并而关闭。

任何重复扣费、返还日预算或旧租约写入即失败。故障时暂停受影响任务，保留周期与账本，不删除重建失败 Job。CHK-032-004 和 AC-002-007 保持未通过，连续窗口由009判断。
