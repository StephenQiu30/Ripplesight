# 37 私有资料与评论

依据：[37 私有资料与评论](../requirement/37-私有资料与评论.md)；设计：[37 私有资料与评论](../design/37-私有资料与评论.md)。采用pm-execution的Card / Conversation / Confirmation拆解。本文定义交付工作，不登记进度，不授权提交推送、真实请求或数据库改造。

## 用户故事与工作拆解

### US-37-01 理解材料与讨论上下文

**Card**：作为个人监测用户，当从原帖读到评论上下文并持续跟踪时，我希望能够读取原帖与评论父链，以便理解上下文并继续跟踪讨论。

**Conversation**：使用FR-37-01及BR-37-01确定范围。需要讨论的边界为“缺父不补造，已采数不等于平台总评论数”；需对齐的业务输入合同为02评论跟踪、03关系、09上下文，不以当前实现是否方便决定取舍。

**Confirmation**：AC-37-01使用固定输入“旧帖有根评论20/总数100、回复5及一条缺父评论”，执行“读父链、展开分页、刷新讨论并加入/退出跟踪”，核对“对象身份、正文版本、来源与时间可核对；短回复结合实际父链解释。”，并验证对应反例。界面样本通过与真实业务验收分别记录。

### US-37-02 核对分析并主动刷新

**Card**：作为个人监测用户，当从原帖读到评论上下文并持续跟踪时，我希望能够主动分析、刷新或跟踪讨论，以便理解上下文并继续跟踪讨论。

**Conversation**：使用FR-37-02及BR-37-01确定范围。需要讨论的边界为“阅读材料不触发刷新，分析未知不当中性或不相关”；需对齐的业务输入合同为02评论跟踪、03关系、09上下文，不以当前实现是否方便决定取舍。

**Confirmation**：AC-37-02使用固定输入“旧帖有根评论20/总数100、回复5及一条缺父评论”，执行“读父链、展开分页、刷新讨论并加入/退出跟踪”，核对“分析版本与实际输入绑定；刷新独立受理、预算及停止检查。”，并验证对应反例。界面样本通过与真实业务验收分别记录。

## 验收与发布门槛

本编号交付先满足FR-37和全部AC，质量方法见[11 质量评测与验收](../requirement/11-质量评测与验收.md)。核心需取得相应真实来源/模型/自然窗口/送达证据；辅助功能还须先确认用户价值与批次。读界面、工程样本、数据迁移和真实业务验收互不替代。

每项任务将实际结果、证据范围、未冻结参数、阻塞及下一步写入根目录BACKLOG；没有证据则保持待验收。实施需要的提交/推送与真实外部请求按AGENTS及已有授权单独处理。
