# PLAN008-02 完整业务真实验收计划

需求：[PRD008](../prd/008-完整业务需求.md) FR-008-001—009；设计：Design008。BACKLOG 代号 BL-02。参考能力的实现另见 [PLAN008-01](008-01-参考能力落地计划.md)。计划规则见 [docs/README §5](../README.md#5-plan-规则)。

## 1. 目标

**让完整业务的每项功能都由真实输入和持久结果支撑，而不是只停留在代码与配置。**

现状：原始公开资讯已接通两个真实来源；六类来源、模型榜/公告、月报、媒体、运营与恢复的真实验证未闭。
