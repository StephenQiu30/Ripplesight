# PLAN003-01 本人 B 站试点恢复计划

需求：[PRD003](../prd/003-本人账号B站试点需求.md)；设计：Design003。计划规则见 [docs/README §5](../README.md#5-plan-规则)。

## 1. 目标

**在不触发任何风控的前提下，让本人能从关注词读到 B 站视频和同轮一级评论。**

现状：MediaCrawler 固定补丁 1bd07bc 修复后真实采集/恢复未通过，来源开关关闭。
