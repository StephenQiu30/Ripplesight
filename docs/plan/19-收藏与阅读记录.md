# 19 收藏与阅读记录

依据：[19 收藏与阅读记录](../requirement/19-收藏与阅读记录.md)；设计：[19 收藏与阅读记录](../design/19-收藏与阅读记录.md)。采用pm-execution的Card / Conversation / Confirmation拆解。本文定义交付工作，不登记进度，不授权提交推送、真实请求或数据库改造。

## 用户故事与工作拆解

### US-19-01 保留与找回线索

**Card**：作为读者，当回找事件资讯评论或日报并保存个人理解时，我希望能够收藏、备注并检索多类型线索，以便回找线索和自己的理解。

**Conversation**：使用FR-19-01及BR-19-01确定范围。需要讨论的边界为“取消收藏、存储损坏或权限撤回不留下可导出的受限正文”；需对齐的业务输入合同为10许可、18阅读位置，不以当前实现是否方便决定取舍。

**Confirmation**：AC-19-01使用固定输入“正常本机存储中有两条可读一条撤权收藏，其中两条被选中；另设存储损坏反例”，执行“全收藏搜索、批量取消、选中Markdown导出并刷新”，核对“收藏以身份为键，备注纯文本，存储方式和容量限制公开可知。”，并验证对应反例。界面样本通过与真实业务验收分别记录。

### US-19-02 导出选择的阅读资料

**Card**：作为读者，当回找事件资讯评论或日报并保存个人理解时，我希望能够导出自己选中的许可资料，以便回找线索和自己的理解。

**Conversation**：使用FR-19-02及BR-19-01确定范围。需要讨论的边界为“不能扩大为全库导出、附带未选择条目或默认云同步”；需对齐的业务输入合同为10许可、18阅读位置，不以当前实现是否方便决定取舍。

**Confirmation**：AC-19-02使用固定输入“正常本机存储中有两条可读一条撤权收藏，其中两条被选中；另设存储损坏反例”，执行“全收藏搜索、批量取消、选中Markdown导出并刷新”，核对“文件只含所选且当前可读的信息；部分不可读明确说明。”，并验证对应反例。界面样本通过与真实业务验收分别记录。
