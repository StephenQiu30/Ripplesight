# 29 登录与验证注册

需求依据：[29 登录与验证注册](../requirement/29-登录与验证注册.md)；工作拆解：[29 登录与验证注册](../plan/29-登录与验证注册.md)。以下为目标设计，未据此改变代码或业务数据库；共享架构、事务及选型原则见[00 产品目标与边界](../design/00-产品目标与边界.md)。

## 设计目标与业务流程

账号密码、邮件验证、GitHub等方式按实际配置显隐；先验证身份再注册，会话可撤销。验证过期、一次使用、重发、安全returnTo明确；关弹窗继续阅读并恢复焦点。

1. **验证身份并安全进入**（FR-29-01）：有效验证后建立可撤销会话；关闭登录仍能继续公开阅读。

## 状态、交互与失败恢复

未配置方式不伪装可用，失败不泄漏账号存在性。验收场景：有效、过期、已使用challenge与站外returnTo；公开文章仍打开；验证注册、重复提交、退出或关闭弹窗后，仅有效身份建会话；站外跳转拒绝；关闭仍可阅读；凭据变化撤销旧会话。

界面先呈现完成任务所需的事实与限制，再给出动作和回执。遵循[11 质量评测与验收](../design/11-质量评测与验收.md#共享状态与反馈)的共用状态、焦点和过期响应规则；无外部读取的静态内容不套远程加载状态。数量、分页、排列由内容规模和性能基线决定，不继承旧固定页数/栏宽。

## 数据库设计

目标关系模型；字段、键、查询索引和生命周期由同编号需求推导。类型为候选表达，正式DDL需验证枚举、长度、外键、容量、迁移与回退；本轮不执行建表。共享owner复合引用和当前版本指针规则见00。

### `accounts`

用途：个人身份与会话主体。

| 字段 | 候选类型 | 可空 | 业务含义与规则 |
|---|---|---|---|
| id | UUID | 否 | 主键 |
| login_name | VARCHAR(128) | 否 | 规范化登录名；唯一 |
| identity_summary | JSONB | 否 | account_identities的可重建只读展示投影，不是唯一身份/验证真源 |
| password_digest | TEXT | 是 | 密码哈希；未完善身份时可空 |
| credential_version | BIGINT | 否 | >=1；凭据变更使旧会话失效 |
| status | VARCHAR(24) | 否 | active、disabled |
| created_at | TIMESTAMPTZ | 否 | 创建时间 |
| updated_at | TIMESTAMPTZ | 否 | 最后修改 |

键与完整性：PK(id)；UNIQUE(login_name)；第三方身份由account_identities的provider/subject唯一键与原子绑定事务保证。

查询与索引候选：login_name唯一索引；禁止用未验证身份查询返回敏感字段。 索引用真实查询基线复核，不能把索引存在当性能达标。

生命周期：停用立即阻止新会话；账号删除须按保留政策处理其拥有数据。

### `sessions`

用途：可撤销登录会话，避免把令牌明文当持久身份。

| 字段 | 候选类型 | 可空 | 业务含义与规则 |
|---|---|---|---|
| id | UUID | 否 | 主键 |
| account_id | UUID | 否 | 身份主体 |
| token_digest | BYTEA | 否 | 随机令牌摘要；唯一 |
| csrf_digest | BYTEA | 否 | 写请求校验摘要 |
| credential_version | BIGINT | 否 | 受理时凭据版本 |
| expires_at | TIMESTAMPTZ | 否 | 有效期终点 |
| revoked_at | TIMESTAMPTZ | 是 | 撤销时间 |
| created_at | TIMESTAMPTZ | 否 | 会话建立时间 |

键与完整性：PK(id)；FK(account_id)→accounts；UNIQUE(token_digest)；expires_at>created_at。

查询与索引候选：account_id；未撤销会话expires_at部分索引。 索引用真实查询基线复核，不能把索引存在当性能达标。

生命周期：过期/撤销拒绝读写；删除会话不能伪装撤销全部凭据版本。

### `account_identities`

用途：规范化身份到账户唯一映射，避免并发注册或绑定到不同账户。

| 字段 | 候选类型 | 可空 | 业务含义与规则 |
|---|---|---|---|
| id | UUID | 否 | 身份映射 |
| account_id | UUID | 否 | 所属账户 |
| provider | VARCHAR(32) | 否 | password_login、email、github等已配置提供者 |
| subject | VARCHAR(512) | 否 | 按provider规范化的稳定身份；外部OAuth用已验证provider subject，不用可变昵称 |
| verified_at | TIMESTAMPTZ | 否 | 完成该身份验证时间 |
| verification_reference | JSONB | 否 | 脱敏验证依据，无token/验证码 |
| revoked_at | TIMESTAMPTZ | 是 | 解除绑定，不回收已用subject导致越权 |
| created_at | TIMESTAMPTZ | 否 | 建立时间 |

键与完整性：PK(id)；UNIQUE(provider,subject)；FK(account_id)→accounts(id)；同身份冲突必须核对本人而非静默换绑。

查询与索引候选：account_id,provider；provider,subject；按真实查询基线复核。

生命周期：provider规范化策略版本化，邮箱/GitHub/登录名不混同；密码哈希在accounts，登录名自身也规范化唯一。解绑是否释放subject须独立验证恢复安全，不默认复用。

### `identity_challenges`

用途：一次性验证及OAuth状态消费，可在尚无账户时存在。

| 字段 | 候选类型 | 可空 | 业务含义与规则 |
|---|---|---|---|
| id | UUID | 否 | 挑战身份 |
| account_id | UUID | 是 | 绑定/改凭据时必填本人，注册前可空 |
| provider | VARCHAR(32) | 否 | 已配置验证方式 |
| subject_digest | BYTEA | 否 | 待验证规范身份摘要，不含challenge秘密 |
| purpose | VARCHAR(32) | 否 | register、login、bind、credential_change |
| challenge_digest | BYTEA | 否 | 随机验证码/状态摘要，仅原始生成一次供验证流程使用 |
| browser_nonce_digest | BYTEA | 否 | 绑定发起会话/浏览器；防止跨会话重放 |
| attempt_count | INTEGER | 否 | >=0 |
| max_attempts | INTEGER | 否 | >0；达到上限失效 |
| expires_at | TIMESTAMPTZ | 否 | 到期拒绝 |
| consumed_at | TIMESTAMPTZ | 是 | 只成功消费一次 |
| created_at | TIMESTAMPTZ | 否 | 发起时刻 |

键与完整性：PK(id)；UNIQUE(challenge_digest)；可空FK账户；attempt_count<=max_attempts；成功消费以consumed_at IS NULL及未到期/用途/会话/身份匹配原子条件更新。

查询与索引候选：expires_at；account_id,purpose；subject_digest,purpose,created_at；按真实查询基线复核。

生命周期：失败尝试原子计数并限制重发；重发使先前挑战失效。成功消费、身份唯一建/绑定、账户建立和会话同事务；冲突不重复建账户或换绑。外部OAuth签名/issuer/audience/回调来源先验证，原始秘密不持久入日志。

## 身份验证事务

匿名挑战不伪造owner；认证后由唯一provider/subject解析账户，后续个人数据才用owner归属。不能以先查询再插入代替唯一约束。身份/挑战状态日志仅保留最小审计，账号是否存在不通过可枚举错误泄漏。挑战存储与会话撤销均有保留期，正式实现核对哈希算法、重发/尝试阈值、CSRF及恢复路径。
