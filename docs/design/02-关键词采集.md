# 02 关键词采集

需求依据：[02 关键词采集](../requirement/02-关键词采集.md)；开发交接：[02 关键词采集](../prd/02-关键词采集.md)；agent工作拆解：[02 关键词采集](../plan/02-关键词采集.md)。以下为目标设计，未据此改变代码或业务数据库；共享架构、事务及选型原则见[00 产品目标与边界](../design/00-产品目标与边界.md)。

## 设计目标与业务流程

每个运行冻结规则、连接、能力、时间窗和预算；原帖发现与评论刷新是不同查询。明确跟踪集合允许旧帖新评论刷新，其纳入、退出、频率、到期和上限可控，不能只滚动检索新帖。

1. **有界发现**（FR-02-01）：每个查询有受理/跳过原因、实际边界及停止原因；运行能回到冻结输入。
2. **原帖与讨论上下文**（FR-02-02）：每条评论可回到原帖；缺父、不可读、未支持及达到上限分别说明。
3. **发现依据**（FR-02-03）：用户从结果可核对为什么命中及由哪个查询取得。
4. **旧帖讨论持续跟踪**（FR-02-04）：旧帖窗口外的新评论仍可发现；退出后不发新刷新请求。

## 状态、交互与失败恢复

滚动窗口外不等于停止讨论；未纳入跟踪的所有历史帖不无限刷新。验收场景：来源支持原帖和根评论、不支持回复；旧帖P发布时间在新帖窗口外且列入跟踪集合；执行新帖查询及P的评论刷新，期间规则v1变v2；预期：运行仍按v1；根评论已采20/来源总数100分别记录，回复不支持；P的新评论入库但P发布时间不变。

界面先呈现完成任务所需的事实与限制，再给出动作和回执。遵循[11 质量评测与验收](../design/11-质量评测与验收.md#共享状态与反馈)的共用状态、焦点和过期响应规则；无外部读取的静态内容不套远程加载状态。数量、分页、排列由内容规模和性能基线决定，不继承旧固定页数/栏宽。

## 数据库设计

目标关系模型；字段、键、查询索引和生命周期由同编号需求推导。类型为候选表达，正式DDL需验证枚举、长度、外键、容量、迁移与回退；本轮不执行建表。共享owner复合引用和当前版本指针规则见00。

### `collection_runs`

用途：一次有明确输入和边界的采集业务运行。

| 字段 | 候选类型 | 可空 | 业务含义与规则 |
|---|---|---|---|
| id | UUID | 否 | 主键 |
| owner_id | UUID | 否 | 用户 |
| operation_id | UUID | 否 | 用户或调度幂等标识 |
| topic_id | UUID | 否 | 主题 |
| rule_version | BIGINT | 否 | 冻结规则 |
| status_revision | BIGINT | 否 | 冻结主题状态授权 |
| trigger_kind | VARCHAR(16) | 否 | manual、scheduled |
| state | VARCHAR(24) | 否 | accepted、running、partial、succeeded、failed、cancelled、unknown |
| window_start | TIMESTAMPTZ | 否 | 左边界 |
| window_end | TIMESTAMPTZ | 否 | 右边界 |
| started_at | TIMESTAMPTZ | 是 | 未开始空 |
| finished_at | TIMESTAMPTZ | 是 | 未终结空 |
| stop_reason | VARCHAR(64) | 是 | 停止/失败/部分原因 |

键与完整性：PK(id)；UNIQUE(owner_id,id)；UNIQUE(owner_id,operation_id)；复合FK主题规则；窗口有序。

查询与索引候选：owner_id,topic_id,window_end DESC,id；state,started_at。 索引用真实查询基线复核，不能把索引存在当性能达标。

生命周期：取消保留已提交材料；配置更新不改旧运行；未知结果先核对。

### `collection_queries`

用途：逐来源逐查询的受理、冻结输入和覆盖结果。

| 字段 | 候选类型 | 可空 | 业务含义与规则 |
|---|---|---|---|
| id | UUID | 否 | 主键 |
| owner_id | UUID | 否 | 用户 |
| run_id | UUID | 否 | 所属运行 |
| binding_id | UUID | 否 | 来源连接 |
| binding_version | BIGINT | 否 | 配置快照 |
| source_capability_id | UUID | 否 | FK source_capabilities.id，冻结具体能力行；source须与binding所属来源一致 |
| query_key | VARCHAR(128) | 否 | 运行内稳定查询键 |
| target_object_id | UUID | 是 | 评论刷新必填原帖；新帖查询为空 |
| track_version | BIGINT | 是 | 自动跟踪刷新必填，对应discussion_track_versions；手动刷新允许无跟踪 |
| query_snapshot | JSONB | 否 | 实际上游表达、本地规则、窗口和限额 |
| state | VARCHAR(24) | 否 | accepted、skipped、running、partial、complete、failed、unknown |
| coverage_receipt | JSONB | 是 | 终点证据、计量口径及缺口 |
| stop_reason | VARCHAR(64) | 是 | 未执行或停止原因 |

键与完整性：PK(id)；UNIQUE(owner_id,id)；UNIQUE(owner_id,run_id,query_key)；UNIQUE(owner_id,run_id,id)；复合FK运行及连接版本；FK(source_capability_id)→source_capabilities(id)，能力与连接source一致由受理事务校验。

查询与索引候选：owner_id,run_id,query_key；owner_id,binding_id,state。 索引用真实查询基线复核，不能把索引存在当性能达标。

生命周期：跳过项也保留，不因没任务就丢失查询解释；complete只针对有界查询。

### `request_attempts`

用途：实际执行尝试边界，支持重试与逐请求保护核对。

| 字段 | 候选类型 | 可空 | 业务含义与规则 |
|---|---|---|---|
| id | UUID | 否 | 主键 |
| owner_id | UUID | 否 | 用户 |
| query_id | UUID | 否 | 查询 |
| run_id | UUID | 否 | 所属运行，用于约束query与execution属于同一run |
| execution_number | BIGINT | 否 | 执行轮次；>=1 |
| request_number | BIGINT | 否 | 轮内请求序号 |
| request_fingerprint | BYTEA | 否 | 脱敏请求身份摘要 |
| state | VARCHAR(24) | 否 | reserved、started、response_saved、failed、unknown |
| started_at | TIMESTAMPTZ | 是 | 未开始空 |
| finished_at | TIMESTAMPTZ | 是 | 未终结空 |
| returned_count | BIGINT | 是 | 未取得可靠响应时空 |
| checkpoint | JSONB | 是 | 脱敏游标与停止证据 |

键与完整性：PK(id)；UNIQUE(owner_id,id)；UNIQUE(owner_id,query_id,execution_number,request_number)；FK(owner_id,run_id,query_id)→collection_queries(owner_id,run_id,id)；FK(owner_id,run_id,execution_number)→collection_executions(owner_id,run_id,number)。

查询与索引候选：owner_id,query_id,execution_number；state,started_at。 索引用真实查询基线复核，不能把索引存在当性能达标。

生命周期：重放不改原观察归属；不能记录敏感URL参数或秘密。

### `collection_executions`

用途：运行的实际领取/执行轮，零请求延期、取消或失败也留真实记录。

| 字段 | 候选类型 | 可空 | 业务含义与规则 |
|---|---|---|---|
| owner_id | UUID | 否 | 账户 |
| run_id | UUID | 否 | 业务运行 |
| number | BIGINT | 否 | 单run递增且>=1 |
| claim_token | UUID | 否 | 该轮唯一围栏令牌，不复用旧轮 |
| state | VARCHAR(24) | 否 | claimed、running、deferred、partial、succeeded、failed、cancelled、expired、unknown |
| lease_expires_at | TIMESTAMPTZ | 否 | 领取有效期 |
| cancel_requested_at | TIMESTAMPTZ | 是 | 持久取消请求 |
| status_revision | BIGINT | 否 | 领取时主题授权代际 |
| claimed_at | TIMESTAMPTZ | 否 | 实际领取时间 |
| started_at | TIMESTAMPTZ | 是 | 零请求时可空 |
| finished_at | TIMESTAMPTZ | 是 | 未终结空 |
| stop_reason | VARCHAR(64) | 是 | 脱敏原因 |

键与完整性：PK(owner_id,run_id,number)；FK(owner_id,run_id)→collection_runs(owner_id,id)；UNIQUE(claim_token)；每run至多一个未结束且可发请求的执行轮，采用部分唯一约束和CAS领取。

查询与索引候选：owner_id,run_id,number DESC；state,lease_expires_at；按真实查询基线复核。

生命周期：请求前和页提交时校验令牌、租约、取消、主题代际与连接准入；过期轮不能提交新结果，未知外部消费先核对；运行累计与本轮独立投影。

### `discussion_track_versions`

用途：明确跟踪哪些旧帖及其刷新边界，支持FR-02-04和FR-37-02。

| 字段 | 候选类型 | 可空 | 业务含义与规则 |
|---|---|---|---|
| owner_id | UUID | 否 | 账户 |
| topic_id | UUID | 否 | 监测主题 |
| object_id | UUID | 否 | 原帖身份，仅可读post/article |
| version | BIGINT | 否 | 跟踪政策版本>=1 |
| is_current | BOOLEAN | 否 | 当前版本唯一 |
| state | VARCHAR(16) | 否 | active、paused、removed、expired |
| reason | TEXT | 否 | 本人加入或已授权事件跟踪准则 |
| interval_seconds | BIGINT | 否 | >0且受来源最小间隔约束 |
| comment_limit | BIGINT | 否 | 每次刷新上限>0 |
| effective_from | TIMESTAMPTZ | 否 | 生效时间 |
| expires_at | TIMESTAMPTZ | 是 | 可选到期 |
| created_at | TIMESTAMPTZ | 否 | 记录时间 |

键与完整性：PK(owner_id,topic_id,object_id,version)；同owner复合FK主题和原帖；部分UNIQUE(owner_id,topic_id,object_id) WHERE is_current；原子切换当前标志，历史正文不覆写。

查询与索引候选：owner_id,topic_id,state,effective_from；owner_id,object_id；按真实查询基线复核。

生命周期：纳入必须来自本人动作或已显式启用的事件跟踪规则，规则含最大活跃帖数/退出期限；退出只阻止后续请求，原帖发布时间不变。自动评论查询以run.topic_id+target_object_id+track_version复合校验该政策。

## 查询与执行事务

受理先冻结规则与来源能力、逐项规划查询；全部跳过也有运行回执。领取执行轮与异步触发写同一持久状态边界。请求外发前持久标started和预算预留，响应及材料/观察/检查点提交使用同一有效执行令牌。重放已提交页只返回旧结果，不转移原观察归属。页级提交失败、外部结果不明与业务失败分开。执行轮、预算窗口、来源游标不能互相替代。

### 评论请求与旧授权的最终检查

每次自动评论外发前重查当前discussion_track_versions：同owner/topic/原帖，is_current且active、生效未到期、未退出、未超活跃集合/评论/频率上限；冻结旧track版本存在不能授权已退出跟踪。绑定的identity_namespace必须与target_object命名空间一致，且当前来源能力支持该评论访问。

collection_executions.status_revision必须同时等于collection_runs冻结status_revision与主题当前授权代际；旧run不因重新领取而改写代际。暂停后恢复新授权建立新run，原run已有部分保留；同授权内可重试才建下一执行轮。排队取消也持久改变run为cancelled并禁止首次领取；并发取消/领取以CAS和请求前围栏收敛。
