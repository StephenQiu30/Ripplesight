# 05 事件证据与新事实

对应 [05-事件证据与新事实](../requirement/05-事件证据与新事实.md)；实施拆分见 [05-事件证据与新事实](../plan/05-事件证据与新事实.md)。需求为范围依据，本文件不表示功能已实现；进度只在仓库根目录BACKLOG。

## 设计目标

了解事件变化、新进展及原始证据，能够纠正误归并。

## 结构与交互

- 事件头部呈现摘要、当前修订、最早/最新证据时间、成员与作者数和来源分布。
- 时间线突出本轮新增事实，事实逐条关联可读材料与版本；区分事件发生时间、证据时间和发现时间。
- 热点条件显示窗口、最低样本及规则版本；误归并/拆分提交原因和预期修订，冲突不覆盖输入。

## 数据与复用边界

先核对现有入口：[backend/app/events/facts.py](../../backend/app/events/facts.py)、[backend/app/events/corrections.py](../../backend/app/events/corrections.py)、[backend/app/api/routers/events.py](../../backend/app/api/routers/events.py)。入口存在只代表可核对，不能据此宣称真实能力已验收。

优先复用现有业务身份、版本、服务与组件；展示派生值、本机阅读状态和持久事实分别处理。新字段仅在同编号需求有实际消费路径时补齐，接口/数据库的唯一合同仍在代码及schema。

## 状态与核对重点

新事实能指向证据与固定修订，热点不是简单摘要或热榜标签，关联不改变原帖身份。

读写状态使用真实回执；已有数据刷新失败保留可读内容并标过期，未知写入先核对结果。正常、空、加载、错误、无权限以及键盘行为按实际交互覆盖；静态内容无远程状态时标不适用。

视觉、组件与响应式沿用 [00-产品目标与边界](../design/00-产品目标与边界.md)；跨页状态沿用 [11-质量评测与验收](../design/11-质量评测与验收.md)；权限、安全渲染和许可沿用 [10-权限与数据生命周期](../design/10-权限与数据生命周期.md)。

## 事实差分与修订读写

一次事件更新以此前可核对修订为基准：新增事实、既有事实补证和重复转述分别呈现；程序统计成员/作者/来源，模型生成的数字不能直接作为指标。每条事实至少能回到可读原帖/评论与正文版本，缺少证据的结论保留未知。

误归并/拆分/移动→提交预期修订与原因→原子写入新的关联/事实视图→失效受影响派生结果→重读新修订。旧版用于核对，但每次读取仍执行当前许可，撤回不能通过旧修订绕过。热点窗口与最低样本由基线校准后冻结，判定引用该规则版本。

### 自动归并修订的冻结差分

“本轮”首先指一次成功自动归并提交的事件修订，与此前锁定的事件修订比较；首次成案明确空基准0。它不是一次采集任务、重试cycle、自然日或24小时窗口。分组评估结果原子保存实际事件/基准/结果修订、新关联成员、固定正文版本及事实身份，提交重放不重算。读取须把分类与冻结分组判断、基准事实身份及实际新增关联交叉核对，损坏记录保持未知，不能仅通过字段结构校验就信任分类。没有回执、旧记录、手工纠正修订或损坏回执保持差分未知，不能用修订号、时间戳或当前事实条数倒推。

显式新root/development事实及其新关联非mention材料记新增事实；background、roundup、unreviewed、旧格式降级结果及单纯mention不算新进展。既有root/development同一事实的新增材料逐条保留模型的补证/重复转述/未知判断与理由；缺判断保持未知，不将多来源或新正文直接当补证。模型只分类，程序计算唯一新增事实数及各类新关联材料数。新事实数量以唯一事实身份去重；新增事实涉及材料、补证材料、重复转述材料及未知材料互斥且和为本轮新关联材料总数，分别标明单位，不能把四类材料相加冒充新事实数。

事实页按选定事件修订读取差分，展示基准→结果修订、分类数量、材料分母与固定来源引用。每次读取沿用事实ALL输入及当前许可门槛；事实或相关成员不可读、待复核或关系改变时，该条差分转未知并隐藏派生理由，不继续展示已撤回的结论。历史读取也执行当前许可。已知零变化与未记录差分分别展示；未记录不显示伪造零值。该差分不证明模型分类正确、独立证实或正式热点达标；真实分层评测仍独立验收。

### 现有来源参与热榜的资格说明

先复用事件热度回执，不新增阈值接口或重新判定热榜。对于已知 `attention-v1-48h-halflife24h`，展示以回执结束时间为准的前48小时窗口（起点不计入、终点计入）、服务端资格结果，以及实际去重参与者/最低2个、其中编辑参与者/最低1个；未满足时分别解释缺少的条件。分组优先按来源组，其次按主体，均未配置时按来源；该计数不等于帖子、作者或独立事实确认。

未知/缺失版本、无有效带时区窗口、无效计数或计数与资格回执不一致时，保留服务端回执与版本并显示说明待确定，不套用旧阈值。覆盖不完整与趋势不可比单独呈现，不改现有资格条件。说明对应当前修订的48小时阅读排序，不代表关键词热点正式阈值已校准，不替代24小时统计、事实差分或首次提醒。
