# 46 任务记录

需求依据：[46 任务记录](../requirement/46-任务记录.md)；开发交接：[46 任务记录](../prd/46-任务记录.md)；agent工作拆解：[46 任务记录](../plan/46-任务记录.md)。以下为目标设计，未据此改变代码或业务数据库；共享架构、事务及选型原则见[00 产品目标与边界](../design/00-产品目标与边界.md)。

## 设计目标与业务流程

运行、实际执行轮、请求尝试、预算周期分开；逐轮归属可证明，零请求取消也有执行记录；累计与单轮返回/观察/唯一身份/四类独立，迟到、重放、历史未知不猜测。

1. **解释异步工作进度**（FR-46-01）：运行、阶段、尝试与结果分别关联，失败指出可处理原因。
2. **区分累计与单轮结果**（FR-46-02）：任务累计、实际执行轮次及预算周期分开；轮次归属无证据时未知。

## 状态、交互与失败恢复

累计和单轮不同快照不能相减，upstream未知不从保存数推算。验收场景：同一运行两执行轮，第一轮零请求取消，第二轮部分保存后失败；重放一页；查看列表及详情累计、单轮和预算后，两轮均保留；重放不转移归属；失败保留部分；各数字标快照/分母。

界面先呈现完成任务所需的事实与限制，再给出动作和回执。遵循[11 质量评测与验收](../design/11-质量评测与验收.md#共享状态与反馈)的共用状态、焦点和过期响应规则；无外部读取的静态内容不套远程加载状态。数量、分页、排列由内容规模和性能基线决定，不继承旧固定页数/栏宽。

## 数据库设计

目标关系模型；字段、键、查询索引和生命周期由同编号需求推导。类型为候选表达，正式DDL需验证枚举、长度、外键、容量、迁移与回退；本轮不执行建表。共享owner复合引用和当前版本指针规则见00。

### `budget_limits`

用途：稳定预算身份，窗口几何固定，政策数值独立版本化。

| 字段 | 候选类型 | 可空 | 业务含义与规则 |
|---|---|---|---|
| id | UUID | 否 | 预算身份 |
| owner_id | UUID | 否 | 账户 |
| scope_kind | VARCHAR(24) | 否 | owner、binding、run |
| scope_id | UUID | 是 | owner范围为空，其余必填并校验归属 |
| metric | VARCHAR(32) | 否 | network_request、analysis_attempt等，单位不可变 |
| window_seconds | BIGINT | 否 | >0，固定窗口跨度 |
| anchor_at | TIMESTAMPTZ | 否 | 固定窗口锚点，不因政策改版重置 |
| current_version | BIGINT | 否 | 指向不可变预算政策 |
| created_at | TIMESTAMPTZ | 否 | 建立时间 |

键与完整性：PK(id)；UNIQUE(owner_id,id)；UNIQUE NULLS NOT DISTINCT(owner_id,scope_kind,scope_id,metric)；FK(owner_id,id,current_version)→budget_limit_versions(owner_id,limit_id,version)。

查询与索引候选：owner_id,scope_kind,scope_id,metric；按真实查询基线复核。

生命周期：身份、metric、窗口跨度和锚点不可直接修改；需要改窗口几何时另评估连续计量过渡，旧窗口和在途消费仍约束新请求，不能新建身份清空额度。

### `budget_windows`

用途：原子预留与结算的资源窗口。

| 字段 | 候选类型 | 可空 | 业务含义与规则 |
|---|---|---|---|
| id | UUID | 否 | 主键 |
| owner_id | UUID | 否 | 用户 |
| limit_id | UUID | 否 | 预算政策 |
| initial_policy_version | BIGINT | 否 | 建立窗口时政策版本，历史初始依据；不参与窗口身份 |
| policy_snapshot | JSONB | 否 | 初始metric/单位/上限/跨度/锚点/版本；不可变初始依据，实际每次预留另绑定政策版本 |
| window_start | TIMESTAMPTZ | 否 | 左边界 |
| window_end | TIMESTAMPTZ | 否 | 右边界 |
| used_units | BIGINT | 否 | >=0 |
| reserved_units | BIGINT | 否 | >=0 |

键与完整性：PK(id)；UNIQUE(owner_id,id)；UNIQUE(owner_id,limit_id,window_start)；FK(owner_id,limit_id,initial_policy_version)→budget_limit_versions(owner_id,limit_id,version)；窗口有序。

查询与索引候选：owner_id,limit_id,window_start。 索引用真实查询基线复核，不能把索引存在当性能达标。

生命周期：请求前在事务锁下验证used+reserved+本次<=限额；窗口不等于执行轮次。

### `budget_reservations`

用途：某次请求使用资源的唯一预留、消费和释放记录。

| 字段 | 候选类型 | 可空 | 业务含义与规则 |
|---|---|---|---|
| id | UUID | 否 | 主键 |
| owner_id | UUID | 否 | 用户 |
| window_id | UUID | 否 | 预算窗口 |
| limit_id | UUID | 否 | 与窗口同稳定预算身份，服务校验 |
| policy_version | BIGINT | 否 | 预留时当前有效政策；复合FK预算政策版本 |
| operation_key | VARCHAR(256) | 否 | 请求/分析尝试幂等标识 |
| reserved_units | BIGINT | 否 | >=0 |
| consumed_units | BIGINT | 是 | 未知不能写0 |
| state | VARCHAR(24) | 否 | reserved、settled、released、unknown |
| created_at | TIMESTAMPTZ | 否 | 预留时间 |

键与完整性：PK(id)；UNIQUE(owner_id,window_id,operation_key)；复合FK预算窗口。

查询与索引候选：owner_id,window_id,state。 索引用真实查询基线复核，不能把索引存在当性能达标。

生命周期：只有能证明未消费才释放；进程中断的未知用量保守核对。

### `outbox_events`

用途：业务状态与异步触发之间的可靠交付提案，不指定消息中间件。

| 字段 | 候选类型 | 可空 | 业务含义与规则 |
|---|---|---|---|
| id | UUID | 否 | 事件ID |
| owner_id | UUID | 否 | 用户 |
| aggregate_kind | VARCHAR(32) | 否 | 业务类型 |
| aggregate_id | UUID | 否 | 业务身份 |
| aggregate_version | BIGINT | 否 | 业务版本 |
| event_kind | VARCHAR(64) | 否 | 事件类型 |
| payload_reference | JSONB | 否 | 业务输入引用，不复制秘密正文 |
| created_at | TIMESTAMPTZ | 否 | 业务提交时间 |
| published_at | TIMESTAMPTZ | 是 | 未投递空 |

键与完整性：PK(id)；业务变化与该记录同事务；消费者以事件ID和业务幂等键去重。

查询与索引候选：published_at IS NULL时created_at部分索引。 索引用真实查询基线复核，不能把索引存在当性能达标。

生命周期：数据库轮询或消息队列是实现选项，只有基线证明需要才采用复杂队列。

### `budget_limit_versions`

用途：不可变限额及准入政策，改变上限不重开窗口。

| 字段 | 候选类型 | 可空 | 业务含义与规则 |
|---|---|---|---|
| owner_id | UUID | 否 | 账户 |
| limit_id | UUID | 否 | 稳定预算身份 |
| version | BIGINT | 否 | 政策版本>=1 |
| limit_units | BIGINT | 否 | >=0；0阻止新预留 |
| admission_enabled | BOOLEAN | 否 | false阻止新请求，不能解释成不限额 |
| effective_from | TIMESTAMPTZ | 否 | 生效时间，当前指针只指已生效版 |
| created_at | TIMESTAMPTZ | 否 | 建立时间 |

键与完整性：PK(owner_id,limit_id,version)；复合FK稳定预算身份；追加版本、切当前指针和审计同事务。

查询与索引候选：owner_id,limit_id,version DESC；按真实查询基线复核。

生命周期：历史不覆盖；当前上限下降时已用和预留仍扣占用，直到窗口自然结束或消费核对，不能改版绕过预算。

## 预算预留、计量与回执

请求在事务内锁定各层预算身份及窗口，按固定anchor/跨度选择同一个窗口，并读取当前有效限额；used+reserved+本次不得超过当前上限。一个请求可能同时占用owner/source/run多层预算，预留全部成功才可外发，operation_key同层幂等。政策改版、重新启用、失败重试都不清零。

降额到低于已占用时remaining=max(0,当前上限-used-reserved)，另报overcommitted；禁止新预留，在途按实际消费核对。未知消费继续保守占用，只有可证明未发生才释放；每次预留保存policy_version，历史能复算。用量>=0，settled须有consumed_units，unknown不补0。

运行→执行轮→请求→观察归属支撑累计和单轮计量。预算窗口是时间额度边界而非执行轮；空执行、部分保存、迟到拒绝、页重放及历史缺证据各有真实状态。列表可按需读取详情，但不能以旧接口兼容为理由缩减目标计量。outbox仅解决业务状态与异步触发交付，消费者按事件/业务身份幂等，不要求独立消息中间件。
