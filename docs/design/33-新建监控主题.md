# 33 新建监控主题

需求依据：[33 新建监控主题](../requirement/33-新建监控主题.md)；开发交接：[33 新建监控主题](../prd/33-新建监控主题.md)；agent工作拆解：[33 新建监控主题](../plan/33-新建监控主题.md)。以下为目标设计，未据此改变代码或业务数据库；共享架构、事务及选型原则见[00 产品目标与边界](../design/00-产品目标与边界.md)。

## 设计目标与业务流程

从意图到关键词/来源/窗口/频率/限额完整草稿；预览只用已存样本，新主题默认未启用；无就绪来源可保存草稿，启用和立即运行分开。

1. **从意图建立主题**（FR-33-01）：表单解释来源语义；有效保存产生本人主题及规则版本。
2. **先预览再决定执行**（FR-33-02）：预览只用既有样本；规则变化使旧预览失效。

业务关联/消费合同：01规则、08准入、02受理。

读操作返回资源身份、版本、作用域、许可范围及缺口；筛选cursor绑定当前用户和条件。写动作按[00 产品目标与边界](../design/00-产品目标与边界.md#接口与异步合同设计)使用预期版本和operation_id。本文只定义本模块语义，不绑定既有路由、框架、队列或组件实现。

## 状态、交互与失败恢复

不把提交创建按钮当授权采集。验收场景：合法关键词但来源未准入，预览样本存在；保存草稿、预览、请求启用/立即运行后，保存成功但未启用；预览不联网；启用失败说明缺口并保留配置。

界面先呈现完成任务所需的事实与限制，再给出动作和回执。遵循[11 质量评测与验收](../design/11-质量评测与验收.md#共享状态与反馈)的共用状态、焦点和过期响应规则；无外部读取的静态内容不套远程加载状态。数量、分页、排列由内容规模和性能基线决定，不继承旧固定页数/栏宽。

## 持久化边界

消费上述归属实体，不新增一套重复材料或事件真源。只读筛选/导航可留客户端；用户主动保存的数据须按相应业务身份和许可管理，未定义消费路径的字段不持久化。
