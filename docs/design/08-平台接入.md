# 08 平台接入

需求依据：[08 平台接入](../requirement/08-平台接入.md)；开发交接：[08 平台接入](../prd/08-平台接入.md)；agent工作拆解：[08 平台接入](../plan/08-平台接入.md)。以下为目标设计，未据此改变代码或业务数据库；共享架构、事务及选型原则见[00 产品目标与边界](../design/00-产品目标与边界.md)。

## 设计目标与业务流程

来源能力分别声明关键词检索、标签/账号、热榜、详情、根评论、回复、分页和删除证据；支持/不支持/未知与合法准入分开。最终国内主流与X/Instagram目标保留，国内POC不能由海外对照替代。

1. **来源能力契约**（FR-08-01）：未知和不支持明确；能力附依据及核对时间。
2. **准入门槛**（FR-08-02）：未获准、计费不明、验证码、失效账号或撤权均拒绝新请求。
3. **目标与替代**（FR-08-03）：来源受限时说明能够回答的问题与缺口，用户可选已准入路径。

## 数据归属与接口

业务关联/消费合同：00执行边界、10秘密管理。

| 设计归属 | 候选实体/存储 | 本能力关系 |
|---|---|---|
| [08 平台接入](../design/08-平台接入.md#数据库设计) | `sources`、`source_capabilities`、`source_bindings`、`binding_versions`、`source_identity_namespaces` | 同owner引用，当前许可投影 |

读操作返回资源身份、版本、作用域、许可范围及缺口；筛选cursor绑定当前用户和条件。写动作按[00 产品目标与边界](../design/00-产品目标与边界.md#接口与异步合同设计)使用预期版本和operation_id。本文只定义本模块语义，不绑定既有路由、框架、队列或组件实现。

## 状态、交互与失败恢复

HN只能做合同对照，单个B站切片不能宣称全部国内POC完成。验收场景：来源只有热榜与详情，搜索/评论未知；另一候选费用不明；预览来源能力并请求启用后，搜索不能标ready；费用不明或未获准拒绝启用；保存能力说明不隐式探测。

界面先呈现完成任务所需的事实与限制，再给出动作和回执。遵循[11 质量评测与验收](../design/11-质量评测与验收.md#共享状态与反馈)的共用状态、焦点和过期响应规则；无外部读取的静态内容不套远程加载状态。数量、分页、排列由内容规模和性能基线决定，不继承旧固定页数/栏宽。

## 数据库设计

目标关系模型；字段、键、查询索引和生命周期由同编号需求推导。类型为候选表达，正式DDL需验证枚举、长度、外键、容量、迁移与回退；本轮不执行建表。共享owner复合引用和当前版本指针规则见00。

### `sources`

用途：来源种类目录与公开能力说明，不存用户凭据。

| 字段 | 候选类型 | 可空 | 业务含义与规则 |
|---|---|---|---|
| id | UUID | 否 | 主键 |
| source_key | VARCHAR(128) | 否 | 稳定来源键 |
| name | VARCHAR(256) | 否 | 来源名称 |
| kind | VARCHAR(32) | 否 | platform、rss、web、json等 |
| scope_description | TEXT | 否 | 能回答的问题与限制 |
| status | VARCHAR(24) | 否 | candidate、admitted、disabled |
| created_at | TIMESTAMPTZ | 否 | 记录时间 |

键与完整性：PK(id)；UNIQUE(source_key)。

查询与索引候选：source_key唯一索引。 索引用真实查询基线复核，不能把索引存在当性能达标。

生命周期：来源目录存在不授予用户访问权，禁用后不得开始新请求。

### `source_capabilities`

用途：逐来源逐能力及依据的版本化声明。

| 字段 | 候选类型 | 可空 | 业务含义与规则 |
|---|---|---|---|
| id | UUID | 否 | 主键 |
| source_id | UUID | 否 | 来源 |
| version | BIGINT | 否 | 能力档案版本 |
| capability | VARCHAR(32) | 否 | search、detail、comments、replies、backfill、deletion等 |
| support_state | VARCHAR(24) | 否 | supported、limited、unsupported、unknown |
| query_semantics | JSONB | 否 | 上游条件、本地精筛、窗口/分页/排序限制 |
| admission_requirements | JSONB | 否 | 权限、费用、停止与频率条件 |
| evidence_reference | TEXT | 是 | 已核对依据；不是凭据 |
| verified_at | TIMESTAMPTZ | 是 | 未核对时空 |

键与完整性：PK(id)；FK(source_id)→sources；UNIQUE(source_id,version,capability)；version>=1。

查询与索引候选：source_id,capability,version DESC。 索引用真实查询基线复核，不能把索引存在当性能达标。

生命周期：旧档案保留供运行追溯，实际执行重新核对当前准入。

### `source_bindings`

用途：用户或站点的来源配置与准入状态；可复用来源目录，不能自动共享个人材料。

| 字段 | 候选类型 | 可空 | 业务含义与规则 |
|---|---|---|---|
| id | UUID | 否 | 主键 |
| owner_id | UUID | 否 | 账户归属 |
| source_id | UUID | 否 | 来源种类 |
| scope | VARCHAR(16) | 否 | personal、site；site须运营权限 |
| current_version | BIGINT | 否 | 当前配置版本 |
| enabled | BOOLEAN | 否 | 新建默认false |
| admission_state | VARCHAR(24) | 否 | pending、ready、blocked、revoked |
| reason_code | VARCHAR(64) | 是 | 未就绪原因 |
| created_at | TIMESTAMPTZ | 否 | 创建时间 |
| updated_at | TIMESTAMPTZ | 否 | 更新时间 |

键与完整性：PK(id)；UNIQUE(owner_id,id)；FK(source_id)→sources；owner_id→accounts。

查询与索引候选：owner_id,enabled,source_id；不以同源强制只允许一个RSS实例。 索引用真实查询基线复核，不能把索引存在当性能达标。

生命周期：撤权/停用阻止新请求；个人与站点公开许可分开。

### `binding_versions`

用途：冻结可执行来源参数，不含Cookie或令牌。

| 字段 | 候选类型 | 可空 | 业务含义与规则 |
|---|---|---|---|
| binding_id | UUID | 否 | 所属连接 |
| owner_id | UUID | 否 | 所属用户 |
| version | BIGINT | 否 | 配置版本 |
| configuration | JSONB | 否 | URL、允许域名、映射等非秘密配置 |
| identity_namespace_id | UUID | 否 | 稳定实例身份空间；换账号/连接版本不自动换平台对象身份空间 |
| capability_version | BIGINT | 否 | 来源能力档案版本 |
| credential_reference | VARCHAR(256) | 是 | 仅本机秘密的不可解析引用；不能存秘密值 |
| created_at | TIMESTAMPTZ | 否 | 版本建立时间 |

键与完整性：PK(owner_id,binding_id,version)；复合FK(owner_id,binding_id)→source_bindings(owner_id,id)；复合FK身份命名空间。

查询与索引候选：owner_id,binding_id,version DESC。 索引用真实查询基线复核，不能把索引存在当性能达标。

生命周期：配置版本不可原地改写；秘密轮换在本机管理，历史引用失效明确说明。

### `source_identity_namespaces`

用途：显式定义原生ID在哪个稳定来源实例内唯一，避免两个RSS/JSON都返回ID=1时误去重。

| 字段 | 候选类型 | 可空 | 业务含义与规则 |
|---|---|---|---|
| id | UUID | 否 | 稳定身份空间主键 |
| owner_id | UUID | 否 | 用户归属 |
| source_id | UUID | 否 | 来源种类目录 |
| namespace_key | VARCHAR(256) | 否 | 稳定非秘密实例键，不直接记录带秘密URL |
| identity_scheme_version | BIGINT | 否 | 原生ID/无ID策略语义版本 |
| description | TEXT | 否 | 身份范围与变更规则 |
| created_at | TIMESTAMPTZ | 否 | 建立时间 |

键与完整性：PK(id)；UNIQUE(owner_id,id)；UNIQUE(owner_id,source_id,namespace_key)；FK(source_id)→sources；owner_id→accounts。binding_versions和source_objects使用同owner复合外键。

查询与索引候选：owner_id,source_id,namespace_key唯一索引。

生命周期：平台全局原生ID使用稳定平台空间，不随账号重绑/配置版本改变；RSS/JSON的局部ID按稳定feed/数据集实例隔离。换feed或ID方案实质改变时新建空间，迁移须显式身份映射；不同绑定指向同一已验证实例可共用空间。不能只因URL文字相同或正文相似合并来源对象。

验收：同owner、同rss种类、feedA/native1与feedB/native1形成两对象；同feedA通过两个绑定再发现native1仍为同对象。此规则补充FR-03-01原生身份合同。

## 当前版本完整性

当前指针采用复合FK：`source_bindings(owner_id,id,current_version)→binding_versions(owner_id,binding_id,version)`。身份首次建立与初版、后续新版本/修订与当前指针/审计同事务；循环关系在DDL采用可延期约束并在提交前验证。不能用应用中随意选最大版本替代当前有效版本。
