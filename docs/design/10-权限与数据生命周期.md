# 10 权限与数据生命周期

需求依据：[10 权限与数据生命周期](../requirement/10-权限与数据生命周期.md)；开发交接：[10 权限与数据生命周期](../prd/10-权限与数据生命周期.md)；agent工作拆解：[10 权限与数据生命周期](../plan/10-权限与数据生命周期.md)。以下为目标设计，未据此改变代码或业务数据库；共享架构、事务及选型原则见[00 产品目标与边界](../design/00-产品目标与边界.md)。

## 设计目标与业务流程

服务端按owner及当前许可投影；标题、计数、附件、历史修订、导出和派生物都受约束。撤权立即不可读，清理异步可追踪；源确认删除与临时读取失败分开；备份恢复先重放删除账本。

1. **访问隔离**（FR-10-01）：替换ID、cursor、附件或导出引用均不能获取他人内容及计数。
2. **许可与删除**（FR-10-02）：撤回后新读取立即不可得；物理清理完成与失败可追踪。
3. **最小化与安全**（FR-10-03）：恶意Markdown/HTML/URL与凭据混入样本被拒绝或清理。

## 数据归属与接口

业务关联/消费合同：29身份、08来源政策。

| 设计归属 | 候选实体/存储 | 本能力关系 |
|---|---|---|
| [10 权限与数据生命周期](../design/10-权限与数据生命周期.md#数据库设计) | `access_policies`、`retention_policies`、`deletion_requests`、`deletion_targets` | 同owner引用，当前许可投影 |

## 状态、交互与失败恢复

删除账本存非正文最小标识并独立保护；清理失败不得重新公开。验收场景：A的主题/附件，B替换ID、cursor、附件；一条公开证据随后撤回；读取当前、历史及导出，再从旧备份恢复；预期：B无标题/计数/正文/字节；撤回即时阻止新读取；恢复重放删除记录后才开放服务。

界面先呈现完成任务所需的事实与限制，再给出动作和回执。遵循[11 质量评测与验收](../design/11-质量评测与验收.md#共享状态与反馈)的共用状态、焦点和过期响应规则；无外部读取的静态内容不套远程加载状态。数量、分页、排列由内容规模和性能基线决定，不继承旧固定页数/栏宽。

## 数据库设计

目标关系模型；字段、键、查询索引和生命周期由同编号需求推导。类型为候选表达，正式DDL需验证枚举、长度、外键、容量、迁移与回退；本轮不执行建表。共享owner复合引用和当前版本指针规则见00。

### `access_policies`

用途：来源/材料当前可读和可公开范围，作为安全判定而非副本正文。

| 字段 | 候选类型 | 可空 | 业务含义与规则 |
|---|---|---|---|
| id | UUID | 否 | 主键 |
| owner_id | UUID | 否 | 所属账户 |
| resource_kind | VARCHAR(32) | 否 | binding、object、public_entry等 |
| resource_id | UUID | 否 | 被保护身份；服务验证类型与归属 |
| version | BIGINT | 否 | 政策版本 |
| is_current | BOOLEAN | 否 | 每保护资源恰有一条当前政策，事务切换；无政策默认拒绝 |
| effective_from | TIMESTAMPTZ | 否 | 生效时刻；延迟公开未到时不开放 |
| read_scope | VARCHAR(24) | 否 | owner、public、denied |
| content_scope | VARCHAR(24) | 否 | full、summary、metadata、none |
| license_reference | TEXT | 是 | 当前许可依据 |
| revoked_at | TIMESTAMPTZ | 是 | 撤回时间 |
| updated_at | TIMESTAMPTZ | 否 | 更新时间 |

键与完整性：PK(id)；UNIQUE(owner_id,resource_kind,resource_id,version)；UNIQUE(owner_id,id)；部分UNIQUE(owner_id,resource_kind,resource_id) WHERE is_current；更新锁定同资源，追加新版本并原子切标志；政策内容不可覆写，is_current仅当前指示。

查询与索引候选：owner_id,resource_kind,resource_id,version DESC。 索引用真实查询基线复核，不能把索引存在当性能达标。

生命周期：撤回使新读取拒绝，不能从较旧版本回退；多态引用无法单一FK，服务和检查共同约束。

### `retention_policies`

用途：按来源及数据类别限定保留与物理清理期限。

| 字段 | 候选类型 | 可空 | 业务含义与规则 |
|---|---|---|---|
| id | UUID | 否 | 主键 |
| owner_id | UUID | 否 | 用户 |
| binding_id | UUID | 是 | 来源特例；空为默认 |
| version | BIGINT | 否 | 政策版本 |
| is_current | BOOLEAN | 否 | 每owner/连接或默认范围/data_class唯一当前政策 |
| effective_from | TIMESTAMPTZ | 否 | 生效时间 |
| data_class | VARCHAR(24) | 否 | structured、raw、media、derived |
| requested_days | INTEGER | 否 | >=0 |
| source_max_days | INTEGER | 是 | 来源上限未知时空 |
| effective_days | INTEGER | 否 | 已知上限时取较小值 |
| cleanup_deadline_seconds | BIGINT | 是 | 需基线与许可冻结的物理清理时限 |

键与完整性：PK(id)；UNIQUE(owner_id,id)；UNIQUE NULLS NOT DISTINCT(owner_id,binding_id,data_class,version)；部分UNIQUE NULLS NOT DISTINCT(owner_id,binding_id,data_class) WHERE is_current；复合FK可选连接；数值非负且effective_days<=已知上限。

查询与索引候选：owner_id,binding_id,data_class,version。 索引用真实查询基线复核，不能把索引存在当性能达标。

生命周期：策略变化可缩短寿命，不能恢复已撤权正文；到期立即不可读和物理清理分开。

### `deletion_requests`

用途：用户删除、源删除、撤权和保留到期的清理回执。

| 字段 | 候选类型 | 可空 | 业务含义与规则 |
|---|---|---|---|
| id | UUID | 否 | 主键 |
| owner_id | UUID | 否 | 用户 |
| operation_id | UUID | 否 | 幂等操作 |
| resource_kind | VARCHAR(32) | 否 | 目标类别 |
| resource_id | UUID | 否 | 目标身份 |
| reason | VARCHAR(32) | 否 | user、source_deleted、revoked、expired |
| state | VARCHAR(24) | 否 | pending、running、partial、completed、failed |
| requested_at | TIMESTAMPTZ | 否 | 逻辑删除时刻 |
| completed_at | TIMESTAMPTZ | 是 | 全部必要目标成功后填写 |

键与完整性：PK(id)；UNIQUE(owner_id,id)；UNIQUE(owner_id,operation_id)；completed与completed_at一致。

查询与索引候选：state,requested_at；owner_id,resource_kind,resource_id。 索引用真实查询基线复核，不能把索引存在当性能达标。

生命周期：受理时关闭可见性；物理失败不得回滚可见性，重试只处理未完成目标。

### `deletion_targets`

用途：跨关系库、对象文件与缓存的清理目标。

| 字段 | 候选类型 | 可空 | 业务含义与规则 |
|---|---|---|---|
| owner_id | UUID | 否 | 用户 |
| deletion_id | UUID | 否 | 清理请求 |
| target_kind | VARCHAR(32) | 否 | relational、object_file、cache、derived |
| target_reference | VARCHAR(512) | 否 | 脱敏目标标识 |
| state | VARCHAR(24) | 否 | pending、running、succeeded、failed |
| attempt_count | INTEGER | 否 | >=0且有重试上限 |
| last_error | VARCHAR(64) | 是 | 脱敏错误 |
| completed_at | TIMESTAMPTZ | 是 | 成功时间 |

键与完整性：PK(owner_id,deletion_id,target_kind,target_reference)；复合FK清理请求。

查询与索引候选：state,attempt_count；owner_id,deletion_id。 索引用真实查询基线复核，不能把索引存在当性能达标。

生命周期：关系对象删除使用明确顺序；不让外部文件失败释放受限读取。

## 权限矩阵与生命周期执行

| 角色/内容 | 公开许可投影 | 本人监测正文 | 配置/纠错/删除 |
|---|---|---|---|
| 匿名 | 仅当前白名单及许可范围 | 拒绝 | 拒绝 |
| 本人 | 按当前公开许可 | 本人且来源仍允许的范围 | 本人显式操作并校验版本 |
| 他人 | 同匿名公开范围 | 拒绝 | 拒绝 |
| 运营 | 按职权查看诊断/主动反馈 | 默认拒绝，诊断不含正文 | 仅被授权的运营资源 |

权限判定按账户归属、来源约束、逐内容例外和公开许可共同取最严格范围；逐内容允许不能突破来源拒绝。access_policies选择当前is_current行并校验effective_from/撤回；未来公开不提前授予，缺政策拒绝。retention按来源特例覆盖默认，effective_days不超过已知来源上限；未知许可限制不得据‘未知上限’无界保存。

撤回先原子写不可读政策与deletion_requests，清理正文、原响应、媒体、派生分析/向量/缓存/导出可控副本及失效引用；各目标独立回执。已被用户下载到系统外的文件无法保证远程抹除，要如实说明。

删除账本和最小tombstone需独立于可回退的业务备份可靠保存，内容限owner、资源/原生标识摘要、删除原因/时间/操作及保留期限，不保留被删正文或秘密。恢复先隔离服务、恢复基础数据，再重放备份之后的删除/撤权账本并复查派生物和附件，最后才开放读取。账本不可用时保持隔离，不能让备份复活已删除内容；具体账本介质、保留期、RPO/RTO待恢复方案评审和演练。

## 列表、固定修订与导出状态投影

报告列表和详情采用相同的全部冻结输入许可检查；最新修订不可读时不回退较旧修订。先过滤不可读报告再填充分页，拒读记录不产生游标，已撤权游标不能继续定位。导出状态读取与下载均复核冻结输入，不返回受限材料数量或文件大小、摘要等元信息；操作诊断通过不含材料正文的任务回执核对。

事件当前与固定修订成员仅投影当前可读集合，分页及member_count/readable_member_count使用同一集合，不返回受限成员身份、版本、来源或隐藏数量。partial只说明证据不完整，不提供拒读材料的具体分母；派生标题/摘要仍按全部历史输入许可约束，不能以剩余可读材料替代原证据。

事实接口同样仅返回当前可读成员；完全没有可读成员的事实及其根事实引用不投影。任一冻结输入撤权时，自动修订差分返回`delta_state=unavailable`且`delta=null`，不能用带受限身份的unknown项、隐藏材料数量或可读子集伪装完整分区。
