# 44 来源连接与采集覆盖

对应 [44-来源连接与采集覆盖](../requirement/44-来源连接与采集覆盖.md)；实施拆分见 [44-来源连接与采集覆盖](../plan/44-来源连接与采集覆盖.md)。需求为范围依据，本文件不表示功能已实现；进度只在仓库根目录BACKLOG。

## 设计目标

作为所属用户，我需要知道来源是否真能采集以及哪里缺数据。

## 结构与交互

- 来源列表分别展示连接、搜索/详情/评论/回复、手动/定时能力及不可用原因，关联准入版本。
- 覆盖记录每页20条，标窗口、预算、任务和停止原因；Chrome绑定显式执行，页面不展示或存Cookie，个人来源另见58。

### 覆盖详情计量

沿用既有侧栏详情，不扩展列表列数。单独展示上游返回条数（精筛前）、持久观察条数（精筛后，可多次出现同身份）与唯一身份数（本任务观察去重）；不同分母不相加、不推导过滤率或全平台覆盖率。

新增、更新、未变、无法比较按[03计量合同](03-增量去重与覆盖.md#增量计量合同)展示，每项明确为“数量及本任务唯一身份分母”，四类互斥。保留首次入库、正文/已知指标变化、已存值相同及证据不足的简短说明。未知分子或分母显示“未知”，真实零显示0；分母为0时展示0个唯一身份，不计算百分比。只有识别的计量口径才能解释四类，历史缺口径或未来未知口径不从旧字段倒推，提示无法核对分类。

旧重复观察单独标“旧口径重复观察”，说明是持久观察减新增身份，包含旧帖更新及同任务多次观察，不作为“未变”也不与四类相加。页面说明计量来自当前保留历史，历史删除可能改变分类；未变仅表示已存正文版本和指标未变。请求失败继续显示错误，不将未取得计量当零；加载、空列表及无权限沿用既有状态和恢复路径。

关键词搜索详情复用逐查询受理组件：受理任务读取任务冻结计划，整来源跳过读取应执行窗口的冻结计划及主题版本，不从当前配置推算历史。历史无快照显示未保存，其他能力不展示关键词查询；来源跳过不记零结果或采集完成。

### 区域与显示边界

下面保留需求定义的区域和数量；必需字段、操作语义和业务约束以同编号需求表为准，不另建字段字典。

| 区域/操作 | 数量与范围 |
|---|---|
| 来源连接 | 来源目录及选中连接 |
| 采集覆盖 | 窗口20条/页；详情单独读；固定时间窗 |
| Chrome绑定 | 明确启用操作；不在页面存Cookie |

## 数据与复用边界

先核对现有入口：[frontend/src/app/sources](../../frontend/src/app/sources)、[backend/app/api/routers/source_connections.py](../../backend/app/api/routers/source_connections.py)。入口存在只代表可核对，不能据此宣称真实能力已验收。

优先复用现有业务身份、版本、服务与组件；展示派生值、本机阅读状态和持久事实分别处理。新字段仅在同编号需求有实际消费路径时补齐，接口/数据库的唯一合同仍在代码及schema。

## 状态与核对重点

未授权、失效、预算、部分覆盖和风控停止；本人连接ID替换拒绝。

读写状态使用真实回执；已有数据刷新失败保留可读内容并标过期，未知写入先核对结果。正常、空、加载、错误、无权限以及键盘行为按实际交互覆盖；静态内容无远程状态时标不适用。

视觉、组件与响应式沿用 [00-产品目标与边界](../design/00-产品目标与边界.md)；跨页状态沿用 [11-质量评测与验收](../design/11-质量评测与验收.md)；权限、安全渲染和许可沿用 [10-权限与数据生命周期](../design/10-权限与数据生命周期.md)。
