# 44 来源连接与采集覆盖

需求依据：[44 来源连接与采集覆盖](../requirement/44-来源连接与采集覆盖.md)；工作拆解：[44 来源连接与采集覆盖](../plan/44-来源连接与采集覆盖.md)。以下为目标设计，未据此改变代码或业务数据库；共享架构、事务及选型原则见[00 产品目标与边界](../design/00-产品目标与边界.md)。

## 设计目标与业务流程

分开展示连接准入、身份有效、能力、启用与最近成功；逐查询覆盖包含窗口、页、返回/新增/重复/缺口、预算和停止原因；恢复连接不等于立即采集。

1. **理解连接与覆盖**（FR-44-01）：配置、连接就绪与真实执行分别说明；搜索/评论/回复逐项可读。
2. **恢复合法连接**（FR-44-02）：启用显式操作；账号/费用/风控边界未满足时拒绝新请求。

## 状态、交互与失败恢复

连接成功不得标全量覆盖。验收场景：已连接但评论不支持，另有登录过期及部分分页；看覆盖并显式恢复连接后，缺口可解释；未准入不探测；恢复后仍须独立受理运行。

界面先呈现完成任务所需的事实与限制，再给出动作和回执。遵循[11 质量评测与验收](../design/11-质量评测与验收.md#共享状态与反馈)的共用状态、焦点和过期响应规则；无外部读取的静态内容不套远程加载状态。数量、分页、排列由内容规模和性能基线决定，不继承旧固定页数/栏宽。

## 持久化边界

消费上述归属实体，不新增一套重复材料或事件真源。只读筛选/导航可留客户端；用户主动保存的数据须按相应业务身份和许可管理，未定义消费路径的字段不持久化。
