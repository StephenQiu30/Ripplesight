# 58 个人来源

需求依据：[58 个人来源](../requirement/58-个人来源.md)；开发交接：[58 个人来源](../prd/58-个人来源.md)；agent工作拆解：[58 个人来源](../plan/58-个人来源.md)。以下为目标设计，未据此改变代码或业务数据库；共享架构、事务及选型原则见[00 产品目标与边界](../design/00-产品目标与边界.md)。

## 设计目标与业务流程

来源类型分别说明能返回什么、ID语义、许可、分页和关键词限制；新建默认关闭，编辑/启用/运行独立；URL和重定向每跳准入，个人资料owner隔离。

1. **管理本人来源**（FR-58-01）：保存与编辑不采集；冲突保留输入；来源及材料按owner隔离。
2. **显式启用与执行**（FR-58-02）：恶意URL、重定向越界或未准入来源拒绝；合法运行可回到原文和配置版本。

## 状态、交互与失败恢复

URL合法不证明关键词检索或完整抓取能力。验收场景：两个RSS各返回本地ID1；合法URL重定向私网；新源默认关闭；保存、启用并显式运行后，两个对象不误合并；私网或越界重定向拒绝；保存零请求且不公开。

界面先呈现完成任务所需的事实与限制，再给出动作和回执。遵循[11 质量评测与验收](../design/11-质量评测与验收.md#共享状态与反馈)的共用状态、焦点和过期响应规则；无外部读取的静态内容不套远程加载状态。数量、分页、排列由内容规模和性能基线决定，不继承旧固定页数/栏宽。

## 持久化边界

消费上述归属实体，不新增一套重复材料或事件真源。只读筛选/导航可留客户端；用户主动保存的数据须按相应业务身份和许可管理，未定义消费路径的字段不持久化。
