# 17 公开事件详情

需求依据：[17 公开事件详情](../requirement/17-公开事件详情.md)；开发交接：[17 公开事件详情](../prd/17-公开事件详情.md)；agent工作拆解：[17 公开事件详情](../plan/17-公开事件详情.md)。以下为目标设计，未据此改变代码或业务数据库；共享架构、事务及选型原则见[00 产品目标与边界](../design/00-产品目标与边界.md)。

## 设计目标与业务流程

显示事实时间线、证据出处、修订与限制；支持收藏、关注入口和许可内分享。观点/情感标样本及平台分布；关注、收藏、已读彼此独立。

1. **核对公开事件的事实变化**（FR-17-01）：事实、时间线和引文来自同一可读修订；被撤回材料立即不可得。
2. **理解讨论与趋势限制**（FR-17-02）：比例附有效样本、窗口、来源和分析状态；覆盖变化标不可比。

## 状态、交互与失败恢复

分享只含公开白名单字段。验收场景：事件两修订、一条更正、部分情感未知，某证据已撤回；读时间线、观点分布并分别收藏/关注后，更正可追溯；未知不计中性；撤回正文隐藏；收藏不自动订阅。

界面先呈现完成任务所需的事实与限制，再给出动作和回执。遵循[11 质量评测与验收](../design/11-质量评测与验收.md#共享状态与反馈)的共用状态、焦点和过期响应规则；无外部读取的静态内容不套远程加载状态。数量、分页、排列由内容规模和性能基线决定，不继承旧固定页数/栏宽。

## 持久化边界

消费上述归属实体，不新增一套重复材料或事件真源。只读筛选/导航可留客户端；用户主动保存的数据须按相应业务身份和许可管理，未定义消费路径的字段不持久化。
