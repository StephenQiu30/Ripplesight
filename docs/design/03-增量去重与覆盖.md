# 03 增量去重与覆盖

需求依据：[03 增量去重与覆盖](../requirement/03-增量去重与覆盖.md)；工作拆解：[03 增量去重与覆盖](../plan/03-增量去重与覆盖.md)。以下为目标设计，未据此改变代码或业务数据库；共享架构、事务及选型原则见[00 产品目标与边界](../design/00-产品目标与边界.md)。

## 设计目标与业务流程

对象身份使用稳定来源实例命名空间与原生种类/ID；评论的根/回复角色不参与身份。正文版本、互动观察、发现路径及各分母分离。空结果、访问失败、评论失败不构成删除证据。

1. **身份与版本**（FR-03-01）：两轮输入中同身份不造新帖，异平台或异作者相似文字不合并身份。
2. **计量分母**（FR-03-02）：互斥四类之和等于同作用域唯一身份数；未知分母不给百分比。
3. **覆盖与缺口**（FR-03-03）：循环游标、失效游标、预算截断和返回缺失均有可读原因。

业务关联/消费合同：02实际请求回执、08命名空间。

| 设计归属 | 候选实体/存储 | 本能力关系 |

## 状态、交互与失败恢复

不同RSS的本地ID相同不合并；缺父链补齐不产生第二条评论；失败不删除旧内容。验收场景：轮1 A/a、A/b；轮2 A/a未变、A/b编辑、A/c两次、B/a一次；提交第二轮并查看单轮与累计计量后，上游返回5、唯一身份4，新增2/更新1/未变1/无法比较0；B/a独立；无历史基线归无法比较。

界面先呈现完成任务所需的事实与限制，再给出动作和回执。遵循[11 质量评测与验收](../design/11-质量评测与验收.md#共享状态与反馈)的共用状态、焦点和过期响应规则；无外部读取的静态内容不套远程加载状态。数量、分页、排列由内容规模和性能基线决定，不继承旧固定页数/栏宽。

## 数据库设计

目标关系模型；字段、键、查询索引和生命周期由同编号需求推导。类型为候选表达，正式DDL需验证枚举、长度、外键、容量、迁移与回退；本轮不执行建表。共享owner复合引用和当前版本指针规则见00。

### `source_objects`

用途：原帖、文章、评论和回复的业务身份，转载不合并身份。

| 字段 | 候选类型 | 可空 | 业务含义与规则 |
|---|---|---|---|
| id | UUID | 否 | 主键 |
| owner_id | UUID | 否 | 用户 |
| identity_namespace_id | UUID | 否 | 稳定来源实例命名空间；区分不同RSS/JSON本地ID空间 |
| native_kind | VARCHAR(16) | 否 | post、article、comment；原生身份种类固定，root/reply是关系角色 |
| native_id | VARCHAR(512) | 否 | 来源稳定对象ID；无原生ID使用明确版本化策略 |
| author_native_id | VARCHAR(512) | 是 | 无法识别作者时空 |
| canonical_url | TEXT | 是 | 安全来源链接 |
| first_discovered_at | TIMESTAMPTZ | 否 | 首次发现 |
| visibility | VARCHAR(24) | 否 | readable、unavailable、deleted、unknown |

键与完整性：PK(id)；UNIQUE(owner_id,id)；UNIQUE(owner_id,identity_namespace_id,native_kind,native_id)；复合FK(owner_id,identity_namespace_id)→source_identity_namespaces(owner_id,id)。

查询与索引候选：owner_id,identity_namespace_id,first_discovered_at DESC,id。 索引用真实查询基线复核，不能把索引存在当性能达标。

生命周期：源删除使新读取不可见；原生身份不因事件归并改变。

### `content_versions`

用途：对象文本与媒体范围的不可变版本。

| 字段 | 候选类型 | 可空 | 业务含义与规则 |
|---|---|---|---|
| id | UUID | 否 | 主键 |
| owner_id | UUID | 否 | 用户 |
| object_id | UUID | 否 | 原生对象 |
| fingerprint | BYTEA | 否 | 规范化内容摘要 |
| source_metadata | JSONB | 否 | 版本化作者/显示名及来源编辑依据，最小化且带schema版本 |
| text_scope | VARCHAR(24) | 否 | full、summary、truncated、media_only |
| title | TEXT | 是 | 来源无标题时空 |
| body | TEXT | 是 | 许可/来源无正文时空 |
| media_references | JSONB | 否 | 受生命周期管理的媒体引用 |
| published_at | TIMESTAMPTZ | 是 | 来源发布时间；未知不可补接收时间 |
| created_at | TIMESTAMPTZ | 否 | 本机版本建立时间 |

键与完整性：PK(id)；UNIQUE(owner_id,id)；UNIQUE(owner_id,object_id,id)；UNIQUE(owner_id,object_id,fingerprint)；复合FK对象。

查询与索引候选：owner_id,object_id,created_at DESC,id；全文/模糊索引待查询基线后选择。 索引用真实查询基线复核，不能把索引存在当性能达标。

生命周期：正文编辑保留新版本并使依赖旧版本的当前结论待重评；旧引文仍受当前许可。

### `content_observations`

用途：互动、可见性与获取时间的观察，和正文版本分离。

| 字段 | 候选类型 | 可空 | 业务含义与规则 |
|---|---|---|---|
| id | UUID | 否 | 主键 |
| owner_id | UUID | 否 | 用户 |
| object_id | UUID | 否 | 对象 |
| content_version_id | UUID | 是 | 本次可读版本；不可得时空 |
| request_attempt_id | UUID | 是 | 实际请求归属；旧/导入记录未知 |
| observed_at | TIMESTAMPTZ | 否 | 来源状态观察时刻 |
| received_at | TIMESTAMPTZ | 否 | 本机持久接收时间 |
| metrics | JSONB | 否 | 有单位的互动数据；缺失键为未知 |
| visibility | VARCHAR(24) | 否 | 本轮可见性 |
| receipt_fingerprint | BYTEA | 否 | 观察重放身份摘要 |

键与完整性：PK(id)；UNIQUE(owner_id,id)；UNIQUE(owner_id,receipt_fingerprint)；复合FK对象、对象所属版本和请求尝试。

查询与索引候选：owner_id,object_id,observed_at DESC,id；owner_id,request_attempt_id。 索引用真实查询基线复核，不能把索引存在当性能达标。

生命周期：计量基于保留观察；清理后不得保证重建已删除历史的分类。

### `content_discoveries`

用途：对象由何种查询和路径发现及命中解释。

| 字段 | 候选类型 | 可空 | 业务含义与规则 |
|---|---|---|---|
| id | UUID | 否 | 主键 |
| owner_id | UUID | 否 | 用户 |
| object_id | UUID | 否 | 对象 |
| query_id | UUID | 否 | 查询 |
| method | VARCHAR(24) | 否 | keyword、tag、account、hotlist、rss、web |
| discovered_at | TIMESTAMPTZ | 否 | 本次发现时间 |

键与完整性：PK(id)；UNIQUE(owner_id,object_id,query_id)；复合FK对象、查询。

查询与索引候选：owner_id,query_id；owner_id,object_id,discovered_at。 索引用真实查询基线复核，不能把索引存在当性能达标。

生命周期：只保存取得对象的路径事实，实际命中词/排除理由只在topic_matches并绑定正文版本维护；重复发现保留多个真实路径，不造多份正文。

### `content_relations`

用途：原帖、根评论、直接父评论和回复目标关系。

| 字段 | 候选类型 | 可空 | 业务含义与规则 |
|---|---|---|---|
| owner_id | UUID | 否 | 用户 |
| child_id | UUID | 否 | 评论/回复对象 |
| relation_type | VARCHAR(24) | 否 | post、root、parent、reply_target |
| related_object_id | UUID | 是 | 父对象未知时空 |
| native_reference | VARCHAR(512) | 是 | 已知原生父ID |
| related_namespace_id | UUID | 是 | 未解析原生引用须带命名空间 |
| related_native_kind | VARCHAR(16) | 是 | 与native_reference一起定位原生对象，未知显式空 |
| resolution_state | VARCHAR(24) | 否 | resolved、missing、unavailable、unknown |

键与完整性：PK(owner_id,child_id,relation_type)；复合FK子对象及可选父对象；禁止自环，服务检验祖先环。

查询与索引候选：owner_id,related_object_id,relation_type,child_id。 索引用真实查询基线复核，不能把索引存在当性能达标。

生命周期：缺父不得造占位正文；来源后补可解析关系但保留分析输入快照。

### `topic_matches`

用途：某规则对某个正文版本的确定性本地匹配结果。

| 字段 | 候选类型 | 可空 | 业务含义与规则 |
|---|---|---|---|
| owner_id | UUID | 否 | 用户 |
| topic_id | UUID | 否 | 主题 |
| rule_version | BIGINT | 否 | 规则 |
| content_version_id | UUID | 否 | 实际判断正文版本 |
| result | VARCHAR(24) | 否 | matched、excluded、unknown |
| reason | JSONB | 否 | 命中/未命中/语言解释 |
| evaluated_at | TIMESTAMPTZ | 否 | 判断时间 |

键与完整性：PK(owner_id,topic_id,rule_version,content_version_id)；复合FK主题规则和正文版本。

查询与索引候选：owner_id,topic_id,rule_version,result,evaluated_at。 索引用真实查询基线复核，不能把索引存在当性能达标。

生命周期：正文/规则变化产生新判断，不覆盖旧版本的解释。

## 身份、差分与可见性规则

- 同一来源原生评论从缺父变为回复，只补关系；不因root/reply角色改变对象身份。author_native_id代表最近观察身份，历史作者/显示名如需参与分析放入content_versions的版本元信息；作者数量按(namespace,author_native_id)去重，缺作者单列未知。
- source_objects是稳定身份；content_versions是不可变内容；content_observations是观察时刻、互动及请求归属；content_discoveries仅是发现路径；topic_matches是特定规则对特定正文版本的唯一匹配解释。语义分析另归09，不能覆写确定性匹配。
- 每轮按该轮实际归属的请求观察聚合唯一身份，再与此前可读保留历史比较：新增/更新/未变/无法比较互斥且覆盖分母。缺前序归属证据不根据接收时间猜轮次；上游返回可含重复且不等于持久观察。
- content_observations(owner_id,object_id,content_version_id)及event_evidence同形引用必须FK到content_versions(owner_id,object_id,id)。关系缺父记录原生三元组，解析后保持同owner且父链无环。
- 空集合、访问失败、无权限或刷新失败仅记录本次观察及覆盖缺口，不标source_deleted；确认删除依据才能触发10的删除流程。
