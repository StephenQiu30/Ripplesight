# Research007 七平台接入与竞品调研

本文是 [PRD007](../prd/007-扩展能力需求.md) 的调研依据，从原 PRD007 §8 迁出，内容为 2026-10-04 的资料快照，不是需求或验收结论。免费路线合同以 [Design007 §11](../design/007-扩展能力设计.md#11-免费本机采集顶层设计) 为准。

资料核验日：2026-10-04，Asia/Shanghai。范围为公开信息获取和持续阅读，不是社交发布工具调研。本次研究读取官方开发者、产品、帮助和价格资料，并只读核验 AIHOT 源码与本机组件；没有登录开放平台、申请审核、购买套餐或调用真实平台采集路由。§1—3 保留官方/商业能力背景，当前免费路线以 §4/§6 和 Design007 §11 为准。以下“文档支持”“候选”均不表示 HotKey 已获准或已上线。

Threads单帖读取还存在独立权限边界：`threads_basic` 未获 Advanced Access 时只能读取 Threads tester 的帖子，获批后才可按允许范围读其他用户公共帖；公共关键词发现成功不自动证明后续单帖正文读取成功。100粉门槛只适用于公开 profile lookup/profile posts 发现路径，不外推所有关键词结果或单帖读取。[读取帖子](https://developers.facebook.com/documentation/threads/retrieve-and-discover-posts/retrieve-posts.md?locale=en_US)

X 官方开发指南对非API采集、模型训练、删除及展示有单独限制；本项目仍仅走官方路径。开发指南列出的删除期限包括源内容移除后24小时、API access终止后10个工作日等；实施前须核对实际合同和可用删除通道。摘要推理是否允许与禁止训练分开判断，禁止训练不直接推论所有推理都允许或都禁止。[X开发指南](https://docs.x.com/developer-guidelines)、[Developer Policy](https://docs.x.com/developer-terms/policy)

## 4. 路径选择、成本与平台特有验收

优先级依据用户目标、零供应商费用、允许的数据用途和现有实现复用程度定性判断；没有触达人数、工时或意愿数据，不编造RICE分数。**当前先完成本机免费路线顶层合同，优先离线核验Threads作者/搜索、Instagram公开作者与B站热门；微博/B站其他路由及抖音作者/话题分别解决风控/浏览器前置；X、Facebook保留免费路径缺口。** 这表示研究优先级，逐路由风险可能改变首批选择，实际执行顺序和WP状态只在PLAN007-01，总体未完成范围汇总至BACKLOG。官方接口可作为范围依据，当前不以申请付费权益为关键路径。

| 路径 | 适用选择 | 必须取得的决定/证据 |
|---|---|---|
| 发布方 RSS/Atom | 当前优先；原生订阅及允许的使用范围明确 | 逐源核对身份、正文、时间、频率、留存/展示与删除，固定订阅流标本地过滤，不称平台原生搜索 |
| 本机 RSSHub/网页或 JSON 适配 | 当前候选；具体路由零费用且行为可约束 | 固定源码/镜像、路由、参数、下游主机与身份，核对自动回退、缓存和风控；本机地址只作为受控连接例外，不能放开任意内网。X现有官方API边界不由RSSHub解除 |
| 本机 Firecrawl/SearXNG | 正文补齐/网页发现工具，各按允许来源使用 | Firecrawl不提供通用作者/关键词平台合同；SearXNG索引不证明源站全量覆盖。不启用收费云端fallback或模型提取，来源正文和已有内容身份保持一致 |
| 官方免费接口 | 零费用与允许用途均有证据时另行准入 | 端点/版本、主体、审批、字段/输出权、免费配额与硬限、删除同步；有免费额度不表示已获本项目权限 |
| 收费API/数据供应商 | 当前排除；只保留调研背景 | 不采购、不调用、不自动降级到收费服务；未来改变路线须由用户另行决定 |
| 用户主动提交链接 | 可用于独立发现/导入评估 | 保存链接不自动抓正文，远端处理仍需来源准入和显式任务；不能替代关键词或持续作者订阅 |

本次供应商调用预算为零；本机服务仍消耗请求、CPU、内存、存储和维护时间。资源量按来源合法运行次数、RSSHub缓存命中/实际更新、Firecrawl调用数及正文规模分别测量；一次调用本机服务可能触发多个下游请求，不能将本机调用数冒充平台请求数。无下游计量时明确“未知”，用固定路由及有界执行限制负载，不宣布全链精确请求预算已通过。

除共享AC外，若未来启用对应官方接口，平台准入仍须包含以下反例；当前免费路由的反例与风控另见 Design007 §11：

- Threads：未批公共搜索只返回自身帖子；Standard示范账号不能代验普通目标；profile lookup/profile posts不返回少于100粉或私密目标；单帖读取的tester/Advanced边界单独验。敏感词空数组保留限制说明，自身 replies 权限不能外推公共评论。
- Instagram：普通consumer账号、未获公共发现权限、第31个新标签等边界；按实际能力核对，不人为制造超额外部请求；仅有媒体ID不能证明有正文/评论读取权。
- Facebook：Page Search返回主页信息不算帖文搜索；开发者自有Page不能代验非自有Page的PPCA；第三方Page字段/用途和撤回逐项核对。
- 微博：先核验认证后的命令目录/积分与服务资格，分别验证账号/关键词/热搜；长文和分页不完整标受限；七天体验权限不外推正式套餐。
- 抖音：新旧scope/生产版本分开，新搜索的后台持续监控用途、最新排序和分页须实测；离线榜延迟按每日更新机制说明，授权列表不外推任意作者。
- Bilibili：授权UP主、任意公开UP主、关键词、评论正文和热榜分开；本人MediaCrawler固定试点与停止合同保持，授权稿件成功不关闭公开订阅目标。

## 5. 证据可读性与复核要求

Meta部分旧路径在检索工具返回429；本次研究通过官方 canonical `documentation/... .md?locale=en_US` 读取正文，官方Postman仅作补充。微博官方CLI为动态网站，核对的是其自行引用的公开前端资源中用户可见手册；本次资源路径为 [index-CzIwDaAm.js](https://open.weibo.com/cli/assets/index-CzIwDaAm.js)，含2026-09-21更新的命令手册，资源哈希路径随网站升级可能变化。知乎动态文档的证据是官网前端实际请求的公开文档目录JSON，不能把读取文档目录当真实内容API验收。

抖音新搜索部分正文来自官方索引，公开页直接读取为目录壳；Bilibili部分文档为动态页，任意公开检索证据不足。实施前用当前官方控制台/完整文档及获准账号补齐版本、条款、字段和费用，再记录原文、日期与证据。不把搜索摘要、旧博客、公开前端手册或HTTP200当生产权限及合同。
