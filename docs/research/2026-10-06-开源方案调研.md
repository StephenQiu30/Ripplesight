# 舆情监控开源方案调研

资料核验日：2026-10-06。星数、许可证和最近推送时间来自 GitHub API；只读取了公开元数据和页面，没有登录任何平台。

## 结论

- **直接接入**：MediaCrawler（评论，已用于 B 站）、RSSHub 的 twitter 路由、twscrape（单账号）。
- **改编并署名**：newsnow、DailyHotApi、twscrape（均为 MIT）。
- **只参考设计**：BettaFish（GPL-2.0）的“抽话题 → 定向深爬 → 情感分析”流程；TrendRadar（GPL-3.0）的关键词筛选与推送规则。
- **排除**：nitter（已归档）；weibo-crawler、Spider_XHS（无许可证）。

## X 趋势公开页面

| 页面 | 核验结果 | 结论 |
|---|---|---|
| [getdaytrends](https://getdaytrends.com/) | robots 无限制；页面返回 200，趋势名可直接解析 | 主入口 |
| [trends24](https://trends24.in/) | robots 允许；直接访问返回 403 | 备选，只经本机 Firecrawl 读取，失败即记失败 |

两者只有趋势名和热度量级，没有推文原文。
