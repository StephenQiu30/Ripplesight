# 术语表

| 术语 | 含义 |
|---|---|
| 主题 | 用户关心的一个话题，由关键词规则定义 |
| 关键词规则 | 任一词、全部词、排除词和别名的组合；保存后形成不可变的采集版本 |
| 运行快照 | 一次任务固定的主题/来源版本、实际查询、窗口、预算和分析规则；之后改配置不改变这轮含义 |
| 候选关联 | 本轮取到的内容与主题/查询/观测的关系，保存过滤理由；不复制一套正文库 |
| 来源 | 一个获取内容的入口，例如 HN 搜索、微博热榜、X 趋势页 |
| 免费取数 | 选定路径无必需付费 API、代理、打码、签名或买号；试用额度不算，代码免费不代表依赖服务免费 |
| 采集任务 | 一次对某个来源的获取，持久记录在数据库中，失败可以重试 |
| 到期 | 按设定频率（默认每小时）应该执行下一次采集的时间点 |
| 热榜快照 | 某一时刻热榜的完整排名，用来比较排名的升降 |
| 命中 | 一条内容符合某个主题的关键词规则 |
| 相关性 | 内容是否真正讨论用户关心的主题；不同于只出现同一个词 |
| 相似度 | 两段内容在措辞或语义上的接近程度；不自动证明同一事件或同样相关 |
| 候选召回 / 重排 | 先取得可能相关的内容，再判断或排序；重排不能找回未进入候选的内容 |
| 新鲜度 / 发现延迟 | 内容距发布多久，或系统距发布多久才发现；二者都不能用刚抓取代替刚发布 |
| P@10 | 前十条结果中人工判为直接相关的比例；不表示全网召回率 |
| 原生搜索 / 本地过滤 | 平台自己的搜索结果，或者先取订阅流再在本机按关键词筛选；两者覆盖范围不同 |
| 精选 | 去重后挑出的代表性报道，同一新闻只保留一条 |
| 事件 | 把描述同一件事的多条内容归在一起，并记录事实和进展 |
| 热度 | 按公式综合各来源的互动和排名得出的分数，可以复算 |
| 评论父链 | 评论属于哪篇帖子、回复的是哪条评论 |
| 页检查点 / 完成水位 | 前者记录已提交到哪页，后者表示声明范围的完整性已确认；截断或失败不能将两者混用 |
| 暂停 / 取消 / 来源停止 | 暂停阻止后续调度，取消终止这次运行，来源停止阻止该来源新请求直至人工恢复 |
| 功能 / 非功能需求 | 前者定义用户能做什么，后者定义正确性、性能、费用、隔离、恢复和可解释等质量要求 |
| 情感 | 对一条内容判断为正面、中性或负面 |
| 观点 | 从评论中归纳出的看法，每条都附原文引用 |
| 发布账号 | 公开页面内容所属的账号，由 `HOTKEY_PUBLIC_PUBLICATION_OWNER_ID` 指定 |
| 风控停用 | 登录平台出现验证码、登录失效或限流时自动停止采集，等本人人工恢复 |
| 可用 / 部分可用 / 未开始 / 冻结 | 能力状态，见[“可用”的定义](decisions/12-可用的定义.md) |
| 验收记录 | 一次真实验收的结果，存放在 `records/` |
