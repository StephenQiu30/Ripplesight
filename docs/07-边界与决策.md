# 07 边界与决策

所有能力共同遵守。改动任何一条，都需要本人明确同意，并在这里写明日期和理由。

| # | 决策 | 原因 |
|---|---|---|
| 1 | HotKey 仅供**个人非商业**使用 | MediaCrawler 等组件的许可只允许非商业用途；如果将来要商用，先替换这些组件 |
| 2 | **第三方服务费用为 0**：不购买 API、付费代理、打码服务或云端模型；会产生费用或计费方式不明的备用路径一律拒绝 | 控制成本，规避不可控支出 |
| 3 | **模型只用本机 Codex app-server**，用于相关性、情感、观点、写作和问答；每小时随采集批量运行，不设每日硬上限；账号被限流时延后处理，不丢任务 | 消耗的是本人 Codex 账号额度，不产生额外费用 |
| 4 | 只采**公开内容或本人账号能看到的内容**；不发帖、不点赞、不评论、不私信，不读私密账号或群组 | 降低法律和平台风险 |
| 5 | 需要登录的平台（B 站、微博、抖音、小红书、X）都用**本人单账号**；默认每小时一轮，单帖评论有上限；出现验证码、登录失效或限流就自动停用，等本人人工恢复；不用多账号、代理池或打码 | 降低封号风险；本人承担各平台条款风险 |
| 6 | **X 不用官方 API**：每日热点读公开趋势页（方案 A）；推文和回复走本人账号试点（方案 B，本机 RSSHub，twscrape 单账号作为备选）；源内容被删除后同步删除 | 2026-10-06 本人决定；本人知晓这违反 X 自动化条款，可能导致封号 |
| 7 | Reddit 只走官方 API + OAuth，本人申请获批之前一个请求都不发 | Reddit 明确禁止未获批的访问 |
| 8 | **优先复用开源项目**：MIT 许可的可以改编，并在 THIRD_PARTY_NOTICES 署名；GPL/AGPL 项目只参考设计，或作为独立服务运行（例如 RSSHub），代码不进本仓库；没有许可证的项目不用 | 不闭门造车，同时守住 MIT 仓库的许可边界 |
| 9 | 账号 token 和 Cookie 只放在本机 `.env` 或独立的浏览器配置目录里，不进日志、数据库明文、证据文件或前端；代理（AI 助手）不经手明文 | 防止凭据泄露 |
| 10 | 数据库结构只以 `backend/database/schema.sql` 为准；测试只用独立的 `hotkey_test_*` 库，用完清理；业务库升级按 [PROJECT §6](../PROJECT.md#6-数据库) 执行 | 防止误删真实数据 |
| 11 | 冻结：对外分发（RSS/只读 API/MCP/Agent Markdown、SEO/IndexNow、分享海报）、Instagram/Facebook/Threads、Flutter App、通用浏览器采集 | 2026-10-06 本人决定，集中精力做阅读和舆情 |
| 12 | 只有用本机真实数据跑通、用户能在页面看到结果，才算“可用”；单元测试、受控测试或模拟数据通过都不算 | 防止文档状态误导方向 |

## 开源组件清单

| 组件 | 许可 | 用途 |
|---|---|---|
| RSSHub | AGPL-3.0（独立服务） | 热榜、X twitter 路由 |
| Firecrawl、SearXNG | 独立本机服务 | 正文提取、网页发现 |
| MediaCrawler | 非商业学习许可 | B 站、微博、抖音、小红书的帖子与评论 |
| twscrape | MIT | X 回复补充（单账号） |
| newsnow | MIT | 补充热榜的参考 |
| AIHOT | 见 THIRD_PARTY_NOTICES | 精选、事件、出刊、模型榜的参考实现 |
| BettaFish、TrendRadar | GPL | 只参考设计 |
