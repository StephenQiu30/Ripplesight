# 06 模型榜与 Codex 公告

## 1. 要解决的问题

关注 AI 的读者想要一份有依据的模型排名，也想知道 Codex 额度什么时候会重置，而不用自己去翻多个榜单网站和 X 帖子。

## 2. 功能

- **模型榜**：从多个公开榜单汇总模型排名，支持分类、开放权重、国内开发方等筛选；可以查看模型详情、排名方法和数据来源；每天更新 4 次；不登录也能看已发布的榜单。
- **Codex 公告**：跟踪固定作者在 X 上发布的额度重置公告，识别预告、进展、完成和撤回，用时间线和日历展示，并支持人工复核；预测结果不冒充用户实际到账的额度。

## 3. 做法

- 模型榜在 `leaderboard` 领域，计算方法参考 AIHOT，署名见 THIRD_PARTY_NOTICES；页面在 `/leaderboard`。
- Codex 公告页面在 `/codex-resets`；公告来源是 X，按 [03](03-每日社媒热点.md) 的方案 B 用本人账号读取，不用官方 API。

## 4. 现状

| 项 | 状态 |
|---|---|
| 模型榜计算、页面、定时刷新 | 部分可用：代码完成；用真实来源抓取、排序、发布到页面的完整流程还没有跑通 |
| Codex 公告识别、页面 | 部分可用：识别逻辑和测试完成；X 采集未接通，还没有真实公告数据 |

## 5. 验收标准

1. 用真实来源完成一轮“抓取 → 排序 → 发布 → 页面可见”，排名可按公开的方法复算。
2. 连续 3 天每天 4 次按时刷新；某个来源失败时，沿用它上一次的数据并标明。
3. Codex 公告：拿到 ≥3 条真实公告，状态识别正确；人工改判后，页面和日历同步更新。

## 6. 不做什么

- 不把种子价格当作实时报价。
- 不预测用户个人实际到账的额度。
