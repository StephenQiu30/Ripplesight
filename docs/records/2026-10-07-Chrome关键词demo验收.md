# Chrome 关键词 demo 真实与定时验收

## 做了什么

按用户最新授权和[POC 卡](../research/2026-10-07-国内平台关键词监控POC验证.md)，复用当前 Chrome 的 B 站登录；本机 cookie-source 1.3.3 只提供 B 站会话，凭据不落产物。独立本机 demo 没有启动全局 Worker 或写业务库。运行、暂停、恢复步骤见[运行说明](../research/2026-10-07-Chrome关键词demo运行说明.md)。

## 结果

- 2026-10-07 16:05:33–16:05:34（北京时间）真实搜索 `DeepSeek`：5 条候选、2 条关键词命中，首轮 4 次来源请求，另有准入探测 2 次，已一并计入日预算（6/60），API 费用 0。
- 真实视频 ID：`117398585805089`、`117398485075678`。首条发表于 16:05:14，首次采集 16:05:34；这是本次样本约 20 秒延迟，不能外推为稳定时效。
- 首轮两个评论请求返回空列表；自动次轮取得 1 条真实根评论，关联原帖并保留来源 ID、原文和时间。楼中楼及已见帖的新评论增量仍未验证。
- 为验证真实定时触发，16:22:38 配置一次两分钟后到期的验收轮次，预算不重置；16:25:15 由 LaunchAgent 自动实采（60 秒检查粒度），取得 2 个新帖和 1 条根评论，累计 4 帖/1 评论、日预算 10/60。下次自动排到 17:25:15。短间隔验收不等同于连续小时或长期稳定运行；改期依据保存在本机 schedule-verification.json。
- 16:03 首次运行错误地把桥接 digest 当作 Cookie 文件校验和，停止于本机解析、来源请求为 0；依据服务源码改为账户摘要格式校验，保留失败轮次。没有来源风控或验证码响应。
- 初次 LaunchAgent 日志目录被 macOS 拒绝；日志迁到 Application Support 后正常运行，未调整系统安全设置。
- Ruff、格式、mypy 通过；1593 项单元/架构测试通过（含本轮 8 项）。独立测试库集成检查以 maxfail=1 停止：253 通过、13 跳过、1 失败；既有覆盖率接口应返回分析异常计数却返回 null，本轮未修改该逻辑。两次测试库均已删除。
- workspace check/build 通过，25 项工具测试和 42 页索引通过；桌面与 390px 阅读、评论展开已核对，无页面横向溢出。未覆盖完整前端五态，不宣称 Web 全体验验收通过。

本记录仅对用户最新要求的“真实并且可以定时获取关键词信息”标记通过。完整卡仍缺连续小时运行、已见帖评论增量、正式账号归属、语义评估与用户反馈；单个平台通过不代表全部国内平台可用。

## 怎么复核

打开本机 [demo](http://127.0.0.1:8669/)，核对原文链接、发布时间、首见时间、最近调度检查与运行记录。结果和预算在 `.tools/keyword-demo/deepseek/state.json`，桌面截图在 `.tools/keyword-demo/desktop.jpg`；均被 Git 忽略，不发布到知识库网页。电脑休眠或关闭 Chrome 时，采集可能延后或暂停。
