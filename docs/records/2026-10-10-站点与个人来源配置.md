# 站点与个人来源配置

## 做了什么

- 需求：站点与个人来源配置、层级页面路径、移除额度统计。
- 核对 `/api/publication/items` 的 `source_status`：读取固定发布账号的编辑来源与公开发布策略。当前11个来源是历史持久配置，0条资讯和8个降级来源并不代表前端内置列表。本轮只读业务来源。
- 探索页筛选只取配置目录，配置名称不再被资讯名称覆盖；事件时间线同样读取配置目录，空目录与读取失败分开展示。
- 站点页从 `/editorial-sources` 迁至 `/sources/editorial`。个人页 `/sources/personal` 通过会话和CSRF管理自己的 RSS、网页、JSON 列表，初次保存停用；许可条件不足时拒绝启用并保留草稿。
- 个人来源复用原版本、审计、任务和许可链路，以 `ed_personal_` 区分并保持现有 schema 合同，不自动公开。服务端校验owner、命名空间、幂等重放与预期修订；图标种子兼容个人来源身份。
- 未知写入结果锁定输入并只重放相同操作。版本冲突可重读列表、保留草稿，再显式打开最新修订编辑。
- 删除 Codex 额度统计与管理页面、工作台链接及榜单区块；历史数据及后端合同保留，旧公告链接指向仍存在的阅读入口。

## 怎么复核

1. 以站点发布账号打开 `/sources/editorial` 管理公开来源；探索页核对配置目录和配置名称。
2. 普通登录账号打开 `/sources/personal`，创建停用RSS、网页或JSON列表；确认另一账号不可读取或修改，且公开策略拒绝纳入个人来源。
3. 两窗口修改同一来源，旧修订保存应冲突并保留草稿；重读、重新编辑后可按新修订保存。未知网络结果重试须使用相同操作ID与请求体。
4. 设置独立测试库和Redis、Kafka、MinIO环境，复跑后端全部检查；运行Web全部检查和契约检查，结束清理测试资源。
5. 复核双尺寸状态、旧路径404与统计入口删除，真实外采单独验收。
