# AIHOT 全量业务迁移需求

用户于 2026-10-02 明确选择：全部迁移 AIHOT 业务，包含模型榜、Codex 重置公告、月报与海报；保留 Python/FastAPI、Next.js、Kafka。迁移持续推进，以全部功能闭环为退出条件，不能只交付提示词、算法、接口、静态页面或部分领域。

参照代码固定为 `035f7b7f6e26cf203562ddd6065ff7adc1bb0c07`。源代码、线上宣传和本项目实现分别判断，未在固定开源代码中实现的线上功能不据宣传推定存在。完整业务范围包含以下所有模块；原有 FR/AC 和未通过条件保持有效。本文只定义新增范围，采集/事件/报告/通知/分发已经明确的功能仍由 PRD002/004/005/006/007 持有。

## 1. 完整范围与兼容目标

原有主题规则、来源版本、帖子与评论父链、原生热榜快照、覆盖和预算、证据生命周期、失败恢复、日报及 Obsidian 必须保留。业务 Demo 继续匿名，不恢复 ToC 用户注册；上游管理员身份作为运营控制能力独立承接，不将管理员与平台采集账号或报告收件人混为一体。

迁移覆盖以下实际业务链路：信源配置/采集/外部摄入 → 材料身份与修订/正文质量/媒体 → 行业预筛/精选评分/结构化/中文写作/全文翻译 → 事实与故事/人工修订/独立参与者热度 → 全部动态/精选/搜索/分类主题/本机收藏已读 → 日周月刊 → RSS/API/MCP/Markdown/SEO/分享 → 内容通知/运维告警/调用回执/恢复/备份。模型榜及 Codex 公告监控各自拥有采集、持久状态、读取、页面和定时执行闭环。

“完整”指获准启用后的真实用户操作和持久结果一致，不要求复制上游的已知缺陷、商标、部署拓扑或供应商。真实调用暂停、凭据/费用/许可未定时，功能仍须实现受控路径和明确禁用原因；未执行的真实验证保留未通过，不能以模拟结果宣布完整迁移已验收。

## 3. 整体退出条件

所有源处理器、业务状态、定时任务、HTTP/MCP/RSS 出口、生成客户端、页面和管理员操作逐项可追踪，无仅配置/仅枚举/仅占位的完成项。受控测试验证正常、失败、并发、撤回、修订、幂等、预算与重启；实际 PostgreSQL/Kafka/对象存储和浏览器验证接入。各真实来源、模型质量、渠道送达及既有持续窗口单独留证，前置条件未满足即保留未通过。原 HotKey 操作与数据回归无损后，才撤下被替代的路径。
