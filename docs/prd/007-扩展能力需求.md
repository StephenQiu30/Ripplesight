# 扩展能力需求

本文定义该能力的产品要求，设计见 [Design007](../design/007-扩展能力设计.md)，当前工作见 [BACKLOG](../../BACKLOG.md)。

## 1. 目标与范围

**目标**：研究者按来源逐项准入指定账号和后续平台，并分别使用告警、报告或原始数据导出。

**用户问题与预期结果**：关键词可能漏掉指定作者的新内容，用户也难以持续盯住负面或事件变化；站内报告还需要可核对的文件供个人整理。对应结果是获准作者的新帖按既定范围收录、有依据的阈值告警及固定版本文件，各自显示权限、缺口和失败。需求价值和使用频率仍是待验证假设，不以竞品覆盖宣传推定所有平台都可持续接入。

**不包含**：把 M1 热榜或其他来源的结果视作后续登录平台、账号追踪或告警的验收；未经凭据与月度上限确认的 X 真实请求；绕过验证、商业爬虫、全站/全历史/全量评论保证。高级导出不包含报告生成，指定账号追踪不扩展本人 B 站试点的许可、账号主体或评论层级。

## 2. 用户场景与状态

- 逐来源核对授权、能力与真实采集证据后，查看指定账号新帖或后续平台内容；公开热榜结果不算登录来源接入。
- 已启用 M5 渠道后核对负面内容或事件热度一小时阈值触发的告警与冷却时间。
- 从有权限的真实报告或原始数据导出 Markdown/PDF、CSV/JSON，核对引用、版本、字段脱敏与失败状态。

身份、个人数据归属及会话遵守 [总需求 §2.1](001-热点舆情监控平台需求.md#21-toc-用户登录需求) 与 [Design001 §9.2](../design/001-热点舆情监控平台总体设计.md#92-公开欢迎页登录与个人数据访问)。

## 4. 功能需求

| ID | 功能 | 要求 |
|---|---|---|
| FR-007-001 | 导出增强 | 有权限的用户选择固定报告版本导出 Markdown/PDF，或选择获准原始数据范围导出 CSV/JSON；受理时冻结对象/内容版本清单、时间窗、格式及渲染/字段版本，提供任务、失败原因和下载结果。文件保留出处、引用、程序数字、缺口与正文许可边界，未知值不写成零；CSV 防公式注入，PDF 中文与分页可读。生成与下载分别复验当前权限和撤回状态，秘密或其他用户资料不得导出；超限明确失败，不把截断产物当完整文件。沿用 Design007 的有界规模，失败不改源报告或内容。已有公开 Markdown 出口、浏览器打印和格式枚举不代表本项四种文件均完成。 |
| FR-007-002 | 突发告警 | 获准用户配置对象、最近一小时负面内容计数或事件热度变化的阈值、冷却时间及已通过 M5 的接收目标，规则默认关闭；事件热度类规则使用 M3 已验收的有效、可比事件/热度输入，负面内容类规则使用 M4 已验收的有效情感输入，按 Design007 的周期评估所选规则。触发记录固定规则与输入版本、适用的事件版本、窗口、实际值、阈值与原因，去重与冷却持久化；缺失有效情感或不可比热度显示无法判定，不补零或以 M3 事件归并代替情感依据。发送前复验规则、目标与许可，执行中断/重放不重复触发；发送结果 unknown 占用冷却并按 M5 人工确认，不自动重发。配置表或通知通道存在不等于阈值评估及真实告警已经完成。 |
| FR-007-003 | 指定账号追踪 | 用户配置本人获授权的指定作者、稳定平台账号 ID、授权连接及来源节奏，显式启用后以作者列表能力采集获准窗口的新帖，全部收录且不受主题关键词限制；不能以昵称、别名表或关键词搜索代替作者扫描。保存稳定作品 ID、内容版本、发现窗口、分页/水位和停止证据，手动与合法到期执行共用去重及预算；仅可信尾段允许推进水位，部分、限流或权限缺口明确可见。停用、授权撤销或连接换版后禁止旧任务继续写入；阅读可回到真实原帖。新帖收录、已有作品修订及缺口分别核对，不承诺未准入的历史回补或平台全量覆盖。 |
| FR-007-004 | 后续来源 | Reddit 仅考虑当前显式获批的官方 API 路径及 OAuth，商业用途另须平台书面批准；核对公共 Data API 迁移/退役与现行合同，不能把 OAuth、旧端点或 Devvit 当作外部全站监测已获准。X 仅走官方 API 且凭据与月度上限确认前不发真实请求；小红书、抖音、微信公众号及其他登录平台分别评估许可、授权、分页、限流、身份与失败状态后逐能力准入；微博、知乎登录仍须分别独立核对准入，不得随热榜验收视作已接入；获准后独立验证真实采集与持久结果 |
| FR-007-005 | 来源准入证据 | 每个候选来源分别保存固定软件/服务版本的软件许可与平台/数据授权证据，记录原文出处、取证时间、允许用途、账号/身份范围、费用额度、留存/传播限制和待确认项。能力矩阵分别列原生关键词搜索、作品正文、顶层评论正文、回复正文及父链、增量/旧帖新评论、公开热榜；评论数等指标与评论正文分开。逐能力记录已验证、受限、未验证/未知、不支持或停用及证据边界；没有证据时保持未知，不从营销覆盖数、公开网页、Cookie、登录成功或 HTTP 200 推定身份、费用权益、数据授权或完整评论覆盖。未决许可、身份与费用条件不记作准入通过，资料核查不替代逐能力真实采集验收 |

Reddit 官方依据（访问日：2026-10-04）：[Responsible Builder Policy](https://support.reddithelp.com/hc/en-us/articles/42728983564564-Responsible-Builder-Policy)要求显式 API 批准及商业用途书面批准；[应用登记](https://developers.reddit.com/app-registration)与[公共 API 迁移公告](https://www.reddit.com/r/redditdev/comments/1wubcvf/moving_data_api_apps_to_the_developer_platform/)说明 2026-10-31 停止新的公共 API 申请、2027-01-12 处理未登记/未参与迁移应用、2027-03 结束剩余公共访问。该公告不等于商业许可合同或所有 Devvit 能力一并关闭；具体适用路径须再次核对。[官方基础设施公告](https://www.reddit.com/r/modnews/comments/1wubgvt/continuing_our_infrastructure_updates_whats/)说明 RSS 于 2026-11-13 停止支持，不能作为长期免费基础来源。上述资料不证明 HotKey 已获准或已接通。

作者扫描、告警评估与高级文件导出各自须有受理、持久结果、恢复和实际读取/送达；资料登记、配置/枚举、公共分发出口和既有账本只提供基础，不能替代完整功能。来源准入将公开阅读、官方 API 授权、平台账号登录及软件许可分开核对；官方接口只覆盖本人或授权账号时，不能描述为任意作者或全站检索。新内容增量和旧帖新增评论分别验证，评论完整性只在指定来源、权限、时间窗、取样范围与可信尾段内成立。

## 7. 依赖、决策与未决项

- **依赖**：导出依赖有权限的真实报告/数据；突发告警按所选规则依赖 M3 有效事件/可比热度或 M4 有效情感，两类均依赖 M5 已验渠道；新增平台和指定账号逐来源准入。X 凭据与月度上限未定前禁止真实请求。
- **决策/未决项**：沿用总需求 DEC-001-106/115/221/225；OPEN-001-104：X 凭据和月度上限；OPEN-001-107：知乎目标能力的数据入口与软件许可选择；各来源真实分页仍见 OPEN-001-108。本文不新建 DEC/OPEN。
- **对应 Design 章节**：[Design 007](../design/007-扩展能力设计.md) §1—9；X 官方 API 的准入仍按总需求 OPEN-001-104。
- **实施前提**：FR-007-005/AC-007-005 的许可/授权记录、逐能力状态及证据关联按 Design007 定标，排期时补该能力执行步骤；准入研究材料不自动证明实施合同通过，不新增来源、付费请求或真实登录操作。
- **就绪与未知条件**：作者追踪先有明确目标及获准作者列表能力；告警按所选规则先有 M3 有效可比事件/热度或 M4 有效情感、阈值/冷却和 M5 已验渠道，缺少对应输入时保留无法判定；高级导出先有有权限的固定版本材料、字段及规模约定。数据用途、软件许可、商业授权、费用或身份未定则保留阻断/未知；不为补样本扩大本人 B 站或付费调用范围。用户对作者追踪、告警和文件整理的实际价值需后续观察验证，不预设市场份额、收益或工期。
