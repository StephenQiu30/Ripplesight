# 本人账号B站试点需求

本文定义该能力的产品要求，设计见 [Design003](../design/003-本人账号B站试点设计.md)，当前工作见 [BACKLOG](../../BACKLOG.md)。

POC 阶段先验证三类版本、风控即停、人工恢复和低频采集的功能链路；本人账号真实操作仍由用户显式控制。连续 72 小时与最终时效比例在后续产品验证阶段核对，短窗或受控回放不关闭依赖连续运行的 AC。

## 1. 目标与范围

**目标**：本人检查独立 CDP 资料并显式启用 B 站后低频搜索；遇验证、登录失效或访问频繁立即停用，检查后人工恢复。

**不包含**：微博、知乎等其他登录平台；B 站楼中楼、完整历史覆盖；M1 六榜中的 B 站热门不等于本人账号接入。

## 2. 用户场景与状态

- 本人核对固定补丁版本、独立 CDP 资料、端口与预算后显式启用 B 站，低频搜索并查看视频、同轮一级评论及相关性。
- 遇验证码、登录失效或访问频繁时查看来源停用与未受理窗口；本人检查后显式恢复，再核对低频真实采集。
- 按六小时来源节奏回看连续 72 小时窗口，区分静默、实际尝试、失败与缺口，并核对风控和分析时效。

身份、个人数据归属及会话遵守 [总需求 §2.1](001-热点舆情监控平台需求.md#21-toc-用户登录需求) 与 [Design001 §9.2](../design/001-热点舆情监控平台总体设计.md#92-公开欢迎页登录与个人数据访问)。 产品登录不替代本人B站授权与固定版本许可核查。

## 3. 业务需求

| ID | 业务需求 | 成功判断 |
|---|---|---|
| BR-003-001 | 安全试用本人账号平台 | 该能力只试 B 站；低频、独立资料，风控信号立即停用并由用户人工恢复 |
| BR-003-002 | 在预算内长期、安全地运行 | 本人账号来源在预算内低频、安全运行；账号风控或来源故障不会静默吞掉任务和缺口。 |

## 4. 功能需求

| ID | 功能 | 要求 |
|---|---|---|
| FR-003-001 | 评论采集 | 保留评论身份与父链，按来源预设限制：B 站只读同轮缓存的一级评论每帖 ≤ 20，暂不采楼中楼。 |
| FR-003-002 | B 站试点控制 | 仅本人账号、公开可见内容；MediaCrawler 只在宿主机从固定补丁版本工作树以子进程运行，运行前校验补丁后 HEAD 与已跟踪文件无改动，并将上游基线、补丁后提交、实际适配器版本三类证据关联 Job，不能混作单一组件版本。固定上游及补丁版本的软件许可原文、用途核查记录与平台/数据授权分别留证，本人账号可见性不代替软件许可或数据使用范围。使用独立且私有的 CDP 资料、输出目录及仅绑定 `127.0.0.1` 的调试端口。同一轮缓存供评论读取；来源级互斥、进程组截止/取消回收及显式来源开关；风控后用户检查再人工恢复 |

较新的上游版本不代表升级或替换当前 `mediacrawler-1bd` 固定基线，也不代表其许可结论已覆盖本地补丁。实际试点须从固定上游与补丁版本分别核查许可原文、用途限制、核查时间及未决项；软件使用许可与平台/数据授权均不能由公开仓库、账号登录或功能矩阵推定。保留个人/非商业研究用途、一级评论每帖 ≤ 20 和不采楼中楼的现有边界，许可或用途待确认时不得写作已具备对应准入条件。

## 5. 非功能需求

| ID | 要求 | 验收口径 |
|---|---|---|
| NFR-003-001 | 本人账号风控 | B 站等本人账号来源以不触发风控为硬上限；遇验证码、滑块、扫码/登录失效或访问频繁立即停该来源及后续调度，记录认证或限流原因，不破解、不自动换号或绕过、不自动恢复；必须由本人核查后人工重启。频率、条数、请求和并发按来源配置 |

## 7. 依赖、决策与未决项

- **依赖**：M1 的采集、相关性、覆盖与任务边界可复用，但 B 站自身须独立验收；本人账号、固定补丁 MediaCrawler 工作树、独立私有 CDP 资料、用户人工检查与恢复是外部条件。
- **决策/未决项**：沿用总需求 DEC-001-214/217/220/221/225；B站分页与评论节奏按OPEN-001-108收集真实样本。AC-003-004依据本地NFR-003-002独立核对M2时效。
- **对应 Design 章节**：[Design 003](../design/003-本人账号B站试点设计.md) §1—9；来源预设节奏见 [Design 002 §3.1](../design/002-信息获取主链路设计.md#31-来源预设与连接)。
- **实施前提**：该能力许可核查记录的固定版本关联、待确认处理及 AC-003-001 前置核对按 Design003 定标，具体核对步骤在排期时补充，不以研究记录代替真实来源验收。
