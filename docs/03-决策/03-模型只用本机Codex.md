# 模型只用本机 Codex

## 决策

**模型只用本机 Codex app-server**，用于相关性、情感、观点、写作和问答；每小时随采集批量运行，不设每日硬上限；账号被限流时延后处理，不丢任务。不调用付费模型接口。

## 原因

消耗的是本人 Codex 账号额度，不产生额外费用。
