# 数据库结构只有一个来源

## 决策

数据库结构只以 `backend/database/schema.sql` 为准；测试只用独立的 `hotkey_test_*` 库，用完清理；业务库升级按[技术架构](../01-产品/03-技术架构.md)中「数据库」一节执行。

## 原因

防止误删真实数据。
