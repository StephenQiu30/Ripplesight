# 登录平台用本人单账号

## 决策

需要登录的平台（B 站、微博、抖音、小红书、X）都用**本人单账号**；默认每小时一轮，单帖评论有上限；出现验证码、登录失效或限流就自动停用，等本人人工恢复；不用多账号、代理池或打码。

## 原因

降低封号风险；各平台的条款风险由本人承担。
