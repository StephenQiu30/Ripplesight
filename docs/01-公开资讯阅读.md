# 01 公开资讯阅读

## 1. 要解决的问题

读者不想登录、不想自己订阅几十个来源，只想在一个页面读到**持续更新、不重复、有出处**的资讯与事件。

## 2. 功能

- 不登录打开首页，看到资讯流、精选、事件和公开日报/周报/月报，每条都能打开原文。
- 同一新闻只出现一条代表报道；没有新信息的跟进不刷屏；新接入来源的历史旧文不当新内容推送。
- 模型关闭时仍能读到原始资讯与按规则生成的刊物。
- 只展示指定“发布账号”下、来源许可允许公开的内容；来源撤回后各页面不再显示。

## 3. 做法

- 公开内容全部来自配置项 `HOTKEY_PUBLIC_PUBLICATION_OWNER_ID` 指定的发布账号；未配置时公开页面显示“未发布”，不会自动挑选某个账户。
- 采集、去重、精选、事件归并、出刊复用 `sources`、`content`、`analysis`、`events`、`publication`、`reports` 领域，详见 PROJECT。
- 精选去重、事实证据抽取、事件关系判定、事件概览、按规则出刊、旧文不刷屏参考开源项目 AIHOT 实现，署名见 THIRD_PARTY_NOTICES。
- 页面：`/`、`/discover`、`/items/[id]`、`/events`、`/editions`、`/reports/daily|weekly|monthly`。

## 4. 现状

| 项 | 状态 |
|---|---|
| 匿名首页与阅读页 | 可用：本机 8666 可匿名阅读；arXiv、Crossref 两个真实来源经正常任务链各入库 20 条 |
| 精选去重、事件归并、按规则出刊、旧文不刷屏 | 部分可用：代码已合入并通过隔离数据库测试；依赖模型的判断质量要等本机 Codex 启用后评测 |
| 更多公开来源 | 部分可用：六类来源新增准入已记录首轮采集，持续运行未验证 |
| 持续稳定运行 | 未验证：没有连续 72 小时的运行记录 |

## 5. 验收标准

1. 连续 72 小时内，公开资讯流至少每 2 小时有新内容，且到期采集的有效完成率 ≥95%。
2. 固定抽样 50 条：每条能打开原文，同一新闻重复出现 0 次。
3. 模型关闭时，日报、周报、月报各至少按规则生成 1 期，内容和条目来源可复算。
4. 撤回一个来源后，所有公开页面在下一次刷新内不再显示其内容。

## 6. 不做什么

- 不做对外分发（RSS/只读 API/MCP/Agent Markdown、SEO/IndexNow、分享海报），这部分已冻结。
- 不自动公开任何个人主题、报告或评论。
- 不做跨设备收藏同步。
