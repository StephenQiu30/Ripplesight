# Ripplesight 页面与功能需求

产品目标与公共验收见 [PRD](../prd/PRD.md)，视觉和交互见 [Design](../design/DESIGN.md)，执行顺序见 [Plan](../plan/PLAN.md)。

下表维护当前页面字段、数量和操作，区分主要流程与辅助功能。数量与缺口是现有合同边界，接口变化时直接更新本表；请求和响应类型以仓库中的 `frontend/src/api/` 与 `backend/app/api/routers/` 为准，不再逐页复制接口和表字典。

| 页面／路由 | 范围 | 当前需要展示的数据和操作 |
|---|---|---|
| 今日热点 · `/` | 主要流程 | 四项全站指标（当前未知）；首屏6个事件，读取最多50条逐批展示；上升5项、X趋势6项与最新日报；窗口不混用 |
| 探索资讯 · `/discover` | 主要流程 | 搜索与筛选：URL保存条件；搜索40条，普通30条，精选时间线20条；结果与专题：服务端过滤；下一页cursor；专题独立读取 |
| 公开专题目录 · `/discover/topics` | 辅助功能 | 专题目录：当前返回目录；后端按许可计算计数 |
| 公开专题详情 · `/discover/topics/[slug]` | 辅助功能 | 专题说明：单专题；精选列表：服务端每页20条，页码导航 |
| 公开事件目录 · `/discover/stories` | 主要流程 | 事件目录：一次最多20个热点，当前没有翻页控件 |
| 公开事件详情 · `/discover/stories/[eventId]` | 主要流程 | 事件概览：单事件及已有reports；进展与证据：进展每页20条，7天窗口 |
| 公开资讯阅读 · `/items/[contentId]` | 主要流程 | 文章与许可：单条正文；目录由正文生成；阅读状态：单条交互；滚动位置按id+revision在本机保存；上下文：按需读取关联组，每批20 |
| 收藏与阅读记录 · `/discover/starred` | 主要流程 | 类型/最近或最早排序、20条/页本机回读、2000字备注、选择/取消/Markdown导出；多类型与关注仍待接入 |
| 最新公开刊物与个人报告详情 · `/reports/[reportId]` | 主要流程 | 公开最新刊物分支：目录最多6期，取最新详情和前后期；元数据另取最新1期；个人报告分支：单报告详情及显式导出 |
| 公开固定刊期阅读 · `/reports/[reportId]/[key]` | 主要流程 | 固定刊期：一份冻结刊期，正文一次读取；导航：并行读取，独立失败 |
| 公开刊物归档 · `/reports/[reportId]/archive` | 主要流程 | 归档列表：每页20期，before_key翻页；日历：daily分支按月；周/月刊不虚构日历 |
| 模型综合榜 · `/leaderboard` | 主要流程 | 4维度、同一run排名/类型/支持指数/变化、每周动态与公告；长上下文/变化暂无合同 |
| 模型分项榜 · `/leaderboard/category/[board]` | 主要流程 | 分项榜：一份现有board响应，复用综合榜组件 |
| 模型详情 · `/leaderboard/models/[slug]` | 主要流程 | 模型概览：单模型；证据与比较：响应分组，比较内容折叠展开 |
| 评测来源目录 · `/leaderboard/sources` | 主要流程 | 来源目录：完整配置目录；按返回组显示 |
| 评测来源详情 · `/leaderboard/sources/[sourceKey]` | 主要流程 | 来源说明：单来源；原始成绩：当前快照行，表格内滚动 |
| 模型榜计算规则 · `/leaderboard/rules` | 主要流程 | 规则：一份随run版本固定的规则 |
| 登录与验证注册 · `/login` | 主要流程 | 登录表单：一次认证动作；仅服务器公布已配置方式；登录能力和侧栏：登录选项1次；热点最多3条且失败独立 |
| 账户与订阅设置 · `/account` | 主要流程 | 账号资料：当前账户1份；更新后读回；凭据与订阅：明确保存或绑定，不自动提交 |
| 个人工作台入口 · `/workspace` | 辅助功能 | 复用监控主题工作区；管理入口收进更多 |
| 监控主题工作区 · `/topics` | 主要流程 | 全宽主题列表位于详情上方，连续关键词/小时命中/采集平台/规则/最近告警；结果、运行和设置次级展开，保留草稿和幂等 |
| 新建监控主题 · `/monitors/new` | 主要流程 | 新主题表单：一次创建；来源选择来自可用能力；规则预览：按按钮预览，输入改变后旧预览失效 |
| 监控主题详情 · `/monitors/[topicId]` | 主要流程 | 复用监控主题工作区，深链接选择主题，权限与版本冲突保留 |
| 个人告警 · `/alerts` | 主要流程 | 规则表单/列表：规则列表当前未分页；主题50/页、事件100/页读取选项；评估历史：每规则最多50条 |
| 私有资料列表 · `/content` | 主要流程 | 筛选列表：20条/页cursor；选择项来源独立读取；网页采集入口：用户显式动作；后端域名准入 |
| 私有资料与评论 · `/content/[contentId]` | 主要流程 | 资料正文与出处：单身份及当前可读版本历史；评论树：根评论20条/页，回复另按20条加载；分析及刷新：切主题/版本读取；刷新评论明确点击 |
| 个人事件列表 · `/events` | 辅助功能 | 事件列表：20条/页；热点另读；热点摘要：当前服务返回热点集合 |
| 个人事件分析 · `/events/[eventId]` | 辅助功能 | 概览与固定修订：单事件，可选择已有revision；成员/事实/关联：成员20条/页；事实/关联按当前响应；热度与修订动作：历史最多48点；操作使用预期revision |
| 平台热榜快照 · `/hotlists` | 辅助功能 | 来源和快照：快照20条/页；选择一个快照；榜单条目：每批20条，继续加载 |
| 个人报告列表 · `/reports` | 辅助功能 | 报告过滤与列表：20条/页cursor |
| 刊期生产档案 · `/editions` | 辅助功能 | 刊期档案：20期/页，按kind/before_key；申请编选：一次显式申请，完成窗口才可编选 |
| 刊期内部详情与修订 · `/editions/[editionId]` | 辅助功能 | 内部刊物与修订：单期和修订列表；编辑：显式提交新修订 |
| 来源连接与采集覆盖 · `/sources` | 主要流程 | 来源连接：来源目录及选中连接；采集覆盖：窗口20条/页；详情单独读；固定时间窗；Chrome绑定：明确启用操作；不在页面存Cookie |
| 编辑来源配置 · `/sources/editorial` | 辅助功能 | 编辑来源配置：现有运营列表和表单；预览/材料/运行：材料20条/页；运行最多100条；先选来源；准入与图标：显式维护动作；令牌仅内存 |
| 任务记录 · `/jobs` | 主要流程 | 任务列表：20条/页cursor；连续失败：独立失败汇总 |
| 任务详情与恢复 · `/jobs/[jobId]` | 主要流程 | 执行详情：单job，显式刷新；有界窗口响应；恢复与取消：仅服务器允许状态可操作 |
| 公开许可与发布管理 · `/publication/manage` | 辅助功能 | 许可管理：运营逐来源或逐内容修改；分析与恢复：按需查询单任务 |
| 运营工作区 · `/operations` | 辅助功能 | 健康与维护：按当前API聚合；反馈与审计：反馈和审计20条/页；通知与评测：通知50条/页；评测明细50条/页 |
| 模型配置与成本 · `/operations/models` | 辅助功能 | 模型配置：一份配置；逐能力显式切换；成本与熔断：按天窗口汇总，确认成本异常需原因 |
| 站点联系配置 · `/site/manage` | 辅助功能 | 联系配置：一份站点配置，显式保存 |
| 意见反馈 · `/feedback` | 辅助功能 | 反馈表单：一次主动提交；限制以现有输入合同为准 |
| 关于 · `/about` | 辅助功能 | 产品说明：静态正文 |
| 隐私说明 · `/privacy` | 辅助功能 | 隐私说明：静态正文 |
| 使用条款 · `/terms` | 辅助功能 | 使用条款：静态正文 |
| 联系 · `/contact` | 辅助功能 | 公开联系：一份可公开联系配置；未配置给说明 |
| 变更记录 · `/changelog` | 辅助功能 | 变更说明：静态发布说明 |
| 个人来源 · `/sources/personal` | 主要流程 | 本人 RSS、网页和 JSON 来源的保存、编辑与启停；创建默认关闭，独立 owner 和许可，不自动公开 |


## 关键页面约束

| 页面 | 必须保留的业务行为 |
|---|---|
| 登录与注册 | 先验证邮箱或 GitHub 身份，再完善用户名和密码；不能凭账号密码直接创建未经验证的身份 |
| 告警 | 通知目标失效时拒绝保存；同一窗口不重复通知，评估、发送与送达分别记录 |
| 任务恢复 | 仅服务器允许的阶段可以重试，沿用任务冻结的配置；取消保留原资料，不偷换为当前新配置 |
| 模型配置与成本 | 模型切换仅影响之后受理的任务；成本按币种分组，不将不同币种直接相加 |
