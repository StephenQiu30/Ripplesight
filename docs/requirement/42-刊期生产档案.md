# 42 刊期生产档案

需求编号：`REQ-42`。来源：OR-11，确定程度见[00 产品目标与边界](../requirement/00-产品目标与边界.md#原始需求与来源登记)。优先级：保留重评；安全与核心阻断问题优先。本文定义目标与验收，实际状态只在根目录 BACKLOG。

## 用户任务

刊物编辑在“管理可发布的固定刊期”的场景中，需要管理刊期草稿、定稿及发布，以便有序编选与发布真实刊期。

## 范围与业务规则

日/周/月刊按周期和覆盖窗口唯一，草稿/定稿/失败/发布分开；生成、修订、发布为显式不同动作，社媒榜等模块保留证据。

- BR-42-01：生成草稿不自动公开。
- 共用权限、读取/写入状态及安全边界引用[00 产品目标与边界](../requirement/00-产品目标与边界.md#跨功能规则)、[10 权限与数据生命周期](../requirement/10-权限与数据生命周期.md)；本文件不复制第二份规则。

## 可验证验收用例

### AC-42-01 管理刊期生产

- **Given**：同一周期窗口重复生成，另有失败刊期；角色为刊物编辑。
- **When**：创建草稿、定稿并显式发布。
- **Then**：同刊期操作幂等，受理与成稿分别可核对。
- **反例**：尚未结束窗口不得冒充完整刊期，页面打开不启动生产。
