# 48 公开许可与发布管理

需求编号：`REQ-48`。来源：OR-12，确定程度见[00 产品目标与边界](../requirement/00-产品目标与边界.md#原始需求与来源登记)。优先级：保留重评；安全与核心阻断问题优先。本文定义目标与验收，实际状态只在根目录 BACKLOG。

## 用户任务

发布管理员在“只公开获准内容并及时撤回”的场景中，需要预览许可范围并显式发布或撤回，以便控制哪些内容何时允许公开。

## 范围与业务规则

来源政策与逐内容例外明确，延迟公开按生效时间；公开投影白名单；许可/定稿/发布独立，纠正或撤回立即影响当前与历史读取、缓存和导出。

- BR-48-01：私人源及作者账号不自动授权公开。
- 共用权限、读取/写入状态及安全边界引用[00 产品目标与边界](../requirement/00-产品目标与边界.md#跨功能规则)、[10 权限与数据生命周期](../requirement/10-权限与数据生命周期.md)；本文件不复制第二份规则。

## 可验证验收用例

### AC-48-01 控制公开许可与撤回

- **Given**：来源允许摘要但某内容拒绝；未来才公开一条；已发内容撤回；角色为发布管理员。
- **When**：预览白名单、发布、撤回并读取历史。
- **Then**：来源策略与逐内容例外可解释；公开投影即时执行当前许可。
- **反例**：个人材料不能默认公开，历史链接和派生物不能绕过撤回。

### 边界验收补充

Given 来源拒绝而逐内容允许、未来生效许可、已撤回旧修订；When 预览/发布/读历史；Then 最严格拒绝优先，未来不提前公开，旧修订不绕撤回。
