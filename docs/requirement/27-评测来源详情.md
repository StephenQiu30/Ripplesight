# 27 评测来源详情

需求编号：`REQ-27`。来源：OR-10，确定程度见[00 产品目标与边界](../requirement/00-产品目标与边界.md#原始需求与来源登记)。优先级：保留重评；安全与核心阻断问题优先。本文定义目标与验收，实际状态只在根目录 BACKLOG。

## 用户任务

模型比较读者在“复核某评测的协议与成绩”的场景中，需要核对评测协议与原始成绩，以便复核某评测成绩的适用范围。

## 范围与业务规则

展示协议版本、任务样本与评分方法、适用范围、原始成绩、时间、许可和署名；不可比轮次明确分开。

- BR-27-01：不复制许可不允许的题目全文。
- 共用权限、读取/写入状态及安全边界引用[00 产品目标与边界](../requirement/00-产品目标与边界.md#跨功能规则)、[10 权限与数据生命周期](../requirement/10-权限与数据生命周期.md)；本文件不复制第二份规则。

## 可验证验收用例

### AC-27-01 复核单个评测来源

- **Given**：同来源两协议和缺失原始成绩；角色为模型比较读者。
- **When**：选择协议和轮次核对原始证据。
- **Then**：原始成绩绑定快照及模型配置；无法对齐模型明确解释。
- **反例**：同步失败不覆盖旧有效快照为成功零条。
