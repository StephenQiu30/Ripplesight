# 28 模型榜计算规则

需求编号：`REQ-28`。来源：OR-10，确定程度见[00 产品目标与边界](../requirement/00-产品目标与边界.md#原始需求与来源登记)。优先级：保留重评；安全与核心阻断问题优先。本文定义目标与验收，实际状态只在根目录 BACKLOG。

## 用户任务

模型比较读者在“理解并复算名次”的场景中，需要按发布方法复算排名，以便理解并复算名次。

## 范围与业务规则

规定准入、分数转换、权重、并列、缺失值、排序及发布窗口；方法改版保留旧轮次，未达到准入说明排除。

- BR-28-01：未定义缺失处理或窗口不能发布排名。
- 共用权限、读取/写入状态及安全边界引用[00 产品目标与边界](../requirement/00-产品目标与边界.md#跨功能规则)、[10 权限与数据生命周期](../requirement/10-权限与数据生命周期.md)；本文件不复制第二份规则。

## 可验证验收用例

### AC-28-01 解释模型排名形成方式

- **Given**：方法v1规定缺证据排除、竞赛排名同分同名次且下位跳号、同分按稳定模型ID展示；A=80、B=80、C缺证据；v2改权重；角色为模型比较读者。
- **When**：按冻结v1复算榜单并切至v2。
- **Then**：v1下A/B同为第1且按稳定模型ID展示，C因缺证据排除并说明；切v2不覆盖v1历史。
- **反例**：规则变更不能无版本地改写历史榜单。
