# 40 平台热榜快照

需求编号：`REQ-40`。来源：OR-03，确定程度见[00 产品目标与边界](../requirement/00-产品目标与边界.md#原始需求与来源登记)。优先级：保留重评；安全与核心阻断问题优先。本文定义目标与验收，实际状态只在根目录 BACKLOG。

## 用户任务

个人监测用户或编辑在“发现非关键词的社媒热点线索”的场景中，需要读取固定平台榜单线索，以便发现关键词之外的热点线索。

## 范围与业务规则

平台热榜保存观察时刻、排序、指标及原文；非关键词趋势可关联新闻背景并进入报告选编，但不据榜单直接确认事件或冒充关键词覆盖。

- BR-40-01：空榜与失败分开，定时收集需独立准入。
- BR-40-02：整榜和每个条目均按字段用途准入、绑定当前来源政策与留存版本并登记生命周期；未准入字段不落库，缺少排名/标题/安全原文链接等必要字段拒绝请求或整次提交。旧快照无完整依据不自动补授许可。
- BR-40-03：采集许可与匿名公开许可分别审批；公开整榜和条目字段须有独立的当前许可、依据、审核有效期及适用来源准入版本，默认关闭。条目被撤回/到期或任一输入不可核对时整榜拒读，禁止回退较旧榜单掩盖最新失败。
- BR-40-04：明确平台、传输提供方、顺序依据、源更新时间、实际观察/接收时间、快照身份及许可。RSSHub顺序不自动等于平台原始绝对名次，未知原生ID/名次/热度单位/源更新时间保留未知。不同平台指标不相加，不用本站事件热度代替。
- BR-40-05：完整、成功空榜、部分数据、过期、尚无快照、采集中、采集失败、准入或公开许可不足分别可辨。时效门槛由来源公开政策显式配置；读取不外发、不采集、不创建任务。删除决定立即拒读，异步清理可追踪，整榜/条目及其派生观察一并清除，保留最小拒读审计。
- 共用权限、读取/写入状态及安全边界引用[00 产品目标与边界](../requirement/00-产品目标与边界.md#跨功能规则)、[10 权限与数据生命周期](../requirement/10-权限与数据生命周期.md)；本文件不复制第二份规则。

## 可验证验收用例

### AC-40-01 复核平台榜单线索

- **Given**：两平台同标题不同原生ID，某榜快照部分失败；角色为个人监测用户或编辑。
- **When**：打开固定快照、核对背景并选为报告线索。
- **Then**：条目排名、原文和平台指标绑定同一快照。
- **反例**：不同平台热度不相加，热榜不能替代关键词覆盖或独立事件证实。

### AC-40-02 首页平台榜单的完整链路

- **Given**：独立来源政策/公开许可及受控完整、空、截断、原生字段缺失、过期、失败、撤权和删除快照；两来源有同标题不同身份。
- **When**：经真实适配器固定响应、任务执行及快照提交后读取公开首页，再撤回条目或许可并执行清理。
- **Then**：按BR-40-02～05展示固定快照与原文、许可及各时间依据；许可/生命周期不足立即清空条目及计数；过期或最新失败不冒充实时可用。清理同时处理原榜及派生观察，保留最小审计，重复执行幂等。
- **反例**：组件许可证不是数据再发布许可；RSS源序号不是已确认原生名次，未知热度不补0；同标题不能跨平台合并身份。

## 真实来源验收边界

FR/US/AC-40-02的真实验收须区分官方条款核查、技术可达、获准采集、获准公开及自然持续运行。连接模板、RSSHub/Firecrawl软件许可、robots或HTTP成功不自动批准平台数据用途、保留期或公开权。缺少当前依据时保持不足，不调用榜单来“证明权限”；验证码/风控停止，不换代理绕过。真实持续运行至少覆盖两个自然相邻计划窗口，记录实际due、请求、作业、快照、更新时间及失败/停止，不以缩短时钟或回补冒充自然成功。该最小链路证据不代表长期稳定性。
