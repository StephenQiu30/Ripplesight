# 40 平台热榜快照

需求编号：`REQ-40`。来源：OR-03，确定程度见[00 产品目标与边界](../requirement/00-产品目标与边界.md#原始需求与来源登记)。优先级：保留重评；安全与核心阻断问题优先。本文定义目标与验收，实际状态只在根目录 BACKLOG。

## 用户任务

个人监测用户或编辑在“发现非关键词的社媒热点线索”的场景中，需要读取固定平台榜单线索，以便发现关键词之外的热点线索。

## 范围与业务规则

平台热榜保存观察时刻、排序、指标及原文；非关键词趋势可关联新闻背景并进入报告选编，但不据榜单直接确认事件或冒充关键词覆盖。

- BR-40-01：空榜与失败分开，定时收集需独立准入。
- 共用权限、读取/写入状态及安全边界引用[00 产品目标与边界](../requirement/00-产品目标与边界.md#跨功能规则)、[10 权限与数据生命周期](../requirement/10-权限与数据生命周期.md)；本文件不复制第二份规则。

## 可验证验收用例

### AC-40-01 复核平台榜单线索

- **Given**：两平台同标题不同原生ID，某榜快照部分失败；角色为个人监测用户或编辑。
- **When**：打开固定快照、核对背景并选为报告线索。
- **Then**：条目排名、原文和平台指标绑定同一快照。
- **反例**：不同平台热度不相加，热榜不能替代关键词覆盖或独立事件证实。
