# 50 模型配置与成本

需求编号：`REQ-50`。来源：OR-12，确定程度见[00 产品目标与边界](../requirement/00-产品目标与边界.md#原始需求与来源登记)。优先级：核心。本文定义目标与验收，实际状态只在根目录 BACKLOG。

## 用户任务

本机模型管理员在“模型不可用时控制积压与资源”的场景中，需要配置并控制本机模型与资源，以便控制本机分析积压与资源。

## 范围与业务规则

配置模型能力及版本，切换/停用冻结新任务并明确在途策略；tokens、缓存、币种/单位/费用、未知分别表达，当前仅本机零第三方费用。

- BR-50-01：成本展示不启用收费接口。
- 共用权限、读取/写入状态及安全边界引用[00 产品目标与边界](../requirement/00-产品目标与边界.md#跨功能规则)、[10 权限与数据生命周期](../requirement/10-权限与数据生命周期.md)；本文件不复制第二份规则。

## 可验证验收用例

### AC-50-01 控制分析能力与资源

- **Given**：旧模型在途，新配置停用；一条缺token/币种回执；角色为本机模型管理员。
- **When**：切换配置并查看积压与用量。
- **Then**：切换只作用于明确的新任务；回执区分用量未知、失败和实际消费。
- **反例**：未知费用不计零，本轮不因配置入口启用收费或云端模型。

### 边界验收补充

Given 模型配置切换时旧任务在途且新任务未启动；When 停用；Then 在途按旧版本明确处理，新任务deferred或拒绝；缺token/成本保持未知，不能记零。
