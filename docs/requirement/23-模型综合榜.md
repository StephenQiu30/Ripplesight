# 23 模型综合榜

需求编号：`REQ-23`。来源：OR-10，确定程度见[00 产品目标与边界](../requirement/00-产品目标与边界.md#原始需求与来源登记)。优先级：保留重评；安全与核心阻断问题优先。本文定义目标与验收，实际状态只在根目录 BACKLOG。

## 用户任务

模型比较读者在“选择适合任务的模型”的场景中，需要在可比轮次下比较模型，以便在共同证据下比较模型。

## 范围与业务规则

综合榜明确协议、发布轮次、时间窗、维度权重、缺失与并列；排名变化只比较同协议可比轮次，模型别名及共同证据用于比较。

- BR-23-01：榜单不由供应商宣传或不同比例分数直接合成。
- 共用权限、读取/写入状态及安全边界引用[00 产品目标与边界](../requirement/00-产品目标与边界.md#跨功能规则)、[10 权限与数据生命周期](../requirement/10-权限与数据生命周期.md)；本文件不复制第二份规则。

## 业务需求规格

输入：模型集合、可比较排名轮次、协议/维度与筛选。所需业务输入合同（编号表示归属，不要求对应页面先完成）：26来源、28规则。输出为下表可观察结果；配置、受理、执行和外部效果分别取证。

## 可验证验收用例

### AC-23-01 比较模型能力

- **Given**：两个同协议轮次和一个改权重轮次，某模型缺分；角色为模型比较读者。
- **When**：切轮次并比较模型。
- **Then**：排名、分项与类型证据同轮可追溯；缺失维度保留未知。
- **反例**：不混合不同协议/轮次制造可比排名或首次入榜结论。
