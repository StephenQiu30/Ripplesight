# 56 联系

需求编号：`REQ-56`。来源：OR-12，确定程度见[00 产品目标与边界](../requirement/00-产品目标与边界.md#原始需求与来源登记)。优先级：保留重评；安全与核心阻断问题优先。本文定义目标与验收，实际状态只在根目录 BACKLOG。

## 用户任务

公开读者在“获取站点主动公开的联系方式”的场景中，需要读取主动公布的联系渠道，以便选择合适渠道主动联系。

## 范围与业务规则

读取已发布且当前允许展示的文字、链接和二维码，联系行为由用户自己发起，不默认上传个人信息。

- BR-56-01：无渠道时显示真实空态，不编造联系地址。
- 共用权限、读取/写入状态及安全边界引用[00 产品目标与边界](../requirement/00-产品目标与边界.md#跨功能规则)、[10 权限与数据生命周期](../requirement/10-权限与数据生命周期.md)；本文件不复制第二份规则。

## 可验证验收用例

### AC-56-01 获取已公开联系入口

- **Given**：一个公开渠道、一个隐藏渠道；角色为公开读者。
- **When**：打开联系页并使用公开链接。
- **Then**：未配置、隐藏及读取失败分别说明。
- **反例**：不得从账号、反馈邮箱或日志推断联系方式。
