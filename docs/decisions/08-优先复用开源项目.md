# 优先复用开源项目

## 决策

**优先复用开源项目**：MIT 许可的可以改编，并在 THIRD_PARTY_NOTICES 中署名；GPL/AGPL 项目只参考设计，或作为独立服务运行（例如 RSSHub），代码不进本仓库；没有许可证的项目不用。

## 原因

不闭门造车，同时守住本仓库 MIT 许可的边界。
