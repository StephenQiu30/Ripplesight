# X 不用官方 API

## 决策

**X 不用官方 API**：每日热点读公开趋势页（方案 A）；推文和回复走本人账号试点（方案 B，本机 RSSHub，twscrape 单账号作为备选）；源内容被删除后，同步删除本地数据。

## 原因

本人决定。本人知晓方案 B 违反 X 的自动化条款，可能导致封号。
