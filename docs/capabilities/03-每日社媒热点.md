# 03 每日社媒热点
## 1. 要解决的问题

用户每天想知道“今天 X 上和国内社交平台上最热的是什么事”，而不只是自己设定关键词命中的内容。

## 2. 功能

- 每天 07:30（北京时间）自动生成“今日社媒热点”：X 趋势 + 国内六个热榜。
- X 趋势按地区（默认全球与美国）列出前 20 个话题、排名与热度量级；每个话题附至少 1 条可打开的新闻报道，归并成事件。
- 结果进入当天日报的“今日社媒热点”区块，也能在热点页单独查看。
- 登录用户可以对固定关键词/作者开启 X 账号试点，拿到推文原文和回复。

## 3. 做法

**X 方案 A：公开趋势页（主线，不碰 X 账号）**
- 每天固定时间读取 [getdaytrends](https://getdaytrends.com/) 公开页面（`robots.txt` 不限制，页面可直接解析）；[trends24](https://trends24.in/) 直接访问返回 403，只能通过本机 Firecrawl 正常读取，作为备选，读取失败就记失败，不绕过。
- 每个趋势词用本机 SearXNG / Google News 补新闻报道，再交给事件归并。
- 局限：只有话题名和热度量级，没有推文原文。

**X 方案 B：本人账号试点（可选）**
- 本人把 X 账号的 `auth_token` 写进本机 `.env`，通过本机 RSSHub 的 twitter 路由按固定关键词/作者每小时采集一次。
- 回复不够时，用开源库 [twscrape](https://github.com/vladkens/twscrape)（MIT）以**单账号**方式补；禁用它的多账号轮换。
- 出现限流、登录失效或风控提示时立即自动停用，等本人人工恢复。

**国内热榜**：沿用 [02](02-关键词热点.md) 的六个热榜快照。

## 5. 验收标准

1. 连续 7 天每天按时生成；每天 ≥10 个 X 趋势附 ≥1 条可打开的报道。
2. 页面读取失败的那天显示“失败”，不补造、不拿前一天的数据顶替。
3. 方案 B：一个主题拿到 ≥30 条真实推文，其中 ≥5 条带回复；模拟风控后新增请求为 0。
4. token 不出现在日志、数据库明文、证据文件或前端。

## 6. 不做什么

- 不用 X 官方付费 API，不用付费数据商，不用多账号、代理池或打码服务。
- 不用已归档的 nitter。
- 不发帖、不点赞、不私信。
