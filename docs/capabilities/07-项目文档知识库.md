# 07 项目文档管理

## 当前方式

用户撤销在线项目知识库，文档唯一原文在 docs。Obsidian 直接打开此目录，模板在 templates，看板在 views；frontmatter 和标准 Markdown 相对链接继续保留。AI 按需读取本机原文，实际任务只在 [BACKLOG](../../BACKLOG.md)。

根文件 BACKLOG、PROJECT、AGENTS 不复制正文，指针链接到仓库根目录。索引与链接校验只处理文件，不发布网站，使用说明见 [README](../README.md)。业务报告的 Obsidian 导出继续保留，详见 [05 能力](05-报告推送与知识库.md)。

## 验收标准与边界

1. 文档内容、模板、Bases 与共享 Obsidian 配置完整迁移，索引和本地链接校验通过。
2. 文档站、项目文档网页/API 与发布设施退出当前工程，业务工作台和业务知识库功能保留。
3. 实际 Obsidian 打开 vault、检索、模板插入、Bases 与根文件定位由真实操作验收；文件检查不替代应用验收，因此状态为部分可用。

原网页/AI/双端编辑 KR 随 [旧专项 PRD](../product/prd/02-PRD-workspace项目知识库.md)废弃。旧工程证据保留在 [VERIFICATION](../VERIFICATION.md)，不计作当前能力可用。
