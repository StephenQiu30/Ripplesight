# 现有数据库字典

2026-10-08 对 `4489b400` 的 [schema.sql](../../../backend/sql/schema.sql) 静态核对，共 123 张表。**这是字段词典，不是第二份建表脚本，也未验证正在运行的数据库与该基线完全一致。** 所有现有字段按原 SQL 摘录约束，不在文档中补造已存在的外键。业务设计见[数据库设计](09-全站页面数据库设计.md)。

存量表数量不决定目标设计，不要求继续扩建所有领域；是否保留/合并/退役以当前页面、后台消费者和数据迁移证据决定。
