# AIHOT provenance

The public consensus v15 constants, Cephes CDF, weighted incomplete Kemeny method, input eligibility/carry-forward rules, representative configuration rules and source registry are adapted from [KKKKhazix/AIHOT](https://github.com/KKKKhazix/AIHOT/tree/035f7b7f6e26cf203562ddd6065ff7adc1bb0c07/packages/backend/src/leaderboard), fixed commit `035f7b7f6e26cf203562ddd6065ff7adc1bb0c07`. The complete upstream MIT license is preserved in `AIHOT-LICENSE`.

The Python port uses the official HiGHS Python interface (`highspy==1.15.1`) for the same binary integer program and two-stage tie policy. New persistence and HTTP integration target HotKey's existing Python architecture. Registry descriptions and static model-weight links are evidence from that snapshot, not claims of current third-party availability. Source attribution/license fields are preserved; source data and logos may carry terms separate from the code license.

The current leaderboard UI deploys letter monograms for model and benchmark-source identification. It does not deploy upstream `assets/model-providers/` or `assets/leaderboard-sources/`; public `brand.src` is therefore null. Official source URLs and factual attributions remain available. This does not alter the separately authorized article-source avatar cache.
