# Figma 视觉验证

固定样本仅用于页面呈现、权限状态和几何检查，不证明真实来源、采集、模型、登录或通知能力可用。所有服务仅监听本机回环地址；不使用业务账号、业务库或现有 8666/8667 服务。

在 frontend 的独立终端分别运行：

```sh
node tests/visual/fixture-server.mjs
HOTKEY_API_ORIGIN=http://127.0.0.1:8670 HOTKEY_WEB_ORIGIN=http://127.0.0.1:8668 pnpm exec next dev --hostname 127.0.0.1 --port 8668
python3 tests/visual/capture.py /tmp/ripplesight-figma-capture
```

需要本机已有 `agent-browser`。脚本使用独立浏览器会话 `ripplesight-figma-matrix`，只在该会话写入虚构身份、收藏编号、备注与主题偏好。输出截图和 `matrix.json`，中断后可用相同目录继续；需要重新验证时使用新的输出目录。

默认是最小样本。观察内容密度时，可在浏览器打开 `http://127.0.0.1:8670/__fixture/state?value=normal&dataset=rich`，再刷新独立预览 `http://127.0.0.1:8668`。丰富样本包含10条资讯、3个事件、4条进展、6个主题、12个模型及分组日报；标题和摘要标有“演示”，包含长标题、多行摘要和不同主题状态。rich日报入口为 `/reports/daily/2026-10-12`。夹具不调用真实提供方，业务写接口仍返回405。

通过同一个控制入口改为 `value=empty` 可对照空态，`value=normal&dataset=minimal` 恢复原最小样本。数据集只影响本机夹具进程，刷新页面后生效；不要在同一进程上并行切换状态。当前DTO没有公开历史曲线、代表评论或汇总统计时仍显示未知/空态，不通过修改DOM伪造画面；mock验证不替代真实能力验收。

矩阵覆盖首页、事件详情、监控主题、日报详情、模型榜、探索、收藏、登录八个入口，对应 Figma 十个画板（包含共享状态和移动首页）。每页在 1440×1000、390×844 下检查正常、空、加载、503 错误、403 无权限；正常态另查深色主题，共 96 个案例。登录页使用匿名会话，其他个人页使用测试会话。空刊物与空事件通过真实路由的不可读状态呈现；未配置的登录方式不会伪装为可用。

脚本记录页面宽度、内部滚动边界、标题、状态、图片有效尺寸和网格尺寸。桌面列表折叠保草稿、侧栏偏好、键盘导航、登录弹窗关闭及焦点恢复需另外交互检查；截图数量或无溢出不代替人工视觉核对。结束后关闭两个本机进程。

401 清理旧私有内容可先在正常主题页载入详情，再将夹具 `/__fixture/state?value=unauthorized` 设为 401，并切换“显示已归档”触发读取；会话接口仍返回固定测试身份，以模拟已经打开的页面失去资源读取许可。减少动态效果用 `agent-browser --session <独立会话名> set media light reduced-motion`，另核对折叠、加载动画和短屏页脚焦点可见性；这两项不计入上述 96 案例。
